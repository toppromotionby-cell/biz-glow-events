# Библиотека шаблонов слайдов + 5 вариантов оформления на каждый

Сейчас при добавлении слайда есть только 5 типов (Титульный, Товар/позиция, Текстовый, Разделитель, Контакты), и у каждого одна раскладка: `SLIDE_TYPES` в `model.ts`, кнопки в редакторе, единая функция `slideLayout` в `design.ts`. Поля «вариант оформления» в модели нет.

## Что добавляю

### 1. Новые типы слайдов (самые востребованные в коммерческих презентациях)

- Оглавление / программа
- Цифры и факты (KPI)
- Тайминг / этапы (timeline)
- Команда
- Сравнение (2 колонки, «было / стало», «пакеты»)
- Галерея / портфолио кейсов
- Отзыв / цитата
- Смета — таблица позиций и итог
- Партнёры / логотипы клиентов
- Призыв к действию (следующий шаг)

Итого 15 типов вместо 5. Существующие слайды не трогаются.

### 2. По 5 вариантов оформления на каждый тип

Стилистика 2026–2027: крупная типографика, асимметрия, bento-сетки, полноэкранное фото с мягким затемнением, много воздуха, тонкие разделители, акцентные плашки. Примеры:

- Титульный: полноэкранное фото, split 50/50, минимал по центру, крупный оверлей, bento-обложка.
- Цифры: 3 крупные метрики в ряд, bento 2×2, одна гигантская цифра + пояснение, лента-полоса, карточки с акцентной заливкой.
- Тайминг: горизонтальная линия, вертикальный список, шаги-карточки, «змейка», нумерованные блоки.
- Сравнение: две колонки, таблица-чеклист, «до/после» с фото, split с акцентом на правой стороне, карточки-пакеты.
- Галерея: контактный лист, bento с героем, мозаика 3×3, лента full-bleed, сетка с подписями.

Вариант выбирается кликом по мини-превью прямо в блоке добавления слайда (SVG-схемы, без тяжёлого рендера) и меняется потом в панели настроек слайда.

### 3. Единый рендер

Вариант хранится в JSON слайда с безопасным дефолтом — миграция БД не нужна. Одна и та же функция раскладки используется в редакторе, превью и PDF/PPTX, так что вывод везде совпадает.

## Технические детали

- `src/lib/presentations/model.ts`: расширяю `SLIDE_TYPES` и `SLIDE_TYPE_LABELS`; добавляю `SLIDE_VARIANTS: Record<SlideType, VariantId[]>`, поле `content.variant` + нормализацию с дефолтом `classic`; `blankSlide(type, variant)` заполняет типовой контент (метрики, шаги, пункты сравнения и т.п.).
- Новый `src/lib/presentations/variants.ts`: чистые функции `variantLayout(slide, base) → SlideLayout`-оверрайды поверх текущей логики `slideLayout` (зоны текста/фото, сетки карточек, выравнивание). `design.ts` вызывает их в конце `slideLayout`, `resolveCollisions` и логика фото/цены остаются как есть.
- Новый `src/lib/presentations/blocks.ts`: описание структурных блоков новых типов (метрика, шаг, колонка сравнения, строка сметы) — используется и `SlideCanvas.tsx`, и `pdf.server.ts`.
- Рендер: `SlideCanvas.tsx` и `pdf.server.ts` получают ветки отрисовки новых блоков через общий спек (как уже сделано для фото-сеток).
- UI: блок добавления слайда в `admin.documents.presentations.$id.index.tsx` — карточка типа раскрывается в строку из 5 мини-превью; переключатель варианта в `SlideSettingsPanel.tsx`.
- Тесты `src/lib/presentations/__tests__/variants.test.ts`: для каждой пары тип×вариант — блоки внутри слайда, без пересечений, текст не залезает на фото/цену/логотипы; регрессия — старые слайды без `variant` выглядят как раньше.
