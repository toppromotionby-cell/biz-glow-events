# Свернуть блок «Направления» в разделах каталога

Список направлений внутри каждого раздела на странице «Разделы и направления» по умолчанию будет скрыт и раскрываться по клику — чтобы страница не была перегружена длинными списками.

## Что изменится

- Вместо всегда открытого списка — компактная строка-переключатель: «Направления · N» со стрелкой. Клик раскрывает/сворачивает список.
- По умолчанию блок свёрнут (для всех разделов).
- В раскрытом виде — всё как сейчас: переименование, описание, счётчик позиций, переключатель «Видно», сортировка стрелками, удаление, поле «Новое направление».
- То же поведение для блока «Что входит в раздел» у своих (виртуальных) разделов.
- Состояние «раскрыт/свёрнут» запоминается в браузере, чтобы после перезагрузки страницы открытые разделы остались открытыми.

## Технические детали

- Правка только в `src/routes/admin.catalog-structure.tsx`, компонент `SectionCard`.
- Обернуть блок направлений (и блок состава виртуального раздела) в `Collapsible` из `@/components/ui/collapsible` с `CollapsibleTrigger` в виде кнопки-заголовка и иконкой `ChevronDown` с поворотом.
- Локальный `useState(false)` для открытия, синхронизация с `localStorage` по ключу вида `catalog-structure:open:<section.key>` (чтение в `useEffect`, чтобы не ломать SSR-гидрацию).
- Изменений в БД и серверных функциях не требуется.
