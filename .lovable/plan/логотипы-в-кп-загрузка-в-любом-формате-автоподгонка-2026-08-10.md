# Логотипы в КП: загрузка в любом формате + автоподгонка

## Что сейчас
- В КП (обычном) есть загрузка логотипа файлом, но без нормализации: файл льётся «как есть» (любой размер и формат).
- В КП-промо есть загрузка своего логотипа и логотипа клиента — тоже без обработки.
- В глобальных настройках документов логотип задаётся только текстовым полем «URL логотипа» — загрузить файл нельзя.
- В PDF логотип не выводится вообще: он есть только в HTML-превью.

## Что сделаем

### 1. Единый загрузчик логотипа
Новый компонент «Логотип» (drag&drop + клик), одинаковый во всех трёх местах:
- Принимает любые форматы: PNG, JPEG, WebP, AVIF, GIF, BMP, SVG (и всё, что умеет браузер).
- Автоматически нормализует: приводит к PNG с прозрачностью, вписывает в 600×200 px (без искажений, с сохранением пропорций), обрезает лишние прозрачные поля по краям, сжимает.
- Показывает превью, кнопки «Заменить» и «Убрать», размер файла и предупреждение, если картинка слишком мелкая (будет мыло в PDF).
- Загружает в публичный бакет `catalog-media` в папку `documents/logos/`.

### 2. Три места применения
- Настройки документов → загрузка логотипа компании вместо ручного ввода URL (поле URL остаётся как запасной вариант).
- Редактор КП → логотип документа (перекрывает глобальный).
- Редактор КП-промо → свой логотип и логотип клиента.

### 3. Логотип в PDF
Сейчас главный пробел. Добавим вывод логотипа во все PDF: КП, КП-промо, счёт, акт, договор, публичная страница /kp/<token>.
- Логотип подтягивается автоматически: у документа свой → иначе глобальный из настроек.
- Ставится в шапку слева, высота фиксированная (~14 мм), ширина по пропорции, вертикальное выравнивание с блоком реквизитов — как в HTML-превью, чтобы превью и PDF совпадали.
- Если логотип не загрузился или битый — PDF всё равно генерируется, просто без картинки.

### 4. Совпадение превью и PDF
Единые размеры/отступы шапки для HTML и PDF, чтобы «в превью одно, в файле другое» больше не было.

## Технические детали
- Новый `src/components/admin/LogoUploader.tsx`: чтение файла → `createImageBitmap` (для SVG — рендер через `Image` + canvas на нужном разрешении) → canvas-ресайз до max 600×200 с devicePixelRatio-запасом → `toBlob("image/png")` → upload в `catalog-media`, `getPublicUrl`.
- Обрезка прозрачных полей: анализ альфа-канала на canvas перед финальным ресайзом.
- В `src/lib/documents/pdf.server.ts`: хелпер `embedLogo(pdfDoc, url)` — `fetch` URL, `embedPng`/`embedJpg` по сигнатуре байтов, кэш в рамках одного рендера, try/catch с фолбэком «без логотипа». Ограничение размера ответа (например 2 МБ) и таймаут, чтобы не подвешивать Worker.
- Точки вызова: `buildOrderDocPdf`, `buildStandaloneQuotePdf`, `buildPromoQuotePdf`.
- Источник URL: `quote.logo_url ?? settings.logo_url`; для промо дополнительно `client_logo_url` справа в шапке.
- Изменений схемы БД не требуется — поля `logo_url` / `client_logo_url` уже есть.
