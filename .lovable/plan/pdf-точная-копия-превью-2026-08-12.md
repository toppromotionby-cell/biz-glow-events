# PDF = точная копия превью

## Проблема

Сейчас превью и PDF рисуются двумя разными кодами:

- превью — HTML (`promo-quote-html.ts`, `quote-html.ts`): таблица с рамками, серые шапки разделов, свои цвета и кегли;
- PDF — отдельный генератор на pdf-lib (`pdf.server.ts`, ~2100 строк): своя шапка с оранжевой полосой, карточки, свои отступы и колонки.

Поэтому файл по кнопке PDF выглядит иначе, чем то, что видно на экране.

## Что делаем

Один общий «макет документа», из которого рисуются и превью, и PDF. Ничего настраивать вручную не нужно: система сама берёт те же данные, те же шрифты, цвета, ширины колонок и переносы, что и в превью.

Итог для пользователя:
- нажал PDF — получил ровно то, что было в превью (шапка с логотипом и реквизитами, блок проекта, таблица с разделами, объединённые ячейки «услуга», итоги, подписи, примечания);
- любые будущие правки превью автоматически попадают в PDF — расхождения больше не появляются.

## Технически

1. Ввести описание макета `doc-spec.ts` рядом с `doc-layout.ts`: секции (шапка, карточка проекта, таблица, итоги, подписи, футер), для таблицы — колонки, выравнивание, объединения (`isServiceOnlyRow`), стили строк (раздел / подытог / доп.), палитра и кегли из `brand.ts` + `density.ts`.
2. `promo-quote-html.ts` и `quote-html.ts` строят HTML из этого спека (текущий CSS сохраняем как эталон — под него подгоняются значения спека).
3. `pdf.server.ts` перевести на отрисовку того же спека: те же границы ячеек, фоновые заливки строк разделов, вертикальное центрирование, центрирование чисел, ширины колонок через `fitColumnWidths`, перенос текста в шапках. Убрать декоративные элементы, которых нет в превью (верхняя полоса, карточки со скруглениями), если они не приходят из спека.
4. Шрифты: кириллические TTF из `pdf-fonts.server.ts` сопоставить со шрифтом превью (`doc-font.ts`), кегли — единый источник в спеке.
5. Тесты: расширить `pdf.server.test.ts` — на одном фикстур-документе проверить, что набор строк/колонок/объединений PDF совпадает со спеком, из которого построен HTML.
6. Кнопки и маршруты (`/render?format=pdf`, скачивание, имена файлов) не меняются.

## Границы

- Только промо-КП и КП (quotes); прочие документы — по тому же спеку, если используют те же рендеры.
- Пиксель-в-пиксель совпадение невозможно (PDF ≠ браузер), цель — визуальная идентичность: структура, цвета, кегли, порядок и переносы.
