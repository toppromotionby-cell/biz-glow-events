# Починка полей в редакторе позиций (промо-КП и смета)

## Что сломано (проверено в коде)

1. **Пропадает курсор при переименовании раздела.** Блок раздела отрисовывается с ключом по его названию (`PromoItemsTable.tsx:111`, `QuoteItemsPanel.tsx:167`). Каждое нажатие клавиши меняет название → меняется ключ → React пересоздаёт весь блок раздела, поле теряет фокус и каретку. Из-за этого же в названии раздела нельзя нормально стереть текст или напечатать пробел.

2. **Числовые поля ведут себя резко.** «Кол-во», «×», «Цена», «Себест.» пишут `Number(e.target.value)` прямо в модель: очистка поля превращается в `0`, нельзя оставить поле пустым, появляются ведущие нули («025»), при вводе дробной части каретка прыгает.

3. **Ненужные подсказки в наименовании.** Поле названия позиции подключено к базе знаний (`SuggestInput`) и всплывает выпадающий список поверх соседних строк, даже когда он не нужен.

4. **Двойные подсказки в названии раздела.** У поля стоит браузерный `datalist`, который открывает собственный список поверх интерфейса.

## Что сделаем

- Отрисовывать разделы по стабильному идентификатору (индекс/стабильный ключ раздела), а не по тексту названия — фокус и каретка остаются на месте при вводе.
- Переименование раздела делать через локальное состояние поля с применением в модель по завершении ввода (blur/Enter), чтобы промежуточные значения не перестраивали список.
- Ввести общее числовое поле: хранит то, что человек напечатал (можно пусто, можно «0,5»), в модель пишет число при вводе, а при уходе из поля нормализует. Применить ко всем числовым графам промо-таблицы и таблицы сметы.
- Убрать автоподсказки из наименования позиции: обычный ввод без выпадающего списка. Подбор из базы знаний остаётся доступен отдельной кнопкой/действием, которое уже есть в разделе («Добавить в раздел из базы знаний»).
- Убрать `datalist` с поля названия раздела; готовые названия остаются в меню «Перенести в раздел».

## Проверка

Прогон существующих тестов расчётов/экспорта + ручная проверка в админке: ввод названия раздела без потери каретки, очистка и ввод дробных чисел, корректный пересчёт «итого» и «всего».
