# КП: единый редактор в стиле презентаций

## Что сейчас (по факту кода)

Создание: одна кнопка «Создать документ» → диалог из 2 шагов (тип: КП / КП промо → источник: с нуля, из заказа, из шаблона, из образца). Это работает и близко к диалогу презентаций.

Редактирование: два почти одинаковых, но по-разному собранных экрана —
`admin.documents.quotes.$id` (867 строк) и `admin.documents.promo.$id` (713 строк).
Оба: липкая шапка с 5–7 кнопками + меню «Ещё», полоса проверок, слева вкладки (Состав / Клиент / Финансы / Оформление), справа итоги и превью A4 в маленьком окне с прокруткой.

Презентации: шапка с названием-инлайн, статусом и состоянием сохранения; слева вертикальный рельс разделов (Слайды / Дизайн / Документ / Сверка / Проверка) с выдвижной панелью; по центру крупный холст с зумом; снизу строка статуса (страница, зум, сетка, подсказка); справа свойства выделенного блока.

## Что лишнее / дублируется в КП

1. Два независимых редактора с копиями шапки, версий, «Сохранить в библиотеку», блока оформления — расходятся при каждой правке.
2. Превью — второстепенное (узкая колонка), хотя это главный результат; при этом есть ещё «Открыть превью в окне» и отдельный маршрут `/render`.
3. Тумблер «Правка по двойному клику» — в презентациях двойной клик работает всегда, тумблер не нужен.
4. Версии: в промо — в «Ещё», в КП — отдельной вкладкой. Один и тот же функционал в двух местах.
5. Меню «Ещё» смешивает разное: версии, «отметить отправленным», заказ, презентация, библиотека, база знаний.
6. Панель синхронизации с Google-таблицей висит первым блоком во вкладке «Состав», хотя это редкая интеграция.
7. Полоса проверок дублирует смысл раздела «Проверка» из презентаций (в презентациях это раздел рельса).
8. Статус сохранения написан текстом мелко в шапке, кнопки «Сохранить» нет — непонятно, сохранилось ли.

## Что делаем

Единый шелл редактора документов, повторяющий презентации, для КП и КП промо.

Шапка: назад · название инлайн · статус · «сохранено / есть изменения» · Отменить · PDF · Отправить · «Ещё» (только: сохранить версию, история, в библиотеку, создать заказ, собрать презентацию, Google-таблица).

Левый рельс (иконки + выдвижная панель):
- Состав — панель позиций и разделов (текущая таблица)
- Клиент — проект, клиент, контакты, период, статус, «действительно до»
- Финансы — комиссия, управление, скидка, НДС + итоги
- Оформление — колонки, шрифт, акцент, логотипы, реквизиты, подвал
- Проверка — ошибки/предупреждения (то, что сейчас в полосе), с переходом к проблемному месту
- История — версии и восстановление (одно место вместо двух)

Центр: лист A4 во всю доступную площадь — это рабочая область. Двойной клик по блоку открывает правку этого блока (без тумблера). Снизу строка статуса: зум (−/100%/+/Вписать), «страница 1 / N», кнопка «Все страницы», подсказка по горячим клавишам.

Правая панель: свойства выделенного блока/строки (как «Выбранный блок» в презентациях). Если ничего не выделено — краткие итоги сметы.

Создание: диалог оставляем, но выравниваем по презентациям — крупные карточки шага 1, на шаге 2 единый список источников с поиском, кнопка «Пустой документ» первой.

## Технические детали

- Новый `src/components/admin/documents/DocEditorShell.tsx` — шапка + `EditorSidebar` + центр + правая панель + статус-строка; `EditorSidebar`, `CanvasStage`, `EditorStatusBar` переиспользуем из `src/components/admin/presentations/` (переносим в общий `src/components/admin/editor/`, презентации импортируют оттуда же).
- Обе страницы КП (`quotes.$id.index.tsx`, `promo.$id.index.tsx`) переписываются как конфигурация секций для шелла: вся текущая бизнес-логика (мутации, patchQuote/patchItems, totals, checks, версии, отправка) сохраняется без изменений, меняется только компоновка.
- Превью: используем существующий `LivePreviewFrame` + `A4Sheet` внутри `CanvasStage` с зумом; убираем тумблер `inlineEdit` (двойной клик всегда активен) и оставляем «открыть в окне» в «Ещё».
- `DocStatusBar` больше не рисуется полосой на странице — его содержимое переезжает в раздел «Проверка» рельса, а на иконке раздела показывается точка при ошибках (механика `dot` уже есть в `EditorSidebar`).
- `PromoSheetPanel` / `QuoteSheetPanel` — из вкладки «Состав» в пункт «Google-таблица» меню «Ещё» (диалог).
- Маршруты, серверные функции, модели данных и рендер PDF не трогаем.

## Ограничения

- Мобильная версия: рельс сворачивается в нижнее меню разделов, превью и панель — по очереди (как сейчас в презентациях на мобильном).
- Ничего не удаляем из функционала: только переносим в одно логичное место.
