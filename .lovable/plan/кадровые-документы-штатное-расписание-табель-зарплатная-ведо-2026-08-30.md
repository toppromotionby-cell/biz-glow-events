# Кадровые документы: штатное расписание, табель, зарплатная ведомость

Цель: три связанных документа работают как единая связка (как в 1С/бухгалтерских сервисах, только просто), формы совпадают с вашими файлами-референсами, лист — A4 альбомный.

## Что уже сделано в текущем шаге

Альбомный лист A4 для видов «Зарплатная ведомость», «Штатное расписание», «Табель» — в превью, PDF и DOCX. Добавлен новый вид документа «Табель учёта рабочего времени».

## 1. Справочник сотрудников (основа связки)

Новый раздел админки «Сотрудники» (внутри Информационной базы):
ФИО, табельный номер, должность, код должности по ОКРБ, подразделение,
тарифный оклад, % повышения, ставка (0.25 / 0.5 / 1), дата приёма/увольнения, статус.

Он же — источник данных для всех трёх документов: один раз завели человека — он попадает
в штатное расписание, из него в табель, из табеля в ведомость.

## 2. Шаблоны по референсам

Три заводских шаблона, повторяющих ваши файлы 1-в-1.

**Штатное расписание** (шапка «УТВЕРЖДАЮ», «Штат в количестве N единиц с фондом оплаты … прописью»):
№, наименование должности, код ОКРБ, кол-во штатных единиц, тарифный оклад на единицу и на факт.
количество, повышение (% по положению, % по ст. 261-2 ТК РБ, сумма на единицу и на количество),
оклад на единицу и на количество, примечание (ФИО). Строки «ВСЕГО» и «ИТОГО» считаются автоматически.

**Табель учёта рабочего времени**: организация, подразделение, месяц, даты отчётного периода,
строки сотрудников с 31 колонкой дней, колонки «Отработано часов», «Дни явок», далее трудовой
отпуск, отпуск без сохранения, нетрудоспособность, адм. отпуск, гос. обязанности, командировки,
выходные, «Всего явок и неявок», плюс блок обозначений (В, О, А, Б, К, ПР, У, Д, Г, НН, ОР, ГП, ОЖ, Р, ГС).
Ввод дня: часы или буква; итоги пересчитываются на лету.

**Зарплатная ведомость** (шапка «УТВЕРЖДАЮ … директор … дата»):
таб. номер, ФИО, должность, оклад, ставка, дни, часы, оклад начислено, надбавка за сложность,
всего начислено, подоходный налог, 1% пенс. фонд, аванс на руки, зарплата на руки, итого на руки,
строка ИТОГО. Формулы: начислено = оклад × отработанные/норма, налог и 1% ФСЗН считаются
автоматически с возможностью ручной правки в любой ячейке.

## 3. Связи между блоками

```text
Сотрудники ──► Штатное расписание (оклад, ставка, код должности)
      │                 │
      │                 ▼
      └──────────► Табель (дни/часы за месяц)
                        │
                        ▼
                Зарплатная ведомость (оклад × отработано → начисления → на руки)
```

- Кнопка «Заполнить из штатного расписания» в табеле (подтягивает состав, ставки, норму часов).
- Кнопка «Заполнить из табеля» в ведомости (дни, часы за выбранный месяц).
- Реквизиты компании, логотип, подпись и печать берутся из карточки компании — как в КП.
- Пересчёт по кнопке «Обновить из источника», без автоперезаписи ручных правок (показываем, что изменилось).

## 4. Импорт из Excel

Загрузка ваших .xls/.xlsx прямо в документ: система распознаёт шапку по названиям колонок
и заполняет таблицу; неопознанные колонки можно сопоставить вручную одним экраном.
Поддерживаются многолистовые книги (лист = месяц).

## 5. Удобство работы

- Табличный редактор с вводом с клавиатуры (Tab / стрелки), автосумма итогов, закреплённая шапка.
- Месяц и год — один селектор, он же подставляет норму рабочих часов и даты периода.
- Экспорт: PDF (A4 альбомный), DOCX, XLSX.
- Копия документа на следующий месяц одной кнопкой.

## Технические детали

- Таблицы: `hr_employees` (справочник) и хранение табеля/ведомости в блоках документа
  `paperwork_documents` (новый тип блока `hrtable` с колоночной схемой и формулами) — без
  дублирования логики документов.
- Расчёты — чистые функции в `src/lib/paperwork/hr/*.ts` (норма часов, начисления, налоги,
  итоги), покрытые тестами; используются и в превью, и в PDF/DOCX/XLSX.
- Импорт Excel — парсер на `xlsx` в server function, с картой синонимов колонок.
- Заводские шаблоны — в `src/lib/paperwork/preset-templates.ts`, с закреплёнными (нередактируемыми)
  шапками таблиц, чтобы форму нельзя было сломать.
- Регрессионные тесты: ширины колонок в альбомном листе, совпадение превью и PDF, расчёт итогов
  ведомости и табеля на данных из ваших файлов.
