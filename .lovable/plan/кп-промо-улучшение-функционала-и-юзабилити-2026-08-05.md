# КП промо: улучшение функционала и юзабилити

Модуль работает, но редактор построен как «одна длинная форма»: позиции нельзя перетаскивать (иконка «ручки» декоративная), разделы вводятся текстом в каждой строке, нет массовых действий, нет истории и отправки клиенту. Ниже — набор улучшений, основанных на типовых решениях редакторов КП (Better Proposals, PandaDoc, Qwilr) и на уже принятых в проекте паттернах (split-view, автосохранение, snippet-библиотека из обычных КП).

## 1. Таблица позиций вместо списка карточек

- Позиции группируются по разделам («Персонал», «Логистика», «Активности»): раздел — заголовок группы, а не поле в каждой строке.
- Перетаскивание строк внутри раздела и между разделами (dnd-kit — уже используется в проекте), сохранение `sort_order`.
- Компактная строка-таблица: наименование, ед., кол-во, ×, цена, сумма. Примечание и флаг «без комиссии» — раскрываются по клику, не занимают место постоянно.
- Действия по строке: дублировать, удалить, перенести в другой раздел.
- Итог по каждому разделу (подсумма) — прямо в шапке группы.
- Массовое выделение строк: удалить, дублировать, перенести раздел, применить наценку %.
- Ctrl/Cmd+Enter в поле «Наименование» — добавить строку ниже (быстрый ввод с клавиатуры).

## 2. Быстрое наполнение

- Кнопка «Добавить раздел» с готовыми названиями из пресетов.
- Библиотека позиций (snippets): сохранить выбранные строки как переиспользуемый блок и вставлять в другие КП — по образцу уже существующей библиотеки блоков в обычных КП.
- Импорт позиций из заказа/каталога — тот же принцип, что «Импорт из заказа» в обычном КП.
- Вставка из буфера: скопированный из Excel фрагмент (наименование/кол-во/цена, разделители табами) разбирается в строки.

## 3. Расчёты и контроль

- Скидка на документ: процент или фиксированная сумма, отдельной строкой в итогах.
- Округление итога и валюта документа в явном поле (сейчас валюта есть в модели, но не редактируется).
- Панель итогов делается «липкой» и показывает маржу: себестоимость (опционально по строке) → выручка → прибыль %.
- Проверки перед отправкой: пустые наименования, нулевые цены, отсутствие клиента — уже частично есть, добавляются в единый чек-лист «Готово к отправке» с переходом к проблемной строке.

## 4. Юзабилити редактора

- Переключатель режимов превью: «Документ» / «Только цифры» + кнопки масштаба и «Открыть в новой вкладке».
- Индикатор автосохранения переносится в липкую шапку; добавляется отмена последнего действия (Undo, Ctrl+Z) для позиций.
- Хоткеи: Ctrl+S — сохранить, Ctrl+P — PDF.
- Предупреждение при уходе со страницы с несохранёнными изменениями.
- Мобильная раскладка: превью сворачивается в отдельную вкладку, а не колонку.

## 5. Жизненный цикл документа

- Кнопка «Отправить клиенту»: письмо с PDF во вложении через уже настроенную почту, статус автоматически → «Отправлено», фиксируется дата отправки.
- Срок действия предложения (валиден до) — поле + вывод в документе и подсветка просроченных в списке.
- История версий: снимок документа при каждой отправке, возможность посмотреть/восстановить.
- В списке: сортировка по сумме/дате, суммарные показатели сверху (в работе, отправлено, принято на сумму), быстрый фильтр «мои/просроченные».

## Технические детали

- Схема: `promo_quotes` — добавить `discount_type`, `discount_value`, `valid_until`, `sent_at`; `promo_quote_items` — задействовать `sort_order` при сохранении, добавить `cost` (себестоимость, опционально). Новая таблица `promo_quote_snippets` (по образцу `quote_block_snippets`) и `promo_quote_versions` для истории. Все таблицы — с GRANT и RLS только для админ-роли.
- `savePromoQuote` сейчас перезаписывает позиции без `sort_order` — при drag&drop порядок нужно передавать явно.
- Расчёты (скидка, маржа) добавляются в `computePromoTotals`, чтобы PDF, XLSX и превью считали одинаково; XLSX-экспорт дополняется формулами для новых строк.
- Редактор разбивается на компоненты: `PromoItemsTable`, `PromoTotalsPanel`, `PromoPreviewPane` — сейчас всё в одном файле роутера на 391 строку.

## Порядок работ

1. Таблица позиций с разделами, drag&drop, подсуммами и массовыми действиями (наибольший эффект).
2. Юзабилити редактора: липкая шапка, хоткеи, undo, режимы превью, мобильная вкладка.
3. Скидка, валюта, маржа, чек-лист готовности.
4. Быстрое наполнение: библиотека позиций, импорт из заказа, вставка из Excel.
5. Жизненный цикл: отправка клиенту, срок действия, история версий, сводка в списке.
