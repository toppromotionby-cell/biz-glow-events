# Презентации: рабочая трансформация блоков и Canva-логика редактирования

Разбор текущего кода подтвердил конкретные причины, почему «блоки живут своей жизнью».

## Что сломано сейчас (проверено по коду)

1. **Тянуть можно только 5 блоков.** В `SlideLayoutOverlay` интерактивные рамки создаются лишь для фото, текстовой колонки, цены и двух логотипов. Заголовок, подзаголовок и описание отдельными объектами не существуют — их можно выбрать только двойным кликом, и у такой рамки нет ни одного маркера (маркеры рисуются только когда у блока есть запись в списке объектов).
2. **Размер текста не меняется.** Растягивание текстового блока меняет только ширину колонки (`textWidth`). Кегля у блоков в модели нет вообще — нет полей масштаба для заголовка/подзаголовка/описания, поэтому «увеличить шрифт мышью» физически нечем.
3. **Логотип тянется вслепую.** Рамка логотипа, стоящего в углу, рисуется по прямоугольнику зоны, а не по самому логотипу. Поэтому маркер стоит далеко от картинки, а коэффициент масштабирования считается от чужого размера — визуально «ничего не происходит» или дёргается.
4. **Текст нельзя править прямо на слайде.** Прозрачные рамки объектов лежат поверх редактируемых надписей и перехватывают клики: попасть курсором в текст можно только двойным кликом, одиночный клик всегда выделяет колонку целиком.
5. **Тормоза и мусорная история.** При каждом движении мыши (и при перетаскивании, и при масштабировании) сразу пишется новое значение раскладки — полный пересчёт слайда и новая точка отмены на каждый кадр. Отмена откатывает не действие, а один пиксель.
6. **Нет обратной связи Canva-уровня.** Нет цифрового размера при растягивании, нет пропорциональности по Shift, нет подсветки достижения предела, нет прилипания маркеров к направляющим.
7. **Кнопка «Сохранить» дублирует автосохранение** — она есть в шапке рядом с включённым автосейвом.

## Что сделаем

**Все блоки становятся объектами.** Заголовок, подзаголовок, описание, цена, фото и оба логотипа выделяются одним кликом, показывают рамку с 8 маркерами и подпись типа блока. Определение типа при клике — по фактическому элементу под курсором, а не по крупной колонке.

**Растягивание с автоподгоном шрифта.** У текстовых блоков появляется собственный масштаб кегля: тянешь рамку — шрифт и межстрочный интервал меняются вместе с блоком, текст остаётся внутри и не наезжает на соседей. Достижение минимума/максимума подсвечивается. Углы — пропорционально, Shift — строго пропорция, Alt — от центра. Во время растягивания рядом показывается текущий размер.

**Логотипы.** Рамка строится по реальным границам логотипа в любом положении (угол, свободное место, титул). Масштаб — маркерами и колесом при зажатом Ctrl, перетаскивание — свободное с магнитными направляющими, стрелками — по пикселю.

**Правка текста.** Одиночный клик выделяет блок, второй клик по выделенному блоку сразу ставит курсор в текст (как в Canva). Пока идёт набор, рамки объектов не перехватывают мышь. Esc выходит из набора в выделение, второй Esc снимает выделение.

**Скорость.** Во время перетаскивания и растягивания слайд перестраивается через кадровую синхронизацию, а в состояние документа и в историю отмены записывается один шаг — по отпусканию. Отмена/повтор откатывают действие целиком.

**Сохранение.** Кнопка «Сохранить» убирается из шапки редактора презентации; остаётся автосохранение и статус «Сохранено HH:MM» с ручным повтором только при ошибке сети. Ctrl+S остаётся как принудительное сохранение.

**Мелочи, которых не хватает.** Дублирование/удаление выделенного блока с клавиатуры, сброс блока в авто по двойному клику на маркере, единая подсказка «Клик — выделить, двойной — править текст, углы — размер».

## Технические детали

- `src/lib/presentations/model.ts`: добавляются `titleScale`, `subtitleScale`, `bodyScale` (кегль-множители, 0.6–1.8, `null` = авто) с нормализацией и обратной совместимостью старых слайдов; общие константы пределов.
- `src/lib/presentations/fit.ts` / `content-spec.ts`: множители кегля учитываются в автоподборе плотности и попадают в общий спек, поэтому превью, PDF и полноэкранный показ остаются идентичными.
- `src/components/admin/presentations/SlideLayoutOverlay.tsx`: список объектов расширяется частями текста (геометрия берётся из спека, а не из DOM); единый `startResize(kind, handle)` с дельтами, Shift/Alt, индикатором размера и подсветкой пределов; `rafCommit` для промежуточных значений и один `onLayout` с флагом «шаг истории» на отпускании; режим `editing`, отключающий перехват указателя.
- `src/lib/presentations/logo-plan.ts` / `design.ts`: `planSlideLogos` возвращает фактический прямоугольник логотипа, overlay использует его вместо прямоугольника зоны.
- `src/components/admin/presentations/SlideCanvas.tsx`: `data-block` для всех частей включая цену и фото; переход в `contentEditable` по второму клику; сохранение позиции курсора при перерисовке.
- `src/routes/admin.documents.presentations.$id.index.tsx`: убирается кнопка «Сохранить», подключается транзакционный шаг истории (`pushHistory` только на завершение жеста), статус автосохранения в футере.
- Тесты в `src/lib/presentations/__tests__/`: арифметика масштабирования (дельты, пределы, пропорции), совпадение геометрии превью и PDF при изменённом кегле, обратная совместимость слайдов без новых полей.
- Проверка в браузере (Playwright): выделение и растягивание каждого типа блока, правка текста, масштабирование логотипов, отсутствие лишних шагов отмены.
