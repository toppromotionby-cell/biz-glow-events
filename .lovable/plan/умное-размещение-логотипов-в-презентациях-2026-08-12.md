# Умное размещение логотипов в презентациях

## Проблема

Сейчас логотипы расставляются в трёх местах независимо друг от друга, поэтому на одном слайде логотип компании может появиться дважды:

- титульный слайд рисует большой логотип по центру **и** тот же логотип в футере;
- на обычных слайдах логотип есть в футере, а при режиме «всегда» добавляется ещё и накладка в углу;
- логотип клиента может встать в тот же угол, что и логотип компании, или наехать на фото.

Плюс PDF и PPTX считают позиции по своим правилам, поэтому превью и файлы расходятся.

## Что сделаем

1. Один общий «планировщик логотипов»: для каждого слайда он решает, где стоит логотип компании и где логотип клиента — и гарантирует **не больше одного логотипа каждого вида на слайде**.
2. Правила по типу слайда:
   - **Титульный / Контакты** — логотип компании крупный в контентной зоне, в футере его нет; логотип клиента — в противоположном верхнем углу.
   - **Раздел** — логотип компании только в футере, клиентский — в свободном верхнем углу.
   - **Текст / Позиция** — логотип компании в футере (или в углу, если футер скрыт/перекрыт фото), клиентский — в свободном верхнем углу.
   - Полноэкранное фото — логотипы ставятся на затемнённую зону, чтобы читались.
3. Автовыбор угла: занятость углов проверяется по реальным рамкам фото; если оба верхних угла заняты — клиентский логотип уходит в нижний свободный угол, а не накладывается на изображение.
4. Оба логотипа никогда не встают в один угол и выравниваются по одной базовой линии, с одинаковым визуальным весом (клиентский чуть меньше или равен — по масштабу из настроек).
5. Настройки брендинга (авто / всегда / только титул / выкл, масштаб) сохраняются, но «всегда» теперь означает «ровно один раз на слайде», а не «дополнительно к футеру».

## Техническая часть

- Новый модуль `src/lib/presentations/logo-plan.ts`: `planSlideLogos({ slideType, frames, layoutPlacement, logoLayout, hasBrandLogo, hasClientLogo })` → `{ brand: null | {slot, w, h}, client: null | {slot, w, h} }`, где `slot` ∈ `hero | footer | tl | tr | bl | br`. Занятость углов и футера считается по `fit.layout.frames` (те же данные, что уже используются в `SlideCanvas`).
- `src/components/admin/presentations/SlideCanvas.tsx`: убрать разрозненные `showClient` / `showBrandOverlay` / логотип в футере; рисовать строго по результату планировщика (футер печатает название бренда текстом, если логотип уехал в hero/угол).
- `src/lib/presentations/pdf.server.ts`: заменить локальные расчёты (`layout.brand === "always"`, титульный логотип, футер) на тот же планировщик, координаты слотов пересчитываются из 1280×720 в размер страницы.
- `src/lib/presentations/pptx.browser.ts`: добавить логотип клиента и использовать те же слоты, чтобы PPTX совпадал с превью.
- Панель брендинга: подписи режимов уточняются, поведение полей не меняется.
- Проверка: добавить unit-тест на `planSlideLogos` — по одному логотипу каждого вида максимум, отсутствие конфликта слотов на всех типах слайдов.
