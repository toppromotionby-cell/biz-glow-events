# Умный календарь: сайт + Google + Telegram-ассистент

Единый календарь в админке, синхронный с Google Календарём, с Telegram-ботом,
который принимает текст и голос, сам понимает «задача или встреча», направление,
время и важность, напоминает, спрашивает и отчитывается.

## Решения, зафиксированные с вами

- Один Google-календарь, направления — цветами и префиксом в названии.
- Встречи → события Google Календаря, задачи → Google Tasks (отдельно).
- Пользователь один — владелец (один Telegram chat_id, один Google-аккаунт).
- Никаких автопереносов: любой перенос — только после подтверждения кнопкой.

## Направления

Список направлений — редактируемый справочник (стартово: Личное, Belight,
EventHub, Top Promotion). Диктуете новое — бот добавляет после подтверждения.
У каждого: цвет, эмодзи, ключевые слова, рабочие часы.

## Как работает ввод

1. Пишете или наговариваете в бота: «завтра в 15 жёсткая встреча с подрядчиком
   по EventHub» / «до пятницы сделать смету по Belight».
2. Голос: файл из Telegram → распознавание речи → текст.
3. Разбор моделью в структуру: тип (встреча/задача), направление, начало,
   длительность, дедлайн, важность (жёсткая = «нельзя переносить»), участники,
   место, заметка.
4. Бот присылает карточку-подтверждение с кнопками: «Сохранить», «Изменить
   время», «Другое направление», «Это задача/встреча».
5. Если распознавание неуверенное или чего-то не хватает (нет времени, неясно
   направление) — бот задаёт один короткий уточняющий вопрос, а не гадает.
6. После сохранения — запись в базу и выгрузка в Google (событие или задача).

## Синхронизация с Google (двусторонняя)

- Наша база — источник правды; Google — зеркало, но правки в Google
  подхватываются обратно.
- Вниз: инкрементальная выборка изменений каждые ~2 минуты (по токену
  синхронизации, без перечитывания всего календаря).
- Вверх: при любом создании/изменении/удалении в админке или боте.
- Конфликт (изменено в обоих местах) — не решаем молча: бот присылает
  «в Google сдвинули на 16:00, принять?» с кнопками.
- Удаление в Google = отмена у нас, с уведомлением.

## Напоминания, дайджесты, контроль

- За 60 и за 15 минут до встречи (интервалы настраиваются; для «жёстких» —
  дополнительно за 2 часа).
- 08:00 — план дня: встречи по времени, задачи по приоритету, конфликты,
  «узкие места» дня.
- Вечером (напр. 20:00) — отчёт: сделано / не сделано / перенесено, вопрос по
  каждой незакрытой задаче.
- Через 30 минут после планового окончания задачи — «сделано?» с кнопками
  «Готово», «Ещё в работе», «Перенести» → бот предлагает 2–3 конкретных
  свободных слота, переносит только после нажатия.
- Понедельник — обзор недели: загрузка по направлениям, просрочки, что
  разгрузить.

## Умная часть

- Приоритизация: срочность (дедлайн), важность (жёсткая/обычная), направление,
  время выполнения → «сначала это, потом это» с одной строкой объяснения.
- Поиск свободных окон с учётом рабочих часов направления и буферов на дорогу.
- Предупреждение о наложениях и о днях-перегрузах ещё при создании.
- Разбиение крупной задачи на шаги по запросу.
- Обучение стилю: бот хранит профиль вашего стиля общения и отвечает в нём,
  коротко и по делу.
- Аналитика: сколько времени по направлениям, доля просрочек, повторяющиеся
  переносы (сигнал «эту задачу вы откладываете 4-й раз»).

## Часовые пояса

Часовой пояс берётся с устройства, с которого пришёл ввод: браузер отдаёт
свою зону автоматически, Telegram — по последней зафиксированной зоне
устройства; при расхождении бот один раз переспрашивает и запоминает.
Всё хранится в UTC, отображается в зоне события.

## Экран в админке

Раздел «Календарь»: месяц / неделя / день / список, фильтр по направлениям,
drag-and-drop переноса (с подтверждением), боковая панель «Входящие» для
нераспознанных или неполных записей, панель «Сегодня» с приоритетами,
настройки: направления, рабочие часы, время дайджестов, интервалы напоминаний.

## Дополнительные идеи (по желанию)

- Привязка события к КП/заказу в системе — из карточки заказа видно встречи.
- Автосоздание задачи «перезвонить» из нового заказа с сайта.
- Кнопка «перенести весь день» при форс-мажоре.
- Тихие часы: ночью бот не пишет, копит и отдаёт утром.

## Техническая часть

- Данные: `calendar_directions`, `calendar_items` (тип, статус, важность,
  времена, направление, google_event_id / google_task_id, etag),
  `calendar_reminders` (что и когда отправить, отправлено ли),
  `calendar_inbox` (сырой ввод, транскрипт, разобранный черновик),
  `calendar_sync_state` (sync-токен, лизинг единственного выполнения),
  `assistant_prefs` (часовой пояс, стиль, расписание дайджестов).
  Всё server-only: доступ через серверные функции, RLS + гранты только
  service_role/владелец.
- Google: connector Google Calendar через шлюз Lovable. Первым шагом проверяем,
  проксирует ли шлюз Google Tasks API; если нет — задачи уходят в тот же
  календарь как события с пометкой «Задача» (то же поведение для вас,
  без отдельного списка Tasks). Это подтверждается до начала разработки.
- Telegram: отдельный вебхук `/api/public/telegram-calendar` с проверкой
  секретного заголовка (по образцу существующего `telegram-support`),
  обработка text / voice / callback-кнопок.
- Голос и разбор: транскрипция и разбор в структуру через Lovable AI;
  ответ модели строго по JSON-схеме, при низкой уверенности — уточняющий
  вопрос вместо догадки.
- Фоновые задания: минутный pg_cron на напоминания и синхронизацию с лимитом
  пачки, лизингом (второй запуск не дублирует), идемпотентной отметкой
  отправленного и «стоп-краном» при ошибках AI/квот с уведомлением владельцу.
- Тесты: разбор фраз (тип/направление/время/жёсткость), конфликты синка,
  таймзоны и переход на другой день, отсутствие двойных напоминаний.

## Порядок работ

1. Проверка Google-коннектора (события + Tasks), подключение.
2. База, справочник направлений, серверные функции CRUD.
3. Экран календаря в админке.
4. Двусторонняя синхронизация с Google.
5. Telegram: текст → карточка подтверждения → запись.
6. Голос: транскрипция + уточнения.
7. Напоминания, утренний план, вечерний отчёт, follow-up с переносом.
8. Умный слой: приоритеты, свободные слоты, аналитика, стиль общения.
