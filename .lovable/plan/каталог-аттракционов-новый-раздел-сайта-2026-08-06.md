# Каталог аттракционов — новый раздел сайта

Новый верхнеуровневый раздел `/attractions` («Каталог аттракционов»), полностью повторяющий дизайн и поведение существующих разделов (Зоны / Оборудование / Услуги / Производство). Данные — с play-game.by, дизайн — только event-hub.by.

## Что получит пользователь

- Страница `/attractions` со списком аттракционов: та же сетка карточек, те же фильтры по категориям, хлебные крошки, цены «от N BYN», кнопки «Подробнее» и «В корзину».
- Страница карточки `/attractions/{slug}`: галерея фото, видео (если есть у источника), описание, характеристики, цена, FAQ, похожие позиции — всё на существующих компонентах.
- 15 категорий, зеркалящих дерево источника: Тимбилдинг, Эстафеты, Спортивные, Надувные/Мягкие, Азартные, Интерактивные, Настольные, Деревянные, Головоломки, Тиры, Видеоигры, Музыкальные, РУ Модели, Детские, Фото развлечения.
- Пункт «Аттракционы» в шапке и в подвале, с переключателями видимости в админке.
- Полное редактирование в админке: раздел «Аттракционы» рядом с остальными типами каталога (публикация, фото, цены, SEO, порядок, категории).
- Фото и видео скачиваются в наше хранилище — сайт не зависит от play-game.by.

## Импорт данных

Одноразовый скрипт-импортёр (запускается мной в песочнице, результат сохраняется в базу):

1. Обход всех категорий play-game.by, сбор ссылок на карточки.
2. По каждой карточке: название, короткое и полное описание, характеристики (размер, мощность, площадка, возраст и т. п.), цена «от N руб» → `pricing.from` в BYN, фото галереи, видео, SEO-тексты категорий.
3. Медиа скачивается и заливается в bucket `media`, в базу пишутся пути (существующая механика подписанных ссылок уже работает для каталога).
4. Slug генерируется транслитерацией названия; при коллизии — суффикс.
5. Всё создаётся в статусе «опубликовано», после импорта я выгружу таблицу «категория / название / цена / кол-во фото / видео» для вашей проверки.

Позиции, где цена не указана на источнике, получают «Цена по запросу» — как в остальном каталоге.

## Технические детали

- Миграция: таблица `public.attractions` с колонками один-в-один как `zones` (slug, title, category, short_description, description, features, requirements, faq, pricing, photo_urls, video_urls, seo_title, seo_description, published, sort_order, extras, created_at/updated_at) + GRANT'ы (`authenticated`, `service_role`; без `anon` — публичное чтение идёт через серверные функции с `supabaseAdmin`, как для остальных типов), RLS, политики по образцу `zones`, триггер `touch_updated_at`. Категории — строки в `catalog_categories` с `entity_type = 'attractions'`.
- Код: расширить `CatalogType` и `TYPES` в `src/lib/catalog.functions.ts`, `CATALOG_TABLES`/`CATALOG_LABELS` в `src/lib/admin/catalog-types.ts`, `CATALOG_SLUG_ROUTE`/`CATALOG_BASE_ROUTE` в `src/lib/catalog-routes.ts`, добавить запись `/attractions` в `CATALOG_PAGE_CONFIG`.
- Роуты: `src/routes/attractions.tsx` через `catalogListRouteOptions("/attractions")` и `src/routes/attractions.$slug.tsx` через существующую фабрику детальной страницы. Новых карточных компонентов не создаём — переиспользуем `CatalogGrid`/`CatalogDetail`, поэтому визуальная идентичность гарантирована.
- SEO: собственные `head()` с title/description/og на списке и карточке, canonical на себя, ItemList и Product JSON-LD через уже существующие хелперы, новые URL в `public/sitemap.xml`.
- Навигация: ключи `header.nav.attractions` и `footer.catalog.attractions` в `SECTION_REGISTRY`, ссылки в шапке/подвале, хлебные крошки работают автоматически.
- Админка: пункт «Аттракционы» в `AdminSidebar` и в списке типов редактора каталога — редактор общий, отдельного кода почти не потребуется.
- Корзина: лимит количества для аттракционов — по образцу «Зон» (1 шт. за заказ), это соответствует характеру позиций.

## Проверка перед сдачей

- Скриншот-сравнение карточек `/zones` и `/attractions` (Playwright) — стили должны совпадать.
- Прогон по всем импортированным карточкам: нет битых изображений, все видео проигрываются, цены совпадают с источником (выборочная сверка + полная выгрузка для вашей проверки).
- Мобильная/планшетная/десктопная сетка, ленивая загрузка изображений, отсутствие скачков вёрстки.
- Все внутренние ссылки ведут на event-hub.by, ни одной ссылки на play-game.by.
