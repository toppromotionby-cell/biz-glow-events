# Фото в PDF и проверка шрифтов на слайдах

## Что не так сейчас

**Фотографии.** В превью слайда фото видны, а в PDF — нет. Причина найдена: почти все фото каталога — это внешние ссылки на старый сайт event-tech.by (502 ссылки), и 201 из них в формате `.webp`. Сборщик PDF умеет вставлять только JPEG и PNG, поэтому webp-файл молча пропускается и на слайде остаётся пустое место. Браузер webp показывает без проблем — отсюда расхождение превью и PDF.

**Шрифты.** Проверка текста сейчас грубая: считает «много текста» на глаз, по приблизительной длине строки, и не сверяется с реальной шириной символов выбранного шрифта. Из-за этого заголовок может вылезать за край или переноситься некрасиво, а размеры текста на соседних слайдах отличаются без причины.

## Что будет сделано

### 1. Фото со старого сайта в PDF

- Общий модуль загрузки картинок для всех PDF (презентации, КП, договоры).
- Порядок работы: скачали файл → определили формат по сигнатуре → JPEG/PNG вставляем как есть → webp/avif/gif конвертируем в JPEG на лету → вставляем.
- Конвертированные файлы кешируются в нашем хранилище (`media/_pdfcache/<хеш>.jpg`), поэтому повторная сборка PDF того же слайда идёт мгновенно и без обращения к event-tech.by.
- Если фото недоступно или битое — вместо пустоты рисуется аккуратная плашка-заглушка, а в предупреждениях слайда появляется строка «Фото не загрузилось».

### 2. Проверка шрифтов и вмещаемости

- Единый модуль измерения текста по реальным метрикам шрифта — одна и та же математика для превью, PDF и полноэкранного показа. Что видно в превью, то и в PDF.
- Автоподгонка: если текст не влезает в блок, кегль уменьшается по общей шкале (шаг фиксированный, чтобы размеры на слайдах не «плясали»), с нижней границей читаемости. Ниже границы текст не ужимается — вместо этого выдаётся предупреждение.
- Проверки для каждого блока каждого слайда: выход за границы, слишком мелкий кегль, «висячее» слово в последней строке заголовка, разнобой размеров между однотипными блоками разных слайдов, наложение блоков.
- Результат виден в трёх местах: значок-предупреждение на миниатюре слайда, список в разделе «Сверка», и подсветка проблемного блока прямо на холсте при выделении.
- Кнопка «Проверить все слайды» — прогоняет проверку по всей презентации и показывает сводку.

## Технические детали

- `src/lib/documents/image-embed.server.ts` — новый общий загрузчик/конвертер картинок для pdf-lib; используется в `presentations/pdf.server.ts`, `documents/promo-pdf.server.ts`, `documents/pdf.server.ts`.
- Конвертация webp → JPEG выполняется WASM-декодером, пригодным для среды воркера; при сбое декодера срабатывает запасной путь через кеш/заглушку, PDF никогда не падает целиком.
- `src/lib/presentations/text-metrics.ts` — измерение ширины строки по метрикам шрифта и перенос по словам; `fit.ts` и `slide-spec.ts` переводятся на него, чтобы превью и PDF считали одинаково.
- `src/lib/presentations/audit.ts` — правила проверки блоков, возвращают список замечаний с уровнем (ошибка/предупреждение) и ссылкой на слайд и блок.
- Юнит-тесты: конвертация форматов (сигнатуры, отказ), измерение текста, автоподгонка кегля, набор правил проверки.
