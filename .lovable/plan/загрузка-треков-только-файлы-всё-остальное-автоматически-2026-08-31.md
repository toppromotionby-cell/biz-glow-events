# Загрузка треков: только файлы, всё остальное — автоматически

Диалог загрузки перестаёт быть формой. Остаются два элемента: зона выбора файлов (drag&drop, массовый выбор, папки) и сетка превью загружаемых файлов. Все поля — артист, название, версия, жанр, BPM, тональность, год, язык, длительность, раздел, форматы мероприятий, обложка — вычисляются автоматически. Если система не смогла надёжно определить материал, файл молча исключается из очереди и не загружается — без предупреждений и сообщений об ошибке.

## Как это будет выглядеть

```text
┌───────────────────────────────────────────┐
│  Загрузка треков                          │
│  ┌─────────────────────────────────────┐  │
│  │   Перетащите файлы или нажмите      │  │
│  │   MP3 · WAV · FLAC · AIFF · папки   │  │
│  └─────────────────────────────────────┘  │
│  [обложка] Artist — Title (Extended)      │
│            128 BPM · 8A · Свадьба · ✓     │
│  [обложка] Artist — Title                 │
│            анализ… ▓▓▓░░                  │
│                       [Отмена] [Загрузить]│
└───────────────────────────────────────────┘
```

Каждая карточка превью показывает автообложку, распознанные артиста/название, BPM, тональность, раздел и статус (анализ → готово → загружено). Отброшенные файлы просто исчезают из списка.

## Правило автоматического распознавания (роль анализатора)

Новый модуль `src/lib/dj/ingest-role.ts` фиксирует единый контракт разбора, по образцу того, как это делают Beatport/Traxsource-каталоги и DJ-пулы (BPM Supreme, DJcity, Mixo): метаданные берутся из тегов, имя файла используется как резерв, спорные значения отбрасываются, а не угадываются.

Порядок источников для каждого поля:
1. ID3/Vorbis/MP4-теги (`music-metadata`) — приоритет.
2. Имя файла и путь папки (`parseFileName`, шаблон `Artist - Title (Version) [BPM Key]`).
3. Акустический анализ в браузере: длительность из декодера, BPM через onset-детекцию по Web Audio (только когда тег и имя молчат), энергия по RMS.
4. Ничего не найдено → поле остаётся пустым (если оно необязательное) либо файл отбрасывается (если обязательное).

Обязательный минимум для приёма файла:
- расширение из белого списка и читаемый аудиоконтейнер;
- длительность от 5 секунд до 3 часов;
- определены и артист, и название (либо явно распознан «безартистный» материал — джингл/сэмпл/отбивка, тогда артист = `event-hub.by`);
- битрейт не ниже 128 kbps для сжатых форматов;
- определён раздел библиотеки (`guessSection`) с непустой уверенностью.

Всё остальное — жанр, год, язык, тональность, BPM, форматы мероприятий — заполняется, если распозналось, и остаётся пустым, если нет. Файл из-за этого не отбраковывается.

Отбраковка молчаливая: карточка удаляется из очереди, `console` и тосты не задействуются; счётчик «принято N из M» не показывается.

## Дедупликация

Перед загрузкой считается SHA-256 содержимого и нормализованный ключ `artist|title|version` (существующий `src/lib/dj/dedupe.ts`, поля `content_hash`/`dedupe_key` в `dj_tracks`). Дубликат внутри выборки и дубликат в базе снимаются с очереди так же молча. Проверка по базе — новая серверная функция `djCheckDuplicates`, принимающая список хэшей и ключей и возвращающая занятые.

## Обложка

Обложка больше не выбирается вручную. Если во встроенных тегах есть картинка, она проходит через брендирование (`watermark`/`branding`), иначе генерируется автообложка по роли `cover-role.ts` в фирменной янтарной палитре с подписью `event-hub.by`. Загружается вместе с треком.

## Технические детали

- `src/components/dj/UploadTrackDialog.tsx` — переписывается: dropzone + сетка превью + очередь с конкуренцией 2 файла, прогресс на карточку, кнопка «Загрузить» активна только когда есть принятые файлы.
- `src/lib/dj/ingest-role.ts` (новый) — константы правил приёмки, пороги и функция `evaluate(parsed): { accept: boolean; track: SubmitPayload }`.
- `src/lib/dj/analyze.ts` (новый) — браузерный BPM/энергия по Web Audio, выполняется только для файлов без BPM, с ограничением по длине анализируемого окна (60 с) чтобы не вешать вкладку.
- `src/lib/dj/metadata.ts` — используется как есть; добавляется возврат битрейта/уверенности разбора.
- `src/lib/dj/dj.functions.ts` — добавляется `djCheckDuplicates`; `djSubmitTrack` дополняется полями `content_hash`, `dedupe_key`, `energy`.
- `src/lib/dj/moderation.server.ts` — запись хэша и ключа, `onConflict`-защита от гонки при параллельной загрузке.
- Никаких изменений в правах: загрузка по-прежнему только для `isTrusted`, публикация — для менеджеров, остальным `pending`.
