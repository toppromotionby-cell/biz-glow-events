# DJ Hub: яркая витрина в духе MusWizard / Jesse Pool + фирменная генерация обложек

Две части: (1) полностью новый визуал и UX раздела `/dj` — фильтры-блоки, крупные обложки, «вкусный» плеер; (2) единый «арт-директор обложек» — зашитая роль-спецификация, по которой все обложки генерируются автоматически в одном стиле.

---

## Часть 1. Витрина и UX

### 1.1 Домашняя `/dj` — витрина, а не текст
Сейчас это заголовок + список фич. Заменяю на разделы как у пулов:
- Хиро: полноэкранный градиентный слой, «живые» размытые пятна, крупный заголовок, счётчики (треков / новинок за 7 дней / разделов), кнопка «Войти в библиотеку».
- Ленты-карусели с горизонтальной прокруткой: «Новинки», «Топ загрузок», «Высокий рейтинг». Каждая карточка — крупная обложка, кнопка Play по ховеру, бейджи BPM / Camelot / версии.
- Плитки восьми разделов (Музыка, Отбивки, Ведущему, Сэмплы, Входы/выходы, Welcome, Шоу, Софт) — крупные градиентные тайлы с иконкой и счётчиком, клик ведёт в библиотеку с предвыбранным разделом.

### 1.2 Фильтры блоками (главное отличие от текущих селектов)
Новый `TrackFilters`:
- **Строка разделов** — горизонтальный ряд «пилюль» с иконками (Все / Музыка / Отбивки / …), активная подсвечена градиентом.
- **Ряд подкатегорий** — чипы из `dj_categories` внутри выбранного раздела.
- **Быстрые чипы**: Новинки 7 дней, Высокий рейтинг, Избранное, Extended, Clean, Intro, Acapella, Instrumental.
- **Жанры** — чипы с мультивыбором вместо выпадашки.
- **BPM** — двойной слайдер с числовыми полями и пресетами (90–100, 100–110, 120–128, 128–140).
- **Camelot** — сетка-«колесо» 12×2 (1A…12B) с цветовой кодировкой; выбранная тональность подсвечивает совместимые соседние ключи.
- Панель «Фильтры» слева на десктопе (sticky) и в выезжающей шторке на мобильном; сверху — строка активных фильтров с крестиками и «Сбросить всё».

### 1.3 Сетка/список треков
- Переключатель вида: сетка карточек (обложка 1:1, ховер-плей, волновой градиент) и плотный список-таблица (как в пулах: обложка 40px, артист/название, версия, BPM, ключ, длительность, рейтинг, кнопки).
- Карточка: бейджи версии и раздела, звёзды-рейтинг, сердечко, скачивание, индикатор «играет сейчас» с анимированным эквалайзером.
- Скелетоны вместо спиннера, бесконечная подгрузка вместо «Назад/Вперёд».

### 1.4 Плеер
Нижняя закреплённая панель по образцу пулов:
- Обложка + название/артист, кнопки prev/play/next, время, громкость.
- **Waveform-полоса** прогресса: рисую псевдо-волну на canvas по детерминированному сиду трека (реальный анализ файла не нужен, рисунок стабилен для трека) с заливкой прогресса; клик/перетаскивание = перемотка.
- Очередь: кнопка «Очередь» открывает список, drag-free (просто клик = играть), автопереход к следующему, повтор и шаффл.
- Горячие клавиши: пробел — play/pause, стрелки — перемотка ±5 c.
- На мобильном — компактная полоса, разворачивается в полноэкранный вид с большой обложкой.

### 1.5 Стилистика
Всё на существующих токенах дизайн-системы (`--primary`, `--accent`, `glass`, `gradient-text`) — никаких хардкод-цветов. Добавляю в `src/styles.css` несколько токенов/утилит для DJ-раздела: неоновое свечение карточки, анимированный градиентный бордер, эквалайзер-анимация, шумовая текстура. Все анимации уважают `prefers-reduced-motion`.

## Часть 2. Единый арт-директор обложек

Ключевое требование: **обложки всегда свои**, встроенные картинки из ID3 больше не используются как источник. Стиль фиксируется «ролью», зашитой в код, чтобы результат был предсказуемо одинаковым.

### 2.1 Роль (спецификация) — `src/lib/dj/cover-role.ts`
Файл-константа, единственный источник правды. В нём декларативно описано:
- **Идентичность**: сетка 1000×1000, поля, безопасные зоны, положение логотипа `event-hub.by`.
- **Палитры**: закрытый набор из 8 фирменных дуо-градиентов, привязанных к разделу (Музыка — оранжево-малиновый, Отбивки — электрик, Ведущему — изумруд и т.д.), плюс детерминированный сдвиг тона по хэшу «артист+название», чтобы соседние треки не сливались.
- **Типографика**: артист — капс, узкий трекинг, 40px; название — 3 строки максимум с авто-подгонкой; подпись — версия/BPM/ключ моноширинным.
- **Графические слои** (в фиксированном порядке): фон-градиент → геометрический паттерн раздела (волны / концентрические круги / диагональные полосы / точечная сетка / эквалайзер) → зерно-текстура → затемнение снизу → текст → водяной знак.
- **Правила контраста**: автоподбор светлой/тёмной подложки под текст с проверкой WCAG.
- **Версия схемы** `COVER_SPEC_VERSION` — при изменении правил можно перегенерировать старые обложки.

### 2.2 Рендер — `src/lib/dj/artwork.ts` (переписываю под роль)
- `renderCover(spec)` — чистая функция отрисовки по роли, без импровизаций в вызывающем коде.
- Варианты: квадрат для трека, 16:9 для софта и раздела, 1200×630 для OG-картинки.
- Водяной знак `event-hub.by` — обязательный последний слой на каждом изображении (без «звёздочек», как договорились).

### 2.3 Автоматизм
- При загрузке трека обложка генерируется всегда, встроенная ID3-картинка игнорируется (флаг «использовать встроенную» не показываем).
- В админке `/admin/dj/tracks` — кнопки «Перегенерировать обложку» и «Перегенерировать все устаревшие» (те, у кого `cover_spec_version` меньше текущей).
- OG-картинка страницы трека собирается той же ролью.

### 2.4 Схема БД
Одна миграция: в `dj_tracks` добавляю `cover_spec_version int` и `cover_palette text` (какая палитра применена) — чтобы отличать актуальные обложки от старых и повторно воспроизводить результат.

## Технические детали

- Файлы: новые `src/lib/dj/cover-role.ts`, `src/components/dj/CoverArt.tsx`, `src/components/dj/TrackCard.tsx`, `src/components/dj/SectionTiles.tsx`, `src/components/dj/CamelotWheel.tsx`, `src/components/dj/Waveform.tsx`, `src/components/dj/QueuePanel.tsx`; переписываю `TrackFilters.tsx`, `TrackList.tsx`, `player.tsx`, `dj.index.tsx`, `dj.pool.tsx`, `artwork.ts`.
- Серверные фильтры: `library.server.ts` получает поддержку раздела/категории, мультижанра и диапазона BPM; `dj.functions.ts` — расширенная Zod-схема.
- Витрина `/dj` остаётся публичной (SSR + свои мета-теги), библиотека — за `MemberGate` как сейчас.
- Тесты: юнит на детерминированность палитры и ключа дедупликации, снапшот-тест размеров/слоёв обложки, тест логики совместимых Camelot-ключей.

## Что не делаю

- Не возвращаю обсуждения/комментарии — они удалены осознанно.
- Не анализирую реальный звук для waveform (тяжело для браузера при массовой загрузке) — рисую стабильную псевдо-волну по сиду трека.
