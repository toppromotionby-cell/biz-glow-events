# Приказы: шаблоны, мастер создания и журнал по годам

## Что в архиве

89 файлов .docx в трёх журналах: «ПО КАДРОВОМУ СОСТАВУ (К)» — 82 приказа за 2022–2026, «ПО ЛИЧНОМУ СОСТАВУ (Л)» — 7 приказов за 2024–2026, «ОСНОВНЫЕ (без буквы)» — приказы по основной деятельности 2022–2023. Все на едином бланке ООО «ТОП ПРОМОУШН»: шапка → «ПРИКАЗ № …» → город и дата → заголовок «О …» → распорядительное слово (ПРИНЯТЬ / УВОЛИТЬ / ПРЕДОСТАВИТЬ / УСТАНОВИТЬ / КОМАНДИРОВАТЬ / ВВЕСТИ / ПРИКАЗЫВАЮ) → текст → «Основание:» → подпись директора → «С приказом ознакомлен(а)».

## 1. Шаблоны приказов (14 видов)

Кадровые (журнал «К»):
1. О приёме на работу
2. О приёме директора (подписывает председатель общего собрания)
3. Об увольнении (с расчётом компенсации за неиспользованный отпуск)
4. О переводе на другую должность с заключением нового контракта
5. О продлении контракта
6. О заключении нового контракта
7. Об изменении штатного расписания (утверждение новой редакции)
8. О введении новой штатной единицы
9. Об установлении неполного рабочего времени (на месяц, на нескольких работников)
10. О выплате надбавки за сложность и напряжённость (список работников и сумм)
11. О возложении обязанностей на время отпуска директора

Личный состав (журнал «Л»):
12. О предоставлении очередного трудового отпуска
13. О предоставлении отпуска без сохранения зарплаты / за свой счёт
14. О командировании

Основная деятельность (без буквы): универсальный «Приказ по основной деятельности» с готовыми заготовками текста — об утверждении Положений, NDA, Учётной политики, о сроках выплаты ЗП, о назначении ответственного, о нормах топлива, о представительских расходах.

Каждый шаблон — заводской пресет с переменными {{ФИО}}, {{Должность}}, {{Дата}}, {{Срок}}, {{Основание}} и т. д., блоками бланка, подписи и строки ознакомления, ровно по образцам из архива.

## 2. Окно выбора при создании приказа

Кнопка «Создать» в разделе «Приказы» открывает диалог в два шага:

```text
Шаг 1. Журнал:  [Кадровый (К)] [Личный состав (Л)] [Основная деятельность]
Шаг 2. Вид приказа: плитки с названиями и подсказками (фильтр поиском)
Шаг 3. Данные: сотрудник из реестра + поля вида (даты, дни, сумма, основание)
```

Сотрудник выбирается из реестра кадров (ФИО, должность, оклад подставляются сами) либо вводится вручную. Номер приказа предлагается автоматически: следующий свободный в журнале за год (05-к, 02-л, 7) — с возможностью исправить вручную. Дата, город и склонение ФИО подставляются автоматически.

## 3. Журнал приказов: фильтры и отображение

Раздел «Приказы» получает вид журнала регистрации:

- Группировка по годам (2026, 2025, …) со сворачиванием; по умолчанию открыт текущий год.
- Фильтры: журнал (К / Л / основные / все), год, вид приказа, сотрудник, статус, поиск по номеру, заголовку и тексту.
- Таблица: № · дата · вид · заголовок · сотрудник · статус · источник (создан в системе / импортирован) · действия.
- Предупреждение о разрывах и дублях нумерации внутри журнала за год.
- Экспорт журнала за год в Excel.

## 4. Импорт архива (89 приказов)

Загрузка ZIP в разделе «Приказы» → «Импорт архива»: система читает .docx, определяет журнал по папке, год по папке, номер и дату из текста, вид приказа по заголовку, сотрудника сопоставляет с реестром. Текст переносится в блоки документа (редактируется наравне с новыми), оригинал .docx кладётся в приватное хранилище и остаётся доступен кнопкой «Скачать оригинал». Перед записью показывается таблица разбора со строками, где что-то не распозналось, — их можно поправить руками.

## Техническая часть

- `src/lib/paperwork/order-presets.ts` — 14 пресетов + метаданные (журнал, распорядительное слово, набор полей мастера); подключение в `PW_PRESETS`.
- `src/lib/paperwork/orders/registry.ts` — реестр видов: код, название, журнал (`k` | `l` | `main`), поля мастера, генератор заголовка и текста.
- Миграция: колонки `order_journal`, `order_kind`, `order_year`, `employee_id`, `source_file` в `paperwork_documents` (+ индексы `doc_type, order_journal, order_year`), таблица `paperwork_order_counters` для нумерации (уникальность журнал+год+номер), приватный бакет `paperwork-archive` с политиками только для персонала. GRANT для `authenticated`/`service_role` в той же миграции.
- Серверные функции в `src/lib/paperwork.functions.ts`: `nextOrderNumber`, `listOrderJournal` (группировка по годам, фильтры), `importOrdersArchive` (разбор ZIP через `fflate` + чтение `word/document.xml`, загрузка оригиналов в бакет), `exportOrderJournalXlsx` (exceljs).
- UI: `src/components/admin/paperwork/OrderWizardDialog.tsx` (журнал → вид → данные), `OrderJournalView.tsx` (годы, фильтры, таблица), `OrderImportDialog.tsx`; подключение в `src/routes/admin.paperwork.type.$type.tsx` для `docType === "order"`.
- Склонение ФИО и должностей — небольшой хелпер `src/lib/paperwork/orders/morph.ts` (дательный/винительный падеж для «ПРЕДОСТАВИТЬ Иванову Ивану Ивановичу»).
- Тесты: пресеты и обязательные блоки, нумерация по журналам и годам, разбор реальных имён файлов и текстов из архива, генерация текста каждого вида.
