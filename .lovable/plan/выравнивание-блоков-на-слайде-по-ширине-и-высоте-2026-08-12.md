# Выравнивание блоков на слайде — по ширине и высоте

Сейчас у слайда есть только косвенные настройки: зона текста (`textZone` — верх/центр/низ) и доля ширины (`textWidth`), причём менять их можно лишь перетаскиванием в режиме «Правка раскладки». Явных кнопок выравнивания нет, и текстовый блок всегда прижат к левому краю своей колонки.

## Что добавим

Для каждого слайда отдельно (настройки хранятся в `content.layout`, как и остальные зоны):

1. **Выравнивание по горизонтали**: слева / по центру / справа — влияет и на положение текстового блока в свободной области, и на выключку самого текста.
2. **Выравнивание по вертикали**: сверху / по центру / снизу (уже есть в модели, но без явного UI).
3. **Растянуть по ширине** — блок занимает всю доступную ширину (сбрасывает ручное сужение).
4. **Растянуть по высоте** — блок занимает всю доступную высоту от верхнего поля до футера, вертикальное выравнивание при этом отключается.
5. Кнопка «Авто» — возврат к автоматическому поведению для конкретного слайда.

Управление — компактный блок из иконочных кнопок в панели настроек слайда (рядом с настройками фото), плюс сохраняется существующее перетаскивание в режиме «Правка раскладки»: перетаскивание просто выставляет те же значения.

Настройки применяются одинаково в превью, PDF и PPTX — движок раскладки один.

- `src/lib/presentations/model.ts`: добавить в `SlideLayoutOverrides` поля `alignX: "auto" | "left" | "center" | "right"`, `stretchX: boolean`, `stretchY: boolean`; значения по умолчанию — авто/false; расширить `normalizeContent` и проверку «раскладка не тронута».
- `src/lib/presentations/design.ts`: в `slideLayout` сдвигать `textBox` по горизонтали внутри доступной колонки согласно `alignX`; при `stretchX` игнорировать `textWidth`; при `stretchY` фиксировать высоту текстовой области и выравнивание `top`.
- `src/lib/presentations/fit.ts`: пробрасывать горизонтальную выключку в `SlideFit` (новое поле `textAlignX`), учитывать `stretchY` при вертикальном сдвиге.
- Рендеры: `SlideCanvas.tsx` (`text-align`), `pdf.server.ts` (расчёт x для строк при center/right), `pptx.browser.ts` (`align` у текстовых блоков) — используют одно и то же значение из `SlideFit`.
- UI: новый компонент `src/components/admin/presentations/SlideAlignControls.tsx`, подключается в `SlideSettingsPanel.tsx`; патч идёт тем же `setContent({ layout })`, что и остальные правки, поэтому автосохранение и живое превью работают без изменений.
- Тесты: дополнить `src/lib/presentations/__tests__/slide-zones.test.ts` кейсами на `alignX`, `stretchX`, `stretchY` (позиция и ширина `textBox`, отсутствие пересечения с фото).
