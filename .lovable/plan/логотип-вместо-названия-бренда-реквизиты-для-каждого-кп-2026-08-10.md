# Логотип вместо названия бренда + реквизиты для каждого КП

## Что не так сейчас

1. Текстовое название бренда рядом с логотипом скрывается только вручную — отдельным переключателем в настройках логотипа. Если его забыли включить, в шапке одновременно и картинка, и надпись «TOP PROMOTION».
2. Реквизиты для конкретного документа редактируются только в обычном КП (12 полей). В «КП промо» такой возможности нет вообще — там всегда подставляются общие настройки компании.

## Что сделаем

### 1. Бренд показывается только когда нет логотипа

Правило станет автоматическим во всех местах сразу:

- есть логотип → в шапке только логотип (текст бренда не печатается);
- логотипа нет → печатается текстовое название бренда, как раньше.

Работает одинаково в: PDF (КП, КП‑промо, счёт, договор, акт), HTML‑превью КП, HTML‑превью КП‑промо и в интерактивном предпросмотре шапки в админке.

Ручной переключатель «Скрыть название бренда» убираем — он больше не нужен. Вместо него в блоке логотипа появится подсказка: «Пока логотип загружен, текстовое название бренда в шапке не печатается».

Строка под логотипом (юр. название · адрес) остаётся — она несёт реквизиты, а не брендинг.

### 2. Реквизиты редактируются под конкретное КП

- **Обычное КП** — блок реквизитов уже есть; дополняем его недостающим полем «Основание подписи» и делаем понятнее: заголовок «Реквизиты этого КП», плейсхолдеры показывают значения из общих настроек, кнопка «Сбросить к общим настройкам».
- **КП промо** — добавляем такой же блок. Для этого в таблицу промо‑КП добавляется поле для переопределений реквизитов (юр. название, бренд, УНП, адрес, телефон, e‑mail, сайт, банк, БИК, расчётный счёт, подписант, должность, основание).
- Логика единая: пустое поле = берём из общих настроек документов, заполненное = используется только в этом документе.
- Переопределения применяются везде, где документ показывает реквизиты: шапка, подвал PDF, блок «Исполнитель», HTML‑превью и публичная ссылка.
