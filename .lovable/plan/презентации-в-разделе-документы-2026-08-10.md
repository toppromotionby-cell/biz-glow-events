# Презентации в разделе «Документы»

Новый подраздел админки: список презентаций, простой конструктор слайдов, автосборка из КП, экспорт в PDF и PPTX. Существующие КП, КП промо, счета и акты не меняются.

## Экраны

**1. Список — `/admin/documents/presentations`**
Пункт «Презентации» в сайдбаре рядом с «Все документы» (право `documents.manage`).
Таблица: название, компания, связанное КП, кол-во слайдов, статус (черновик / готова / архив), дата изменения, действия (открыть, редактировать, дублировать, удалить с подтверждением, PDF, PPTX).
Над таблицей: поиск по названию, фильтры «Компания», «Связанное КП», «Статус». Пустое состояние — аккуратная заглушка с кнопкой «Создать презентацию».

**2. Диалог создания**
Поля: название, компания (селект существующих компаний), шаблон оформления (Светлый / Тёмный / Акцентный), способ: «Пустая презентация» или «На основании КП». При выборе КП — селект КП, отфильтрованных по выбранной компании.
Пустая → создаются титульный и контактный слайды. Из КП → титульный + по слайду на каждую позицию КП (заголовок, описание, «Что входит» из `includes`, цена, фото из карточки товара по `entity_type`/`entity_id`, если карточка найдена) + контактный слайд.

**3. Редактор — `/admin/documents/presentations/$id`**
Три зоны:
- слева — миниатюры слайдов: drag-and-drop порядок, стрелки вверх/вниз, дублировать, скрыть (глазок), удалить, «+ Добавить слайд» (титульный / товар / текст / разделитель / контакты);
- центр — предпросмотр слайда 16:9 в фирменном стиле, редактирование заголовка и подзаголовка кликом прямо на слайде;
- справа — панель настроек текущего слайда: описание, список «Что входит» (добавить/удалить строку), фото (загрузка / ссылка / замена), цена (показать-скрыть), тумблеры видимости блоков.
Сверху: название, статус, автосохранение с явной кнопкой «Сохранить», кнопки PDF/PPTX, вкладка «Проверка по КП».

**4. Вкладка «Проверка по КП»** (только у презентаций со связанным КП)
Сводный статус: «Полностью синхронизировано» / «Есть позиции из КП без слайдов» / «Есть лишние слайды» / «Есть позиции без фото или описания», плюс три списка: есть, не хватает, лишние.
Действия: «Добавить недостающие позиции», «Обновить данные из КП» (по подтверждению), «Открыть связанное КП». Лишние слайды никогда не удаляются автоматически — только предупреждение.

## Данные

Две новые таблицы (в одной миграции, с GRANT и RLS как у `quote_items`: доступ admin/manager).

`presentations`: id, title, company_id → `company_profiles` (ON DELETE SET NULL), quote_id → `quotes` (ON DELETE SET NULL), status (draft/ready/archived), template, created_by, created_at, updated_at.

`presentation_slides`: id, presentation_id → `presentations` (ON DELETE CASCADE), position, type (title/product/text/section/contacts), title, subtitle, image_url, content_json (описание, «что входит», характеристики, цена, флаги видимости блоков), entity_type + entity_id (карточка товара), quote_item_id, is_visible, created_at, updated_at.

Триггеры `touch_updated_at` на обе таблицы.

## Оформление

Стиль берётся из существующих токенов документов (`src/lib/documents/brand.ts`): фирменный оранжевый `#FF7500`, нейтральная палитра, аккуратные отступы, мягкие тени. Титульный слайд подтягивает из карточки компании логотип, название, сайт, телефон, email, адрес — отсутствующие поля просто не отображаются. Логотип компании — крупно на титульном, компактно в углу на остальных; при отсутствии логотипа место не резервируется.

## Экспорт

- **PDF** — серверная генерация на существующем стеке `pdf-lib` + встроенные шрифты (кириллица уже решена), страницы 16:9 landscape, только видимые слайды, порядок сохраняется. Роут `/admin/documents/presentations/$id/render?format=pdf` по аналогии с КП.
- **PPTX** — генерация в браузере через `pptxgenjs`: упрощённая, но редактируемая вёрстка (фирменный фон, логотип, заголовки, текст, изображения).
- Имя файла: `Prezentatsiya_Nazvanie_2026-06-22.pdf` / `.pptx`.

## Технические детали

- Серверные функции в `src/lib/presentations.functions.ts` (список, создание, создание из КП, сохранение слайдов, дублирование, удаление, сверка с КП) через `createServerFn` + `requireSupabaseAuth`.
- Рендер слайда — один общий компонент `SlideCanvas`, используется и в миниатюрах, и в предпросмотре, и в маршруте печати.
- Новая зависимость: `pptxgenjs` (только клиентский импорт, динамический).
- Переиспользуются `AdminPageHeader`, `AdminTable`, `StatusPill`, `useConfirm`, `CompanySelect`, `UniversalMediaUploader`, `@dnd-kit`.

## Порядок работ

1. Миграция таблиц.
2. Серверные функции + типы.
3. Список, фильтры, диалог создания, дублирование/удаление.
4. Редактор слайдов и рендер слайда.
5. Автосборка из КП и вкладка «Проверка по КП».
6. Экспорт PDF и PPTX.
