# Таблицы КП: авто-ширина колонок, выравнивание, «Цена за единицу»

## Что меняем

1. **Ширина колонок под содержимое**
   Узкие колонки («Ед. изм.», «Кол-во», «Всего», «Цена», «Сумма») получают ширину по самому длинному значению в колонке, а не фиксированный процент. Освободившееся место автоматически уходит в «Наименование» и «Примечания».

2. **Колонка «Примечания» шире**
   Минимальная доля «Примечаний» увеличивается (с ~18–27% до ~30–34% в зависимости от набора колонок) плюс она первой забирает свободное место после авто-подгонки.

3. **Выравнивание**
   - По вертикали — по центру во всех ячейках таблицы (сейчас `vertical-align: top`), кроме строк с длинным перечнем «что входит», где верх остаётся уместным — там тоже переводим на центр для единообразия.
   - Все числовые колонки (Кол-во, Всего, Цена, Сумма) — по центру. Сейчас «Цена» и «Сумма» выровнены вправо.
   - Текстовые колонки («Наименование», «Примечания») остаются слева.

4. **Заголовок цены**
   Везде «Цена за единицу» вместо «Цена за час» / «Цена за ед.» / «Цена» — заголовок перестаёт зависеть от единицы позиции.

## Где именно

- `src/lib/documents/doc-layout.ts` — общий движок колонок: подпись `price`, выравнивание `center` для price/amount, расчёт ширины по контенту вместо `BASE_WIDTH`, увеличенный минимум для `note`.
- `src/lib/documents/promo-quote-html.ts` — превью КП: CSS `vertical-align: middle`, `.c-money { text-align:center }`, ширины из авто-расчёта, `Цена за единицу`.
- `src/lib/documents/pdf.server.ts` — колонки PDF: авто-ширины по замеренной ширине текста (`widthOfTextAtSize`), вертикальное центрирование в `drawTable`, `align: "center"` для price/sum, заголовок «Цена за единицу».
- `src/lib/documents/promo-xlsx.browser.ts` — ширины столбцов по контенту, `alignment: { vertical: "middle", horizontal: "center" }` для числовых, шире «Примечания», новый заголовок.
- `src/lib/documents/promo-gdocs.server.ts` и `src/lib/promo-sheets.server.ts` — те же заголовок/ширины/выравнивание, чтобы синхронизация и обратное чтение не сломались (сопоставление колонок остаётся позиционным).
- `src/lib/documents/quote-html.ts` / `quote-xlsx.browser.ts` — обычное КП приводим к тем же правилам выравнивания и подписи цены.

## Технические детали

- Авто-ширина: для каждой колонки считаем максимум длины отрендеренной строки (в PDF — реальная ширина в пунктах для выбранного шрифта и кегля, в HTML/Excel — оценка по символам), добавляем паддинг, ограничиваем минимумом/максимумом. Сумма узких колонок вычитается из ширины таблицы, остаток делится между «Наименование» и «Примечания» в пропорции ~45/55.
- В HTML используем `table-layout: fixed` с рассчитанными процентами, чтобы превью и PDF совпадали.
- Объединённые ячейки «услуга» (colspan) учитываются: они не влияют на расчёт ширины колонок «Кол-во»/«Ед. изм.».
- Проверка: юнит-тесты PDF/XLSX прогоняем повторно, плюс визуальная проверка превью КП с включёнными и выключенными колонками.
