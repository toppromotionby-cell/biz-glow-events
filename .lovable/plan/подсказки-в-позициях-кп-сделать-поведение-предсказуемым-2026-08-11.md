# Подсказки в позициях КП: сделать поведение предсказуемым

## Что происходит сейчас

В полях «Наименование» (КП и промо-КП) работает компонент подсказок из базы знаний. Он всплывает в моменты, которые с точки зрения пользователя выглядят случайными:

1. **Список зависит от нестабильных функций.** В `QuoteItemsPanel` и `PromoItemsTable` загрузчик и подпись передаются как новые функции при каждой перерисовке таблицы (`fetcher={(term) => fetchItems(term, section)}`, `labelOf={(h) => h.title}`). Эффект подсказок подписан на них, поэтому перезапускается при любой перерисовке — правка соседней строки, пересчёт итогов, автосохранение. Отложенный запрос при этом стартует заново, и выпадашка может появиться позже действия, которое её вызвало.
2. **Скрывается только один дословный дубль.** Проверка «уже точно совпадает» срабатывает лишь когда в ответе ровно одна подсказка. Если совпадений несколько (как на скриншоте — «Шатер "Звезда"» уже введён полностью), список всё равно открывается и перекрывает строку описания.
3. **Флаг «пользователь печатает» сбрасывается только по blur/выбору.** Пока фокус в поле, любой внешний перерисовыв может открыть список, даже если пользователь уже ничего не вводит.
4. **Список не закрывается при прокрутке и изменении размера**, поэтому «висит» поверх соседних строк.

## Что сделаем

**Один явный сценарий:** подсказки появляются только тогда, когда пользователь действительно печатает в этом поле, и исчезают во всех остальных случаях.

- Открывать список только после ввода **от 3 символов** и только если с момента последнего нажатия клавиши прошла пауза; программные подстановки (выбор из библиотеки, импорт, автозаполнение) подсказки не открывают.
- Не показывать список, если **любая** подсказка дословно совпадает с введённым текстом — предлагать нечего.
- Закрывать список при прокрутке контейнера, изменении размера окна, `Escape`, потере фокуса и после выбора; повторно открыть можно только новым вводом.
- Ограничить высоту списком из 5 позиций и не перекрывать соседнюю строку сильнее необходимого.
- Убрать «случайные» перезапуски: загрузчик и подпись держать в ref, эффект подсказок реагировать только на введённый текст.
- Дать явный ручной вызов: `Ctrl/Cmd + Space` в поле открывает подсказки по текущему тексту — если человек хочет посмотреть варианты сам.

## Технические детали

- `src/components/admin/SuggestInput.tsx` — переписать логику открытия: `MIN_TERM = 3`, `fetcher`/`labelOf` через `useRef`, эффект с зависимостью только от `value`, отдельный флаг `armed` (взводится в `onChange`, снимается при выборе, blur, `Escape`, прокрутке), проверка `hits.some(exact)`, слушатели `scroll` (capture) и `resize`, обработчик `Ctrl/Cmd+Space`.
- `src/components/admin/quotes/QuoteItemsPanel.tsx` и `src/components/admin/promo/PromoItemsTable.tsx` — передавать стабильные колбэки (`useCallback`, ключ по секции) вместо инлайновых стрелок.
- Тестов на UI не добавляем; проверю поведение на превью редактора КП.
