# Убрать «Краткое описание» из карточек и каталога

Поле «Краткое описание» перестаёт существовать: в админке блок удаляется, а везде, где на сайте показывался этот текст, показывается текст из основного «Описания» (аккуратно сокращённый до нужной длины). Данные из колонки удаляются из базы.

## Проверено перед планом

- Колонка `short_description` есть в 5 таблицах каталога: `zones` (117), `services` (4), `tech_equipment` (35), `production_items` (4), `attractions` (407).
- Во всех строках, где заполнено краткое описание, заполнено и полное описание — то есть при переходе на «Описание» ни одна карточка не останется без текста.
- В коде уже есть готовая функция сокращения текста `toCardExcerpt` (`src/lib/rich-text.ts`): она чистит HTML, берёт первый содержательный абзац и обрезает по границе слова.

## Что меняется на сайте

1. Карточки каталога и «Наши рекомендации» на главной — под заголовком остаётся тот же по размеру блок текста, но берётся из «Описания».
2. Быстрый просмотр («Подробнее») и страница позиции — короткая строка под заголовком берётся из «Описания». Если она полностью повторяет начало основного описания ниже, строка не дублируется — показывается только основной текст.
3. Поиск по сайту — сниппет результата строится из «Описания».
4. Мета-теги (og:description, description) — из «Описания».
5. Презентации и подбор позиций в КП — описание позиции берётся из «Описания».
6. Админка → Каталог: поле «Краткое описание» из формы удаляется; проверка «нет описания» опирается только на «Описание».

## Сохранность вёрстки

Блок текста в карточке сейчас имеет фиксированную минимальную высоту и обрезку в 2–3 строки — эти правила остаются без изменений, меняется только источник текста, поэтому сетка карточек не «поедет». После правок проверяются в браузере: главная, каталог (все разделы), карточка позиции, модальное окно «Подробнее», поиск — на десктопе и мобильном.

## Технические детали

- `src/lib/rich-text.ts`: `toCardExcerpt` упрощается до одного аргумента (описание).
- Обновляются: `src/lib/catalog-adapter.ts`, `src/lib/home.functions.ts`, `src/lib/catalog.functions.ts` (SELECT), `src/lib/search.functions.ts`, `src/lib/catalog-slug-route.tsx`, `src/lib/catalog-page-config.ts`, `src/lib/presentations.functions.ts`, `src/lib/quotes.functions.ts`.
- Компоненты: `FeaturedCard.tsx`, `CatalogQuickView.tsx`, `CatalogDetail.tsx`, `admin/catalog/CatalogEditor.tsx`, `admin/catalog/shared.ts`, `routes/admin.catalog.$type.tsx` (поиск в админке).
- Миграция: `ALTER TABLE ... DROP COLUMN short_description` для `zones`, `services`, `tech_equipment`, `production_items`, `attractions`; после неё регенерируются типы Supabase.
- Порядок: сначала перевод кода на `description`, затем миграция — чтобы не было момента, когда код обращается к несуществующей колонке.
- Финальная проверка: типизация проекта и прогон страниц каталога/главной в браузере.
