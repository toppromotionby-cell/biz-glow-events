# Договор займа: четыре шаблона и выбор займодавца при создании

Сейчас вид документа «Договор займа» существует, но встроенных шаблонов под него нет (в каталоге заводских шаблонов нет ни одного пресета типа `loan`), поэтому создаётся пустой документ. Добавим четыре шаблона по присланным референсам и шаг «Кто выдаёт заём?» при создании.

## Четыре шаблона (по референсам)

| Шаблон | Займодавец | Заёмщик | Особенности текста |
|---|---|---|---|
| Заём от Кузнецова Д. В. (физлицо) | гражданин Кузнецов Д. В., паспорт/ид. номер/прописка | ООО «Топ промоушн» в лице зам. директора по генеральной доверенности | реквизиты займодавца — паспортные |
| Заём от Трубиной П. Е. (физлицо) | гражданка Трубина П. Е., ид. карта/ид. номер/адрес регистрации | ООО «Топ промоушн» в лице директора на основании Устава | подписант — директор |
| Заём от ИП Кузнецов | ИП Кузнецов Д. В., свидетельство о госрегистрации №192140518 | ООО «Топ промоушн» по генеральной доверенности | реквизиты ИП |
| Заём от ООО «Топ промоушн» | ООО «Топ промоушн» | ИП Кузнецов Д. В. | обратное направление: компания выдаёт заём |

Структура во всех одинаковая и повторяет оригиналы: заголовок «ДОГОВОР ДЕНЕЖНОГО ЗАЙМА № {{Номер документа}}», строка «г. Минск «{{Дата}}»», преамбула сторон, разделы 1–7 (предмет, порядок предоставления, порядок возврата, ответственность, разрешение споров, прочие условия, срок действия), блок «Юридические адреса и банковские реквизиты сторон» (две колонки) и подписи.

Переменные, которые заполняются в панели полей документа: `{{Номер документа}}`, `{{Дата договора}}`, `{{Сумма займа}}`, `{{Сумма прописью}}`, `{{Срок возврата}}`, `{{Пеня, %}}`. Реквизиты сторон в шаблонах уже заполнены по референсам, но остаются редактируемыми.

## Диалог при создании

На странице «Договор займа» кнопка «Создать документ» открывает окно **«Кто выдаёт заём?»** с четырьмя карточками:
- Кузнецов Д. В. (физическое лицо)
- Трубина П. Е. (физическое лицо)
- ИП Кузнецов Д. В.
- ООО «Топ промоушн»

Выбор сразу создаёт документ из соответствующего шаблона и открывает редактор. Ниже — ссылка «Пустой договор» для нестандартного случая. Тот же диалог используется при создании из общего хаба документов.

## Техническая часть

- `src/lib/paperwork/preset-templates.ts` — четыре новых пресета `loan-kuznetsov-person`, `loan-trubina-person`, `loan-ip-kuznetsov`, `loan-company-lender` с `doc_type: "loan"`, категорией `contracts`, блоками heading / paragraph / list / parties / signature. Тексты переносятся из DOCX-референсов дословно, с подстановкой плейсхолдеров вместо конкретных сумм и дат.
- Новый компонент `src/components/admin/paperwork/LoanLenderDialog.tsx` — выбор займодавца; сопоставление «вариант → id пресета» держим рядом с пресетами (`LOAN_LENDERS`), чтобы список был единым источником.
- `src/routes/admin.paperwork.type.$type.tsx` — для `docType === "loan"` кнопка «Создать документ» открывает диалог, а не создаёт пустой документ; создание идёт через существующий `createDocumentFromTemplate` по найденному шаблону (доустановка встроенных пресетов уже работает при входе в каталог шаблонов — добавим её и на этот маршрут, чтобы шаблоны займа гарантированно существовали).
- Тесты: проверка, что для каждого варианта займодавца находится пресет и его блоки проходят нормализацию/валидацию обязательных блоков вида `loan`.

## Отмечу

Реквизиты в шаблонах жёстко берутся из присланных договоров (паспортные данные, УНП, р/с). Если какие-то данные устарели — их можно поправить прямо в шаблоне, изменения применятся ко всем новым договорам.
