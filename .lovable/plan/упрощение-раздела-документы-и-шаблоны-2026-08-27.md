# Упрощение раздела «Документы и шаблоны»

Сейчас раздел перегружен: две вкладки-каталога на входе, кнопка «Установить встроенные шаблоны», а в редакторе — панель с 4 вкладками (Содержание / Переменные / Бланк / AI и импорт), над ней ещё 6 полей шапки и 3 кнопки. Пользователь вынужден сам решать, где что настраивать, вместо того чтобы просто сделать документ.

Цель: один понятный путь «выбрал что делаю → отредактировал → скачал», как в КП.

## Что меняется

### 1. Вход в раздел — один экран без вкладок
- Сверху ряд крупных плиток «Что создаём»: Письмо, Приказ, Доверенность, Справка, Уведомление, Служебная записка, Договор, Счёт, Акт, Произвольный. Клик — сразу создаёт документ нужного вида и открывает редактор (шаблон и стартовые блоки подставляются из реестра видов).
- Ниже — единая таблица «Мои документы» с поиском и фильтром статуса (как сейчас).
- Каталог шаблонов уезжает на отдельную страницу `/admin/paperwork/templates` (ссылка «Шаблоны» в шапке раздела). Встроенные шаблоны ставятся автоматически при первом открытии раздела — кнопки «Установить встроенные шаблоны» больше нет.

### 2. Редактор — две зоны вместо четырёх вкладок
- Слева: содержание документа (блоки) — единственная постоянная рабочая область.
- Справа: живое A4-превью (без изменений).
- Всё остальное убирается в компактную верхнюю строку и выдвижные панели:
  - Шапка: название документа + статус + кнопки «Сохранить», «PDF», «DOCX». Остальные поля (номер, дата, тип, компания) — в свёрнутом блоке «Реквизиты документа», раскрывается по клику.
  - «Переменные» — не вкладка, а панель, которая появляется под блоками только когда переменные реально есть, с счётчиком незаполненных.
  - «Бланк» и «AI/импорт» — кнопки в шапке, открывают боковую панель (Sheet) поверх, не отбирая место у редактора.

### 3. Блоки — короче и понятнее
- Кнопки добавления блоков группируются: Текст (заголовок, абзац, список, примечание), Таблицы (таблица, позиции с суммами), Реквизиты (адресат, стороны, подпись, отступ). Вместо длинного ряда — компактное меню «Добавить блок».
- Для каждого вида документа предлагаются только релевантные блоки, остальные — в «Ещё».
- Незаполненные обязательные блоки вида подсвечиваются одной строкой-подсказкой сверху, без отдельного модуля проверок.

### 4. Единый стиль с остальной админкой
- Шапка через `AdminPageHeader`, состояния списка через `StateViews`, статусы через `StatusPill`, подтверждения через `ConfirmDialog` — как в КП и презентациях.
- Терминология выравнивается: «Документ», «Вид документа», «Бланк компании», «Поля документа».

## Техническая часть

- `src/routes/admin.paperwork.index.tsx` — убрать `Tabs`, добавить плитки создания по `PW_KIND_LIST` из `src/lib/paperwork/kinds.ts`, оставить таблицу документов.
- Новый `src/routes/admin.paperwork.templates.tsx` — каталог шаблонов (переносится текущий контент вкладки).
- `installPaperworkPresets` вызывается автоматически в лоадере списка шаблонов, если у пользователя нет ни одного шаблона.
- `PaperworkEditor.tsx` — убрать `Tabs`; добавить `Collapsible` «Реквизиты документа», `Sheet` для `PwBlankPanel` и `PwAiPanel`, панель переменных рендерить условно.
- `PwBlockList.tsx` — заменить ряд кнопок на `DropdownMenu` с группами, фильтрация предложений по `pwKind(docType).starterBlocks` + «Ещё».
- Модель, переменные, PDF/DOCX-экспорт не трогаем — меняется только слой представления.

## Отмечу
Функционал никуда не пропадает — бланк, AI, импорт и переменные остаются, просто перестают занимать место по умолчанию и открываются по требованию.
