# Аудит и доработка раздела «Презентации»

## Что проверено

Список презентаций, редактор слайдов (миниатюры, канвас, настройки, сверка с КП), диалог создания, серверные функции CRUD, маршрут выгрузки PDF, экспорт PPTX.

Основные потоки работают: создание с нуля и из КП, открытие, правка, добавление/дублирование/удаление/перемещение слайдов, сохранение, удаление и дублирование презентации, экспорт PDF и PPTX. Ломать их не нужно — доработки точечные.

## Найденные проблемы

### P0 — критично

1. **Ошибка загрузки = вечное «Загрузка…»**. Редактор (`/admin/documents/presentations/$id`) при сбое запроса или несуществующем id показывает бесконечный текст загрузки: проверяется только `isLoading || !meta`. Ни ошибки, ни кнопки «Повторить», ни возврата к списку. Ожидается: экран ошибки с текстом, «Повторить» и «К списку»; для отсутствующей презентации — «не найдена».
2. **Потеря несохранённых правок**. Правки живут в локальном состоянии; уход со страницы, обновление вкладки или клик по «Назад» стирают их молча. Ожидается: предупреждение при уходе (браузерное + подтверждение при внутренней навигации), пока `dirty`.
3. **Удаление слайда без подтверждения**. Крошечная иконка корзины в миниатюре удаляет слайд мгновенно, отмены нет. Ожидается: подтверждение (для непустого слайда) и тост с «Вернуть».

### P1 — неудобно/нестабильно

4. **Список: нет состояния ошибки и «ничего не найдено»**. При сбое загрузки показывается «Презентаций пока нет», как будто данных нет. Пустой поиск неотличим от пустого раздела. Нет кнопки «Повторить».
5. **Поиск дёргает сервер на каждый символ** — `queryKey` включает `search` без задержки. Нужен дебаунс и кнопка очистки.
6. **Пустой раздел без призыва к действию** — нет кнопки «Создать первую презентацию».
7. **Нет переименования из списка** — только вход в редактор. Нужен пункт «Переименовать» в меню действий.
8. **Нет сортировки** (по обновлению/названию/дате создания) и счётчик в шапке показывает число загруженных строк, а не всего.
9. **Действия слайда невидимы без мыши** — `opacity-0 group-hover`, недоступны с клавиатуры и на тач-устройствах, у кнопок нет доступных подписей. Нужны видимость при фокусе, `aria-label`, доступность на мобильном.
10. **Нет полноэкранного просмотра** — посмотреть презентацию слайд за слайдом нельзя, только выгрузить PDF.
11. **Редактор не адаптивен** — жёсткая сетка из трёх колонок с `max-h-[70vh]` разваливается на планшете и мобильном; настройки слайда уезжают вниз, миниатюры занимают весь экран.
12. **Нет автосохранения и горячих клавиш** — Ctrl/Cmd+S не работает, переключение слайдов стрелками нет, статус сохранения виден только как строчка «есть несохранённые правки».
13. **Нет индикатора «Слайд N из M»** у крупного канваса, номер виден только в подписи миниатюры.

### P2 — мелочи

14. Порядок слайдов меняется только стрелками по одному шагу — нет перетаскивания.
15. В списке нет миниатюры первого слайда — карточки одинаковые на вид.
16. Нет переключателя «таблица/плитка» для списка.
17. Скрытый слайд (`is_visible=false`) виден только по прозрачности, без явной подписи «скрыт».
18. Диалог создания: при выборе режима «из КП» без выбранного КП кнопка активна, валидации нет.

## Что будет сделано

### Этап 1. Надёжность (P0)

- Экран ошибки и «не найдено» в редакторе и в маршрутах (`errorComponent`, `notFoundComponent`) с кнопками «Повторить» и «К списку»; скелетон вместо текста «Загрузка…».
- Защита от потери правок: `beforeunload` и блокировка внутренней навигации, пока есть несохранённые изменения, с диалогом «Сохранить / Уйти без сохранения / Отмена».
- Подтверждение удаления слайда + тост с возможностью вернуть удалённый слайд.

### Этап 2. Список презентаций (P1)

- Состояния: скелетоны, ошибка с «Повторить», пустой раздел с кнопкой «Создать первую», «Ничего не найдено» с очисткой поиска.
- Дебаунс поиска (300 мс) и крестик очистки.
- Сортировка: по дате обновления, названию, дате создания.
- Пункт «Переименовать» (модалка с валидацией) и «Открыть» в меню действий; действия видимы на мобильном.
- Переключатель «Таблица / Плитка»; в плитке — миниатюра первого слайда, название, компания, число слайдов, дата обновления, меню действий.

### Этап 3. Редактор (P1 + практичные фичи)

- Адаптивная раскладка: на десктопе три колонки, на планшете — миниатюры лентой сверху, на мобильном — вкладки «Слайд / Настройки» и горизонтальная лента миниатюр.
- Панель миниатюр: действия видимы при наведении **и** фокусе, доступные подписи, перетаскивание для смены порядка (мышь + клавиатура-стрелки как запасной путь).
- Индикатор «Слайд N из M» и статус сохранения («Сохранено · время» / «Есть изменения» / «Сохраняем…»).
- Автосохранение с задержкой (например, 3 с бездействия) + кнопка «Сохранить» остаётся; во время сохранения кнопки экспорта блокируются.
- Горячие клавиши: Ctrl/Cmd+S — сохранить, стрелки вверх/вниз в панели миниатюр — переключение слайда, Delete — удалить выбранный слайд (с подтверждением). Ввод текста не перехватывается.
- Полноэкранный просмотр: слайд 16:9 на весь экран, переключение стрелками/кликом, Esc — выход, счётчик слайдов; скрытые слайды пропускаются.
- Явная метка «Скрыт» на скрытых слайдах и подсказка-заглушка на пустом слайде.

### Этап 4. Качество UX

- Валидация в диалоге создания (режим «из КП» требует выбранного КП, название обрезается по длине), понятные состояния «недоступно» вместо неработающих кнопок.
- Видимые состояния фокуса, доступ с клавиатуры к действиям слайдов и меню, контроль контраста подписей.
- Проверка отсутствия ошибок в консоли на всех экранах раздела.

## Технические детали

- Изменяются только файлы раздела: `src/routes/admin.documents.presentations.index.tsx`, `src/routes/admin.documents.presentations.$id.index.tsx`, компоненты в `src/components/admin/presentations/` плюс новые небольшие компоненты (`PresentationCardGrid`, `SlideThumbRail`, `PresentationFullscreen`, `RenamePresentationDialog`).
- Серверные функции переиспользуются как есть; добавляется только параметр сортировки в `listPresentations` и, при необходимости, обновление названия через существующий `savePresentation`.
- Никаких новых тяжёлых зависимостей: перетаскивание — на нативных HTML5 drag-событиях, полноэкранный режим — на существующем `Dialog` и `SlideCanvas`.
- Схема БД не меняется. Существующие подтверждения (`useConfirm`), тосты (`sonner`) и дизайн-система остаются.

## Предположения

- Автосохранение включается по умолчанию, кнопка «Сохранить» сохраняется для явного сохранения.
- «Избранное» для презентаций не добавляем — вместо него используются существующие статусы (Черновики / Готовые / Архив).
- Полноэкранный просмотр — внутри админки, публичной ссылки на презентацию не создаём.
