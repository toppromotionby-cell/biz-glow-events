# Планер и ассистент: новый вид, Google Tasks и «умные» фичи

## Что сейчас

- `/admin/planner` — 925 строк в одном файле: карточки, вкладки, календарь, настройки, аналитика свалены вместе, вёрстка не в стилистике админки (нет единой сетки, плотности, статусных цветов как в заказах/КП).
- Разделения «задача vs событие» на уровне Google нет: всё уходит в Google Календарь. Поле `google_task_id` в базе есть, но ни одной строки кода Google Tasks нет.
- Проверил шлюз: запрос к Google Tasks API проходит маршрутизацию, но возвращает 403 «insufficient authentication scopes» — то есть техническая дорога есть, не хватает только разрешения `tasks` у подключённого Google-аккаунта.
- Направления (Личное / BeLight / EventHub / Top Promotion) живут в таблице `calendar_directions` и уже используются в календаре — их же используем как списки задач.

## Что делаем

### 1. Планер в стилистике сайта
Разбиваем страницу на компоненты (`src/components/admin/planner/*`) и собираем как остальные разделы админки:
- Единая шапка `AdminPageHeader` с быстрыми действиями и поиском.
- Верхняя полоса «Сегодня»: сколько дел, сколько жёстких, что просрочено, что дальше по времени.
- Основная область: слева список (Сегодня / Неделя / Просрочено / Без даты), справа календарь; переключение «Список ↔ Календарь ↔ Доска» одной кнопкой.
- Доска (kanban) по статусам с перетаскиванием.
- Цвета и типографика — только токены дизайн-системы, направления — цветные точки, «жёсткие» дела — отдельная рамка.
- Мобильный вид: одна колонка, крупные кнопки «Сделано / Перенести / +1 час».
- Быстрое добавление одной строкой: «завтра в 15 встреча с подрядчиком #EventHub !важно» — разбирается на лету с предпросмотром до сохранения.

### 2. Google Tasks и раздельная маршрутизация
- **Разрешение**: сначала переподключаем существующий Google-коннектор с областью Tasks; если стандартный коннектор её не отдаёт — заводим свой Google OAuth-клиент (одно разовое подтверждение вашим аккаунтом) со scope `tasks` + `calendar`. Без этого шага Tasks физически недоступны — это первый пункт работ.
- **Правило маршрутизации**: встречи и всё, что имеет конкретное время начала и конца, → Google Календарь. Задачи (дела с дедлайном или вовсе без времени) → Google Tasks. Пограничные случаи (задача с жёстким временем) — по вашему выбору в настройках: «в календарь», «в задачи» или «в оба».
- **Списки по направлениям**: в Google Tasks создаём и поддерживаем четыре списка — Личное, BeLight, EventHub, Top Promotion. Ассистент перед записью определяет направление (по ключевым словам, словарю памяти и явному указанию) и кладёт задачу в соответствующий список; если не уверен — спрашивает одной строкой с кнопками.
- **Двусторонняя синхронизация**: задачи, созданные в Google Tasks с телефона, подтягиваются в планер (название, заметка, дедлайн, отметка «сделано»), удаление и выполнение синхронизируются в обе стороны, конфликт решается по времени изменения.
- **Выдача информации**: «что у меня в задачах по EventHub», «покажи просроченные задачи», «что в личном на неделю» — ответ сгруппирован по спискам/направлениям и по срокам, с кнопками действий, а не сплошным текстом.

### 3. Разведка лучших практик и наполнение фичами
Отдельным этапом изучаем, как сделаны Todoist, TickTick, Motion, Sunsama, Reclaim, Akiflow, Google Calendar/Tasks, и переносим то, что реально полезно. Кандидаты (финальный список после разведки):
- Естественный ввод дат и повторов («каждый вторник», «через 3 дня»).
- Приоритеты P1–P4, теги/метки, подзадачи и чек-листы.
- Повторяющиеся дела с гибкими правилами и «перенос всей серии».
- Автопланирование: свободные слоты в расписании под задачи с учётом рабочих часов направления.
- Time-blocking: перетащил задачу в календарь — получил событие.
- Разбор «Входящих» (то, что бот не понял) в один клик.
- Умные списки/фильтры и сохранённые виды.
- Быстрые действия с клавиатуры (⌘K, «t» — сегодня, «e» — редактировать).
- Оффлайн-устойчивость: отправленное в бот не теряется даже при сбое модели.
- Аналитика: выполнено/перенесено, загрузка по направлениям, «долги».

### 4. Ассистент умнее и быстрее
- Мгновенный ответ на частые команды без обращения к модели (сегодня, завтра, неделя, сделано, перенеси) — ощутимо быстрее.
- Расширенный набор инструментов: задачи Google Tasks, подзадачи, повторы, поиск слотов, массовые операции («перенеси всё с пятницы на понедельник»).
- Понимание с полуслова через словарь и привычки (уже есть память — дополняем правилами по направлениям и типовым длительностям).
- Ответы: краткое подтверждение + карточка с кнопками; списки — с группировкой и итогом дня; картинки-таймлайны остаются как есть.
- Понятная справка: команда «что ты умеешь» и раздел «Как пользоваться» в админке с примерами фраз.

### 5. Багфиксы и скорость
- Профилируем загрузку планера: один запрос на диапазон вместо нескольких, кеш по неделям, оптимистичные обновления при переносе/отметке.
- Чиним найденные при переработке проблемы синхронизации (дубли при повторной синхронизации, потеря часового пояса, «зависшие» токены синхронизации).
- Регрессионные тесты: маршрутизация задача/встреча, синхронизация Tasks в обе стороны, разбор фраз, рендер ответов.

## Технические детали

- Миграция: в `calendar_directions` — `google_tasklist_id`; в `calendar_items` — `priority`, `parent_id`, `recurrence`, `tags`, `google_tasks_etag`; в `assistant_prefs` — правило маршрутизации и настройки автопланирования. Для всех таблиц сохраняем текущие RLS и GRANT (доступ только через `service_role`/серверные функции).
- Новый модуль `src/lib/calendar/gtasks.server.ts` — обёртка над Tasks API через шлюз коннектора (`/tasks/v1/...`), плюс `sync-tasks.server.ts` с инкрементальной синхронизацией и разрешением конфликтов.
- `store.server.ts` получает единый `routeTarget(item, prefs)` — одна точка решения «календарь / задачи / оба», её же вызывают бот, Алиса и админка.
- UI разбивается на `PlannerHeader`, `PlannerList`, `PlannerBoard`, `PlannerCalendar`, `PlannerSettings`, `QuickAdd`; страница-маршрут остаётся тонкой.
- Разведка реализаций — отдельной фоновой задачей, результат сводим в короткий список фич до кодирования интерфейса.

## Порядок работ

1. Разрешение Google Tasks (переподключение коннектора либо свой OAuth-клиент) и проверка доступа.
2. Разведка лучших планеров, финальный список фич.
3. Миграция базы и слой Google Tasks + маршрутизация задача/встреча по направлениям.
4. Двусторонняя синхронизация Tasks и выдача информации по спискам.
5. Полная переработка интерфейса планера в стилистике админки (список/календарь/доска, быстрый ввод).
6. Расширение ассистента: инструменты, скорость, справка, ответы с кнопками.
7. Багфиксы, оптимизация, тесты и проверка в реальном боте.
