# Убрать кнопку «Админка» из хедера

## Цель
Убрать ссылку/кнопку перехода в админ-панель из шапки сайта (десктоп и мобильная версии), сохранив доступ к `/admin` через прямую ссылку.

## Что меняем
- `src/components/SiteChrome.tsx`

## Шаги
1. Удалить блок кнопки «Админка» в десктопных действиях (условие `isStaff && ...` рядом с кнопкой «Кабинет»).
2. Удалить блок кнопки «Админ-панель» в мобильном меню (условие `isStaff && ...` в нижней части шторки).
3. Убрать неиспользуемые импорты: `ShieldCheck` из `lucide-react` и `useRoles` из `@/hooks/use-roles`, если после удаления они больше не нужны.
4. Проверить, что `isAuthenticated` и остальные элементы шапки работают без изменений.
5. Запустить типизацию/сборку, чтобы убедиться, что не осталось неиспользуемых переменных или импортов.

## Ожидаемый результат
- В шапке больше не отображается кнопка «Админка» / «Админ-панель» ни на десктопе, ни в мобильном меню.
- Пользователь по-прежнему может зайти в админку по прямому URL `/admin`.
