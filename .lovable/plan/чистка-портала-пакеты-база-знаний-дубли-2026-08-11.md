## 2. База знаний — только админка

Сейчас сигналы из документов подмешиваются в публичный калькулятор.

- Публичный калькулятор и любые публичные подсказки перестают обращаться к базе знаний и к «популярности из документов»: остаются только данные каталога (разделы, услуги, техника, продакшн) и спрос по реальным запросам с сайта.
- Все функции базы знаний (поиск позиций, контактов, текстовых блоков, шаблонов) вызываются только из админских экранов конструкторов КП/Промо/Презентаций.
- Серверные функции базы знаний закрываются проверкой прав: доступ только сотрудникам с правом работы с документами, не анонимным посетителям.

## 3. База знаний хранит только часто используемое

Добавляем автоматическую гигиену вместо ручной чистки:

- Для каждой записи учитывается счётчик использований и дата последнего использования (уже частично есть).
- Правило хранения: запись остаётся, если использовалась 2+ раза ИЛИ применялась за последние 6 месяцев. Всё остальное считается мусором.
- Автоочистка: при сохранении документа и по расписанию (раз в сутки) удаляются записи, не прошедшие правило, а дубли сливаются в одну запись с суммарным счётчиком.
- В разделе «База знаний» — панель состояния: сколько записей, сколько кандидатов на удаление, кнопки «Слить дубли» и «Очистить мусор», плюс переключатель порогов (минимум использований, срок хранения).
- Каталожная синхронизация перестаёт заливать в базу знаний всё подряд: подтягиваются только позиции, реально попадавшие в документы.

## 4. Проверка на дубли (сайт + админка)

Новый раздел админки «Гигиена данных» (в настройках):

- Сканер дублей по каталогу (зоны, услуги, техника, продакшн, аттракционы), кейсам, блогу, разделам каталога, контактам и позициям базы знаний.
- Сопоставление по нормализованному названию (регистр, пробелы, ё/е, знаки) плюс похожесть текста и совпадение slug — чтобы ловить «Фотозона Neon» и «фотозона неон».
- Дополнительно ищет: одинаковые slug, одинаковые изображения, пустые/незаполненные карточки, скрытые дубликаты неопубликованных карточек.
- Результат — список групп дублей: карточки рядом, видно где используется каждая (в заказах, КП, презентациях), и действия: «Оставить эту, остальные скрыть», «Удалить», «Слить в одну» (переносит связи на главную запись).
- Сводка сверху: индекс чистоты портала, количество групп дублей, мусорных записей базы знаний, карточек без описания/фото.
- Проверка запускается вручную кнопкой и автоматически раз в сутки; результат виден бейджем в меню админки.
