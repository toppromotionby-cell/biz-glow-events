# DJ Hub: яркий hero, разделы в цветах сайта, вход для сотрудников

Три правки на странице `/dj` (и одна общая — палитра обложек).

## 1. Hero-блок в диджейской тематике

Сейчас hero — стеклянная плашка с текстом и цифрами. Делаем его заметно ярче и «звучащим», но в фирменной янтарно-оранжевой гамме сайта:

- Тёмная сцена-подложка с фирменным градиентным свечением (`--gradient-hero`, `--gradient-primary`) вместо нейтрального стекла.
- Графика темы: крупный полупрозрачный винил/диск справа с медленным вращением, декоративная линия эквалайзера вдоль нижней кромки и лёгкая «зерно»-текстура.
- Заголовок — крупная фирменная типографика с градиентом сайта, подзаголовок и две кнопки («Войти в библиотеку» — градиентная, «Софт и плагины» — контурная).
- Счётчики (треки / новинки за неделю / софт) остаются, но подаются как светящиеся плашки.
- Всё анимационное отключается при `prefers-reduced-motion`; никаких новых картинок-ассетов — только CSS/SVG.

## 2. Разделы библиотеки — в цвета сайта

Сейчас плитки разделов раскрашены разнородными палитрами (фиолетовый, циан, маджента, стальной) — выбивается из стилистики. Приводим к лаконичной фирменной гамме:

- Все восемь разделов получают оттенки одной янтарно-оранжевой шкалы сайта: различие между разделами — только по светлоте/насыщенности и рисунку паттерна, не по «чужому» цвету.
- Плитки: единый тёмный фон + фирменный градиент, тонкая рамка, иконка раздела, название и подсказка, аккуратный ховер с подъёмом и подсветкой.
- Та же гамма автоматически применится к автогенерируемым обложкам треков (они берут цвета из того же источника), поэтому лента карточек тоже станет визуально единой.

## 3. Вход для сотрудников внизу страницы

В самом низу `/dj`, отдельным сдержанным блоком (визуально отделён от контента для диджеев):

- Заголовок «Вход для сотрудников», короткое пояснение, что раздел служебный.
- Кнопка ведёт на страницу входа с возвратом в админку (`/login?redirect=/admin/dj`).
- Оформление — приглушённое, без ярких градиентов, чтобы не конкурировало с hero.

## Технические детали

- `src/routes/dj.index.tsx`: новый hero, перерисованные плитки разделов, футер-блок входа для сотрудников.
- `src/lib/dj/cover-role.ts`: `COVER_PALETTES` переводится на фирменную шкалу (hue ~40–75, разная светлота/насыщенность), паттерны разделов сохраняются. Поднимается `COVER_SPEC_VERSION` — уже сгенерированные обложки останутся как есть, новые будут в новой гамме; массовую перегенерацию можно запустить отдельно.
- `src/styles.css`: пара утилит для сцены hero (свечение, винил, эквалайзер-полоса) на семантических токенах, без хардкода цветов.
- Проверка: типы + визуальный просмотр `/dj` в светлой и тёмной теме.
