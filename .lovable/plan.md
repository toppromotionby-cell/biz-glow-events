# Удаление блока «Занятость»

Убираем функциональность занятости/бронирования дат с публичного сайта и из админки. Таблицу `availability` в базе не трогаем (данные остаются, просто нигде не используются).

## Публичный сайт

- Удалить компонент календаря занятости `AvailabilityCalendar` и серверную функцию чтения занятости.
- Карточка услуги (полная страница): убрать блок «Занятость».
- Быстрый просмотр карточки: убрать вкладку «Занятость» на десктопе и на мобильных; если после этого остаётся одна вкладка, показывать её содержимое без табов.

## Админка

- Удалить страницу «Занятость каталога» (`/admin/availability`) и пункт меню в сайдбаре и в командной палитре.
- Убрать бейдж «бронирований на сегодня» у пункта «Календарь».
- Дашборд: убрать счётчик, который считает записи занятости.
- Карточка заказа: убрать блок проверки конфликтов по занятости (проверка пересечений дат). Если в этом блоке есть другие проверки, они сохраняются — удаляем только часть про занятость.
- Страница «Календарь» сейчас показывает исключительно записи занятости, поэтому она станет пустой. Предлагаю перевести её на даты мероприятий из заказов (номер заказа + клиент), чтобы раздел остался полезным. Если это не нужно — скажите, и мы удалим «Календарь» целиком.

## Техническая часть

Затрагиваемые файлы: `src/components/AvailabilityCalendar.tsx` (удаление), `src/lib/availability.functions.ts` (удаление), `src/routes/admin.availability.tsx` (удаление), `src/components/admin/OrderConflicts.tsx`, `src/components/CatalogDetail.tsx`, `src/components/CatalogQuickView.tsx`, `src/components/admin/AdminSidebar.tsx`, `src/components/admin/AdminCommandPalette.tsx`, `src/routes/admin.index.tsx`, `src/routes/admin.tsx` (хлебные крошки), `src/routes/admin.calendar.tsx`, `src/lib/orders.functions.ts` (очистка записей availability при удалении заказа больше не нужна).

Схема БД не меняется; таблица `availability` остаётся, но код к ней не обращается.
