# Раздел «Компании» вместо «Реквизиты и шаблоны»

## Что меняется

1. Пункт меню и заголовок страницы переименовываются в «Компании».
2. Из раздела убираются три вкладки, которые дублируют карточку компании:
   «Общие реквизиты», «Банк», «Подписант». Все эти поля (юр. название, бренд,
   УНП, адрес, телефон, e-mail, сайт, логотип, акцентный цвет, банк, БИК,
   счёт, подписант, должность, основание) уже есть внутри каждой компании.
3. Остаются вкладки: «Компании», «КП», «Счёт», «Договор», «Акт».

## Как сохранится корректность документов

Сейчас, если в документе компания не выбрана, реквизиты берутся из общих
настроек. Чтобы после удаления вкладок ничего не «поехало»:

- источником запасных реквизитов становится компания, отмеченная «по умолчанию»;
- при сохранении компании по умолчанию её реквизиты (включая банк, подписанта,
  логотип, акцентный цвет) автоматически записываются в общие настройки, которые
  используются как fallback в КП, счёте, договоре и акте;
- если ни одна компания не отмечена по умолчанию, в карточке компаний
  показывается подсказка с кнопкой «Сделать основной».
