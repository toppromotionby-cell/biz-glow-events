# Редактор презентаций как в Canva

## Что есть сейчас

- Страница слайда — три вкладки: «Слайды», «Оформление», «Сверка с КП». Полотно живёт внутри вкладки и делит ширину с панелями.
- Правка блоков включается отдельной кнопкой «Правка раскладки»: пока она выключена — можно печатать текст, но нельзя двигать блоки; пока включена — наоборот.
- Есть перетаскивание по «умным зонам», плавающая панель блока, миниатюры с drag-and-drop, показ на весь экран, автосохранение, отмена только для раскладки.
- Нет: единого рабочего пространства без вкладок, панели вставки слева, зума/подгонки полотна, направляющих и привязок, копирования стиля, полноценных undo/redo по всем правкам, контекстного меню, дублирования и выравнивания клавишами, панели порядка/слоёв.

## Что делаем

Собираем рабочее пространство по логике Canva: слева — панель вставки, рядом — лента слайдов, в центре — полотно, справа — контекстные свойства, снизу — строка состояния с зумом и навигацией.

### 1. Каркас окна
- Убираем вкладки на странице слайда. Экран: верхняя панель (название, статус, сохранение, «Показ», «PDF») → рабочая область на всю высоту.
- Левая колонка: переключатель разделов «Слайды», «Фото», «Текст», «Оформление», «Сверка с КП» — контент раздела открывается выдвижной панелью, как в Canva. Панель сворачивается.
- Центр: полотно с серым фоном вокруг, тень листа, отступы, вертикальная прокрутка при большом зуме.
- Право: панель свойств выбранного блока (то, что сейчас в плавающей панели + настройки слайда). Пока ничего не выбрано — свойства слайда целиком.
- Низ: строка состояния — номер слайда, стрелки, зум (−/+/ползунок/«Подогнать»/100%), кнопка заметок.

### 2. Работа с блоком как в Canva
- Один режим вместо «Правка раскладки»: клик — выделить блок, двойной клик — редактировать текст внутри, Esc — снять выделение.
- Рамка выделения с 8 маркерами, перетаскивание за тело, изменение размера за углы, курсоры под действие.
- Умные направляющие при перетаскивании: центр слайда, края полей, выравнивание с соседними блоками, магнитная привязка.
- Клавиатура: стрелки — сдвиг на 1 px, Shift+стрелки — на 10, Cmd/Ctrl+D — дублировать слайд, Delete — очистить/скрыть блок, Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z — отмена и повтор.
- Контекстное меню правой кнопкой на блоке и на миниатюре: дублировать, удалить, на передний/задний план, «сбросить положение».

### 3. Общая история изменений
- Undo/redo распространяем на всё: текст, свойства, добавление/удаление/перестановку слайдов, раскладку. Кнопки в верхней панели + горячие клавиши.

### 4. Лента слайдов
- Миниатюры с номером, кнопкой «+» между слайдами, множественным выделением (Shift/Cmd), групповым удалением и дублированием, перетаскиванием.
- Кнопка «Сетка» — обзор всех слайдов крупной сеткой, клик открывает слайд.

### 5. Панель вставки
- «Слайды» — типы слайдов карточками с превью-макетом вместо выпадающего списка.
- «Фото» — загрузка и выбор из медиатеки, перетаскивание на слайд.
- «Текст» — добавление заголовка/подзаголовка/описания одним кликом.
- «Оформление» — шаблон, шрифт, логотипы, компания (переносим текущую панель бренда).

### 6. Показ и проверка
- «Показ» — как сейчас, плюс подсказки клавиш и таймер.
- «Сверка с КП» — теперь раздел левой панели, с бейджем расхождений.

### 7. Проверка
- Прогон редактора в браузере: выделение, перетаскивание, привязки, зум, undo/redo, добавление и удаление слайдов, автосохранение, PDF совпадает с превью.
- Тесты на новые чистые модули: история изменений, привязки/направляющие, множественное выделение ленты.

## Технически

- Новый модуль состояния редактора `src/lib/presentations/editor-store.ts`: слайды, выделение, история (undo/redo стек патчей), зум.
- `src/lib/presentations/snap.ts`: расчёт направляющих и привязок (чистые функции + тесты).
- Разбиваем страницу `admin.documents.presentations.$id.index.tsx` на каркас `PresentationWorkspace.tsx` + панели: `InsertPanel.tsx`, `PropertiesPanel.tsx`, `StatusBar.tsx`, `SlideGridView.tsx`, `SlideContextMenu.tsx`.
- `SlideLayoutOverlay.tsx` переводим на единый режим с маркерами и направляющими; `BlockToolbar.tsx` переезжает в правую панель свойств (плавающий вариант оставляем для мобильного).
- Раскладка и рендер не меняются: `design.ts`, `zones.ts`, `logo-plan.ts`, `slide-spec.ts` и `pdf.server.ts` остаются единым источником геометрии — PDF продолжает совпадать с превью.
- Мобильная версия: панели становятся выдвижными снизу, полотно во всю ширину.

## Границы

- Не добавляем анимации переходов слайдов, совместное редактирование, комментарии и облачную библиотеку шаблонов Canva.
- Формат данных слайдов и серверные функции не меняем — только слой редактирования и интерфейс.
