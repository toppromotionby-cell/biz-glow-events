# Раздел «Документы» в админке + конструктор КП

## Что появится

Новая группа меню **«Документы»** в сайдбаре админки (между «Операции» и «Контент») с пунктом **«Коммерческие предложения (КП)»**. Внутри — полноценный конструктор КП: список сохранённых КП, черновики, редактор всех блоков документа и выгрузка в PDF в фирменном стиле сайта.

## Список КП (`/admin/documents/quotes`)

- Таблица: номер, название/клиент, дата мероприятия, сумма, статус (черновик / отправлено / принято / отклонено), автор, обновлено.
- Поиск, фильтр по статусу, сортировка по дате.
- Кнопки: «Создать КП», «Импорт из заказа» (выбор заказа → подтягиваются клиент, дата, позиции), «Дублировать», «Удалить», «Скачать PDF».

## Редактор КП (`/admin/documents/quotes/$id`)

Двухколоночный экран: слева форма-конструктор с секциями, справа живой предпросмотр документа (тот же стиль и шрифты, что на сайте). Автосохранение черновика (1.2 с debounce), статус сохранения в шапке.

Секции формы:

1. **Шапка документа** — номер (авто, редактируемый), дата документа, срок действия, название/тема КП.
2. **Клиент** — ФИО, компания, УНП, телефон, email, адрес. Кнопка «Подставить из заказа/профиля».
3. **Мероприятие** — дата, время начала и окончания, площадка/адрес, количество гостей, формат, монтаж/демонтаж, свободное поле комментария.
4. **Реквизиты исполнителя** — по умолчанию берутся из «Настройки → Документы», любой пункт можно переопределить в конкретном КП; загрузка логотипа/подписи/печати (bucket `media`, приватный, доступ через подписанные ссылки).
5. **Позиции** — добавление из каталога (зоны, оборудование, услуги, производство) через поиск с автоподстановкой цены/единицы, плюс произвольные строки. Поля: название, описание, кол-во, единица, цена, сумма. Drag-n-drop сортировка, группы/разделы позиций.
6. **Итоги** — скидка (% или сумма), предоплата (% или сумма), НДС-примечание, доставка/логистика, итог прописью.
7. **Текстовые блоки** — вступление, условия, сроки, что входит/не входит, футер. Значения по умолчанию из настроек документов, редактируются в самом КП. Простое форматирование (жирный, списки, абзацы).
8. **Оформление** — акцентный цвет, показывать/скрывать логотип, подпись, печать, обложку, блок «О компании».

Действия в шапке: «Скачать PDF», «Открыть HTML-версию», «Дублировать», «Сменить статус», «Удалить».

## PDF

Генерация на сервере через существующий движок (`src/lib/documents/pdf.server.ts`, pdf-lib + Roboto), расширенный под новые блоки КП: обложка, мероприятие, описания позиций, скидка/предоплата, подпись и печать, футер. Шрифты и цвета — те же токены, что на сайте. HTML-версия документа собирается тем же билдером, что и предпросмотр, чтобы вид совпадал.

## Технические детали

- Миграция: таблицы `quotes` (номер, статус, клиентские поля, поля мероприятия, реквизиты-переопределения, тексты, настройки оформления, скидка/предоплата, итог, `order_id` nullable, `created_by`) и `quote_items` (позиция, описание, кол-во, единица, цена, сортировка, ссылка на каталожную запись). GRANT + RLS: доступ только staff (`has_role` admin/manager) и `service_role`; триггеры `touch_updated_at`; нумерация КП по формату даты, аналогично `set_order_number`.
- Серверные функции `src/lib/quotes.functions.ts`: список, чтение, создание, автосохранение, дублирование, удаление, импорт из заказа, поиск по каталогу для подстановки позиций (через `requireSupabaseAuth` + проверка роли).
- Роуты: `src/routes/admin.documents.tsx` (обёртка с `<Outlet />`), `admin.documents.quotes.index.tsx`, `admin.documents.quotes.$id.tsx`, серверный роут `admin.documents.quotes.$id.pdf.tsx` (HTML + `?format=pdf`) на базе `requireStaff`.
- Билдер `src/lib/documents/quote-doc.server.ts` — единый HTML для предпросмотра и печати; PDF-рендер в `pdf.server.ts` получает новый `buildQuotePdf` с расширенной моделью.
- Сайдбар: новая группа «Документы» с иконкой `FileText`; существующий пункт «Документы» в «Системе» переименовывается в «Реквизиты и шаблоны», чтобы не путать с новым разделом.
- Валидация zod на клиенте и в серверных функциях (суммы неотрицательные, до 2 знаков, лимиты длин, корректность дат/времени).
