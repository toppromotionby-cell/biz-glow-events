# Шапка таблицы КП не совпадает с колонками (превью в редакторе)

## Что происходит

Воспроизвёл на вашем КП в редакторе и измерил ячейки:

- ширины `<th>` шапки: 71 / 43 / 40 / 33 / 78 / 72 / 61 px
- ширины ячеек строки: 105 / 26 / 33 / 20 / 47 / 47 / 161 px

То есть шапка и тело действительно живут по разным ширинам — визуально «съезжает».

## Причина (подтверждена замером)

Таблица документа имеет класс `grid` (`<table class="grid">`). В админке подключён Tailwind,
где `.grid` — это утилита `display: grid`. В итоге у таблицы вычисленный `display: grid`,
а `<colgroup>` и `<thead>` становятся блоками (замер показал `display: block`), поэтому
проценты ширин из `colgroup` перестают действовать на шапку.

В отдельном HTML-файле и в PDF Tailwind нет — там всё выравнивается ровно (проверил:
координаты ячеек шапки и строк совпадают до пикселя). Поэтому проблема видна только
в превью внутри админки.

## Что сделаю

1. Переименовать класс таблицы документа с `grid` на `doc-grid` в генераторе HTML
   промо-КП и в его CSS (`promo-quote-html.ts`), чтобы имя не пересекалось
   с утилитами Tailwind. То же — для остальных селекторов `.grid th`, `.grid td`,
   `tr.sec`, `tr.extra` и т.п.
2. Добавить в CSS документа страховочные правила, изолирующие превью от глобальных
   стилей приложения: `display: table` для таблицы, `table-column-group` для `colgroup`,
   `table-header-group` для `thead`, `table-row-group` для `tbody`.
3. Проверить остальные генераторы документов (стандартное КП, счета/акты) на такие же
   «общие» имена классов и переименовать при совпадении с утилитами Tailwind.
4. Тест-страховка: тест, который рендерит промо-КП в редакторе и сверяет,
   что ширины ячеек шапки совпадают с ширинами ячеек строки.

## Технические детали

- Файлы: `src/lib/documents/promo-quote-html.ts` (разметка + `PROMO_DOC_CSS`),
  при необходимости `src/lib/documents/quote-html.ts` и `build.server.ts`.
- PDF-рендер (`promo-pdf.server.ts`, `doc-layout.ts`) не трогаем — там ширины уже
  единые и корректные; менять расчёт колонок не нужно.
