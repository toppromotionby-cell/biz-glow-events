# Документы: скачивание PDF, разделы в КП, состав позиции + аудит админки

## 1. PDF не скачивается

Проверка показала: сервер отдаёт корректный PDF (200, `application/pdf`, 21 КБ) для реального КП. Значит ломается не генерация, а сам момент сохранения файла в браузере: скачивание запускается через невидимую ссылку `<a download>` внутри iframe предпросмотра, где загрузки блокируются, и пользователь не видит ни файла, ни ошибки.

Что сделаем:
- Надёжное скачивание: сначала пробуем `<a download>`, и если документ находится внутри iframe (предпросмотр) — открываем PDF в новой вкладке из blob-ссылки, откуда его можно сохранить.
- Понятные сообщения: если браузер заблокировал вкладку — тост с подсказкой; если сервер вернул ошибку — показываем текст ответа, а не только код.
- Индикатор загрузки на кнопках «Скачать PDF» (КП, КП промо, документы заказа), чтобы не было повторных кликов.
- Одинаковое поведение во всех местах: список КП, редактор КП, список и редактор КП промо, счёт/договор/акт заказа, публичная страница `/kp/<token>`.

## 2. Разделы в КП: полноценное управление

Сейчас раздел — это просто текстовое поле внутри каждой позиции. Сделаем разделы самостоятельной сущностью интерфейса:

- Кнопка «Добавить раздел» в составе КП: создаёт именованную группу (по подсказкам: Оборудование, Персонал, Логистика… или своё название).
- У каждого раздела: переименование прямо в заголовке, перемещение раздела выше/ниже целиком, дублирование, удаление (с выбором — удалить позиции или перенести их в «Без раздела»), сворачивание/разворачивание.
- Добавление позиции сразу внутрь конкретного раздела, перенос позиции в другой раздел из меню строки.
- Порядок разделов сохраняется (в позициях, через сортировку) и используется в предпросмотре, HTML- и PDF-версии документа, а также в выгрузке.
- В документе раздел печатается как подзаголовок с подытогом; можно скрыть подытоги раздела в настройках оформления.

То же управление разделами добавим в «КП промо», чтобы модули работали одинаково.

## 3. Состав позиции («что входит»)

Для своей (произвольной) позиции добавим отдельный редактор состава:

- В строке позиции — кнопка «Состав»: открывается панель, где построчно добавляются пункты «что входит» (например: доставка, монтаж, оператор 4 часа, расходники).
- Пункты можно добавлять, редактировать, менять местами и удалять; есть быстрая вставка сразу нескольких строк списком.
- Опционально у пункта — количество/примечание (короткая строка справа).
- Отдельно остаётся свободное описание позиции — оно печатается абзацем, а состав — маркированным списком под названием позиции.
- Флажок «Показывать состав в документе» на уровне КП (по умолчанию включён) — чтобы можно было отправить краткую версию.
- Готовые наборы: сохранить состав как шаблон и подставить его в другую позицию (используем существующий механизм сниппетов).

## 4. Аудит админки

После правок пройдём все разделы админки в браузере под реальной сессией и починим найденные ошибки:

Заказы, Календарь, Доступность, Документы (КП, КП промо, реквизиты/шаблоны), Контент (каталог, кейсы, блог, отзывы, секции), Промокоды, Кампании, Пользователи и роли, Почта и шаблоны писем, Уведомления, Аудит, Настройки.

Проверяем: открытие страницы без ошибок в консоли, создание/сохранение/удаление записей, автосохранение, скачивание и предпросмотр документов, отправка писем (тестовая), работа фильтров и поиска, доступ по ролям. Список найденных проблем и их исправления приложим к отчёту.

## Технические детали

- `src/lib/authed-fetch.ts`: `downloadAuthedFile` — определение iframe (`window.top !== window.self`), fallback на `openInlineBlob`, чтение тела ошибки, возврат имени файла; вызовы обновляются в `admin.documents.quotes.index.tsx`, `admin.documents.quotes.$id.index.tsx`, `admin.documents.promo.index.tsx`, `admin.documents.promo.$id.index.tsx`.
- Миграция: `quote_items.includes jsonb not null default '[]'` и `promo_quote_items.includes jsonb not null default '[]'`; поле `quotes.design`/`promo_quotes` получает флаги `show_item_includes`, `show_section_subtotals` (в существующем jsonb, без миграции схемы).
- `src/lib/quotes-model.ts` и `src/lib/promo-quote-model.ts`: тип `QuoteItemInclude = { text: string; note?: string }`, нормализация, zod-схема, сохранение в серверных функциях `quotes.functions.ts` / `promo-quotes.functions.ts`.
- Разделы: порядок разделов выводится из `sort_order` позиций; операции над разделом (переименование, перемещение, удаление, перенос) — чистые функции в `quotes-model.ts` с юнит-тестами, UI — переработанный `src/components/admin/quotes/QuoteItemsPanel.tsx` (+ аналог в промо-редакторе).
- Новый компонент `src/components/admin/quotes/QuoteItemIncludesEditor.tsx` (диалог состава позиции), переиспользуется обоими модулями.
- Рендер: `src/lib/documents/quote-html.ts`, `promo-quote-html.ts`, `pdf.server.ts` (`buildStandaloneQuotePdf`, `buildPromoQuotePdf`) — подзаголовки разделов с подытогами и маркированный список состава позиции.
- Аудит: Playwright-прогон по маршрутам админки с логом консоли и сетевых ошибок, точечные фиксы по результатам.
