# Черновик презентации из любого КП

## Как это работает у других

В PandaDoc, Qwilr и Canva «док → дека» устроено одинаково: система не просто копирует строки, а собирает сценарий (сториборд) — обложка, разделы, карточки позиций, условия, бюджет, контакты — и даёт человеку до создания увидеть и отредактировать список слайдов. Делаем так же.

## Что будет у нас

В редакторе КП и промо-КП появляется кнопка «Собрать презентацию». Она открывает окно сборки:

- **Шаблон и тема** — как при обычном создании презентации.
- **Сценарий** (чекбоксы, все включены по умолчанию):
  - Обложка — тема КП, клиент, дата мероприятия, номер КП;
  - «О нас» — из карточки компании (если заполнена);
  - Разделитель на каждый раздел КП (только если разделов больше одного);
  - Слайд на каждую позицию — название, описание, «что входит», фото из каталога, цена и количество;
  - «Дополнительно» — мелкие позиции без фото собираются в один список, чтобы не плодить пустые слайды;
  - Условия и примечания — из текстовых блоков КП;
  - Бюджет — Позиции / Скидка / Доставка / Менеджмент / Комиссия / НДС / Итого / Предоплата (можно выключить, если клиенту дека уходит без цен);
  - Контакты.
- **Список позиций** — можно снять галочки с ненужных, увидеть, у каких позиций нет фото и описания.
- **Предпросмотр структуры** — нумерованный сториборд («1. Обложка», «2. Раздел: Техника», …) до нажатия «Создать».

После создания открывается редактор презентации с готовым черновиком: слайды уже разложены существующей авто-раскладкой (умные зоны, сетки фото 1–15), фон и логотип — по шаблону.

## Повторная сборка без конфликтов

- Если у КП уже есть презентация, кнопка предлагает: «Открыть существующую» или «Создать новую» — дубликаты не создаются молча.
- В открытой презентации кнопка «Обновить из КП» показывает разницу: добавленные позиции, удалённые, изменившиеся цены/названия. Пользователь отмечает, что применить. Ручные правки слайдов (тексты, фото, раскладка) не затираются: обновляются только те поля, которые пользователь отметил.
- Связь идёт по `quote_item_id`, поэтому слайд всегда знает свою строку КП.

## Проверки

- Сборка блокируется, если в КП нет ни одной позиции — с понятным сообщением.
- После сборки открывается панель проверок презентации: слайды без фото, слишком длинный текст, позиции КП, не попавшие в деку, цены в деке против цен в КП.
- Права: сборка доступна только сотрудникам с доступом к документам (та же проверка, что и в остальных функциях документов).
- Тесты: сценарий сборки по фикстурам (КП с разделами и без, с фото и без, промо-КП), тест на пересборку (нет дублей, ручные правки сохраняются), тест на бюджетный слайд (числа совпадают с итогами КП, включая менеджмент и комиссию).

## Технические детали

- Новый модуль `src/lib/presentations/from-quote.ts` (browser-safe, чистые функции): `buildStoryboard(quote, items, sections, totals, options)` → массив `SlideDraft` + метаданные шага сценария. Здесь же правила подбора типа слайда: `section` → separator, позиция с фото → product, группа мелких → text, итоги → text-слайд «Бюджет».
- Серверные функции в `src/lib/presentations.functions.ts`:
  - `planPresentationFromQuote({ quoteId, source: 'quote' | 'promo', options })` — сухой прогон, возвращает сториборд для предпросмотра;
  - `createPresentationFromQuote(...)` — создаёт презентацию и слайды одной вставкой, переиспользуя `productSlideFromItem` и `normalizeSlide`;
  - `diffPresentationAgainstQuote({ presentationId })` — расхождения для «Обновить из КП»;
  - существующая `buildSlidesFromQuote` остаётся и вызывает общий модуль, чтобы формула сборки была одна.
- Промо-КП: загрузчик позиций для `promo_quote_items` рядом с текущим `loadQuoteItems`, дальше общий путь.
- Бюджетный слайд берёт числа из `computeTotals` / `computePromoTotals` — те же, что в документе (с менеджментом и комиссией).
- UI: `src/components/admin/documents/BuildPresentationDialog.tsx` (окно сборки со сторибордом), кнопки в `admin.documents.quotes.$id.index.tsx` и `admin.documents.promo.$id.index.tsx`, панель «Обновить из КП» в редакторе презентации.
- Фото: до 15 на слайд через существующий `photo-grid.ts`, лишние отбрасываются; ссылки строятся через `mediaPublicUrl`.
- Тесты: `src/lib/presentations/__tests__/from-quote.test.ts`.
