# Убрать ссылки «Открыть полную страницу»

## Что меняем

1. **Сайт — быстрый просмотр каталога**
   Внизу окна «Подробнее» убираем ссылку «Открыть полную страницу» вместе с разделителем над ней. Окно быстрого просмотра остаётся единственным местом с полной информацией по позиции.

2. **Админка — модалка заказа**
   Убираем кнопку «Полная страница» в шапке модального окна заказа.

3. **Админка — список заказов**
   Убираем иконку-ссылку с подписью «Открыть полную страницу заказа …» из строки таблицы.

Сами страницы по прямым адресам продолжают работать — исчезают только ссылки и кнопки в интерфейсе.
