# Убрать кнопку «В новой вкладке» из просмотра документов

## Что делаем
В диалоге предпросмотра документа (`src/components/admin/DocumentViewerDialog.tsx`) убираем кнопку «В новой вкладке» из шапки модального окна. Кнопка «Скачать» остаётся без изменений.

## Технические детали
- Удалить блок кнопки с `ExternalLink` и ссылкой `href={doc.url} target="_blank"` (строки 31–35).
- Убрать импорт `ExternalLink`, если он больше нигде не используется в этом файле.
- Подвал с подсказкой про «откройте документ в новой вкладке» оставить без изменений, чтобы сохранить запасной вариант при блокировке скачивания.

## Проверка
- Сборка проходит без ошибок.
- В диалоге просмотра КП/документа отображается только кнопка «Скачать».
