# Итоги в КП: убрать дублирующую строку «Сумма без НДС»

## Что меняется
В блоке итогов КП строка «Стоимость позиций» переименовывается в **«Стоимость позиций (без НДС)»**.

Отдельная строка «Сумма без НДС» убирается, когда она дублирует стоимость позиций (нет скидки и доставки). Если есть скидка или доставка — суммы отличаются, поэтому строка остаётся, чтобы было видно базу для расчёта НДС.

Итоговый вид без скидки:
```text
Стоимость позиций (без НДС)      7 000,00 BYN
НДС 20%                          1 400,00 BYN
Итого с НДС                      8 400,00 BYN
```

## Где применяется
- HTML-превью КП
- PDF-выгрузка КП
- Промо-КП (превью и PDF) — там строка «Сумма без НДС» тоже сворачивается при отсутствии скидки
- Панель итогов в админке — та же логика подписей

## Технические детали
- `src/lib/documents/quote-html.ts` (блок `totals`): подпись subtotal + условие показа строки net (`t.vatEnabled && (t.discount || t.delivery)`).
- `src/lib/documents/pdf.server.ts` (~строки 1842–1850): аналогичные правки в `drawSummary`.
- `src/lib/documents/promo-quote-html.ts` (~строка 158) и соответствующий PDF-вывод (~2046): скрывать строку net при отсутствии скидки, подпись строки итога позиций — «Стоимость позиций (без НДС)».
- `src/components/admin/promo/PromoTotalsPanel.tsx`: синхронизировать подписи.
- Строки «Сумма без НДС» в счетах/актах (`build.server.ts`, pdf 1307/1511) не трогаем — это другие документы.
