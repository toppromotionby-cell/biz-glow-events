# Модуль «Коммерческие предложения» — апгрейд функционала и удобства

Сейчас редактор КП — это одна длинная колонка аккордеонов слева и превью справа. Позиции добавляются простым списком без разделов, перемещаются стрелками ▲▼, нет истории версий, нет проверок перед отправкой, нет отправки клиенту, нет маржи. В соседнем модуле «КП промо» уже реализованы более удобные решения — переносим лучшие практики сюда и добавляем то, чего нет нигде.

## 1. Новая структура редактора (вкладки вместо простыни)

Вместо длинного аккордеона — вкладки, как в КП промо:

- **Состав** — таблица позиций (основная рабочая зона)
- **Клиент и событие** — заказчик, площадка, дата, гости, комментарии
- **Финансы** — скидка, доставка, предоплата, НДС, маржа
- **Документ** — шаблон, блоки, тексты
- **Вид** — оформление, логотип, подпись, печать, реквизиты

Справа остаётся живое превью, а над ним — липкая панель итогов (позиции → скидка → доставка → итого → предоплата/остаток).

## 2. Позиции: разделы, drag-and-drop, быстрый ввод

- Группировка позиций по **разделам** (поле `section` уже есть в базе, но в UI не используется): «Оборудование», «Персонал», «Логистика» и т. д., с подытогом по каждому разделу и сворачиванием.
- **Drag-and-drop** перетаскивание строк и разделов вместо стрелок (компонент `SortableList` уже есть в проекте).
- **Вставка из Excel** — копипаст таблицы прямо в редактор, разбор строк «название / кол-во / ед. / цена».
- **Дублирование** позиции и раздела, массовое удаление.
- Компактная строка: название на всю ширину + сумма справа, под ним мелкие подписанные поля (кол-во, ед., цена) — та же схема, что мы только что сделали в КП промо.
- Улучшенный поиск по каталогу: добавление нескольких позиций за один заход без закрытия окна, показ уже добавленных.

## 3. Себестоимость и маржа

- Новое поле `cost` у позиции (себестоимость), скрыто по умолчанию, включается тумблером.
- Панель финансов показывает: выручку, себестоимость, маржу в деньгах и в %, с цветовым индикатором при низкой марже.
- Себестоимость **никогда** не попадает в PDF/HTML для клиента — только внутренняя аналитика.

## 4. Проверки перед отправкой

Панель «Проверки» вверху редактора (как в КП промо): не заполнен клиент, нет позиций, нулевые цены, отсутствует дата события, скидка больше суммы, не указан срок действия. Ошибки — красным, замечания — серым.

## 5. Версии и отправка клиенту

- **История версий**: снимок КП при каждой отправке и по кнопке «Зафиксировать версию», просмотр и восстановление любой.
- **Отправка клиенту по e-mail** прямо из редактора: письмо с PDF во вложении, статус автоматически меняется на «Отправлено», дата отправки фиксируется.
- **Публичная ссылка на КП** (по секретному токену), чтобы клиент открыл документ в браузере без вложений.

## 6. Шаблоны КП

- Сохранение любого КП как **шаблона** (с позициями, текстами, оформлением) и создание нового документа из шаблона в один клик — на списке появляется переключатель «Документы / Шаблоны», как в КП промо.
- Библиотека переиспользуемых позиций (сниппетов) — серверные функции уже есть (`listQuoteSnippets`, `saveQuoteSnippet`), но в UI редактора не подключены; подключаем.

## 7. Мелочи удобства

- **Ctrl+Z** (отмена последнего изменения) — локальный стек истории.
- **Ctrl+S** — принудительное сохранение, автосейв остаётся.
- **Экспорт в XLSX** (сейчас есть только HTML и PDF) — по образцу промо-экспорта с живыми формулами.
- Подсказки-тултипы к нетривиальным полям (срок действия, тип предоплаты, примечание по НДС).
- Мобильная адаптация: превью сворачивается в отдельную вкладку.

## Техническая часть

- Миграция БД: `quote_items.cost numeric not null default 0`; `quotes.sent_at`, `quotes.is_template`, `quotes.template_name`, `quotes.public_token`; новая таблица `quote_versions` (снимок JSON + автор + дата) с RLS и GRANT для admin/manager.
- Модель: расширить `src/lib/quotes-model.ts` — `computeTotals` с маржой, `checkQuote()` для проверок, `parsePastedQuoteRows()` для вставки из Excel.
- Сервер: в `src/lib/quotes.functions.ts` добавить `listQuoteVersions`, `createQuoteVersion`, `restoreQuoteVersion`, `markQuoteSent`, `saveQuoteAsTemplate`; сохранение `cost` во всех путях CRUD/копирования.
- Компоненты: `src/components/admin/quotes/QuoteItemsTable.tsx` (разделы + dnd), `QuoteTotalsPanel.tsx`, `QuoteItemsToolbar.tsx`, `QuoteChecks.tsx` — по аналогии с уже готовыми промо-компонентами.
- Экспорт XLSX: `src/lib/documents/quote-xlsx.browser.ts` (в браузере, `exceljs`, имя файла `.browser.ts` из-за защиты импортов TanStack Start).
- Отправка письма — через существующий `sendWithAttachments` в `src/lib/admin-email.server.ts`.
- Себестоимость исключается из `quote-html.ts` и `pdf.server.ts`.

## Порядок работ

1. Миграция БД + модель и серверные функции
2. Новая таблица позиций с разделами и dnd + панель итогов + проверки
3. Перевод редактора на вкладки, Ctrl+Z / Ctrl+S
4. Версии, шаблоны, публичная ссылка
5. Отправка по e-mail и экспорт XLSX
