# Презентации: одинаковый вид в превью и в PDF

## Проблема

Слайд в редакторе (превью) и слайд в PDF рисуются двумя разными кодами. Общими у них являются только расчёт плотности текста (`fit.ts`) и планировщик логотипов (`logo-plan.ts`), а сама отрисовка расходится:

- Титульный слайд: в превью блок центрирован по вертикали, есть подпись с датой, контакты идут «чипами», есть акцентный круг в углу. В PDF — жёстко заданные координаты (y = H − 130), контакты в одну строку через точку, ни даты, ни круга.
- Слайд-раздел: в превью заголовок центрирован по высоте с акцентной чертой сверху, есть футер. В PDF — привязка к середине страницы и другие кегли (34/16 вместо шкалы плотности).
- Слайд «Контакты»: в превью — сетка карточек 2×2 на цветной подложке. В PDF — простой список строк.
- Слайды с фото на весь слайд: в превью снизу тёмный градиент и белый текст. В PDF затемнения нет — текст сливается с фотографией.
- Кегли и отступы заголовков/подзаголовков/футера на титуле, разделе и контактах в PDF заданы числами, а не общей шкалой; из-за этого размеры не совпадают.

## Что делаем

Один общий «сценарий слайда» для всех типов: PDF повторяет то, что видно в превью — та же вертикальная центровка, те же кегли, те же блоки (карточки контактов, дата, чипы, акцентные линии, затемнение под фото, футер).

Итог: нажал «PDF» — получил ровно то, что было на слайде в редакторе; будущие правки превью автоматически отражаются в PDF.

## Технически

1. Вынести в `src/lib/presentations/design.ts` (или новый `slide-spec.ts`) описание геометрии для всех типов слайда: отступы, позиции блоков титульного/раздела/контактов, размеры карточек контактов, футер, акцентные полосы, декоративный круг — в координатах холста 1280×720.
2. `SlideCanvas.tsx` рисует HTML из этого спека вместо текущих «магических» чисел (визуально сохранив нынешний вид как эталон).
3. `pdf.server.ts` переписать на тот же спек:
   - титул, раздел, контакты — по общим координатам и кеглям из `fit.type`, с вертикальной центровкой, как в превью;
   - контакты — карточки на подложке `theme.panel`, а не строки;
   - для `placement === "full"` добавить градиентное затемнение снизу (полосами, как в `drawBackground`) и белый текст;
   - титул — акцентный круг, дата, контакты в том же порядке и с теми же кеглями;
   - футер — размер `ts.caption` и координаты из спека.
4. Расширить `src/lib/presentations/__tests__` проверкой, что для набора фикстур-слайдов геометрия блоков одна и та же для превью и для PDF (сравнение через спек, не пиксельно).
5. Маршрут `/admin/documents/presentations/$id/render?format=pdf` и кнопки не меняются.

## Границы

- Пиксель-в-пиксель совпадение недостижимо (браузер ≠ pdf-lib): цель — идентичная структура, порядок блоков, цвета, кегли и переносы.
- Шрифты остаются текущие (Inter/Space Grotesk/Ubuntu); Space Grotesk без кириллицы — заголовки на кириллице продолжают рисоваться запасным шрифтом.
