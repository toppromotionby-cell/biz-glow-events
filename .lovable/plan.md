# Логотипы в презентациях: одинаковый размер и свободное перетаскивание

## Что изменится для пользователя

1. **Титульный слайд** — логотип компании и логотип клиента одного размера и заметно крупнее. Размер подбирается автоматически: чем больше свободного места, тем крупнее логотипы (в пределах разумного максимума).
2. **Остальные слайды** — логотипы компактные, но тоже строго одинакового размера между собой, по тем же правилам подбора.
3. **Ручное перетаскивание** — в режиме «Правка раскладки» логотип можно перетащить в любую точку слайда, а не только в один из углов. Он останется там, где отпустили.
4. **Умный подбор при переносе** — в новой точке логотип автоматически уменьшается или увеличивается под свободное пространство. Текст и блок цены он не перекрывает никогда (отодвигается/ужимается), а поверх фотографии ложиться может свободно.
5. Если места совсем мало (меньше минимального читаемого размера) — логотип не рисуется, как и сейчас.

## Правила размера

- Общий размер = минимум из подходящего под свободное место у логотипа компании и у логотипа клиента, чтобы оба были одинаковыми.
- Титульный слайд: базовая высота крупная (примерно вдвое больше обычной), масштабируется до свободного места.
- Прочие слайды: базовая высота компактная.
- Пользовательский масштаб из настроек брендинга по-прежнему применяется поверх авторасчёта.

## Техническая часть

- `src/lib/presentations/model.ts`: расширить `LogoOverride` полями свободной позиции `pos: { x: number; y: number } | null` (доли 0..1 от холста 1280×720) с нормализацией и учётом в `isAutoLayout`.
- `src/lib/presentations/logo-plan.ts`:
  - `LogoPlacementPlan` получает опциональные `x`/`y` для свободной позиции (слот тогда `free`).
  - Новая функция подбора размера: по точке размещения ищем максимальный свободный прямоугольник с учётом только «жёстких» препятствий (текст, заголовок, блок цены) — фото в препятствия не входит.
  - Общий шаг выравнивания: после расчёта обоих логотипов привести их к одному коэффициенту (min), сохраняя пропорции каждого логотипа.
  - Титульный слайд: увеличенная база для обоих логотипов, hero-слот для бренда остаётся, но размер считается тем же solver'ом.
- `src/components/admin/presentations/SlideLayoutOverlay.tsx`: для логотипов отключить привязку к зонам — при перетаскивании писать `pos` (доли координат), рамка выделения и тулбар остаются; в тулбаре добавить «Вернуть авто» для сброса `pos`/`zone`.
- `src/components/admin/presentations/SlideCanvas.tsx`: рендер логотипа по `plan.brand/client` со слотом `free` — абсолютное позиционирование по `x`/`y`.
- `src/lib/presentations/pdf.server.ts` и `pptx.browser.ts`: поддержать слот `free` (пересчёт координат из 1280×720) — превью, PDF и PPTX совпадают.
- `src/lib/presentations/__tests__/logo-plan.test.ts`: тесты — одинаковый итоговый размер двух логотипов, увеличение на титульном, уважение свободной позиции, отсутствие пересечения с текстом, допустимость наложения на фото.
