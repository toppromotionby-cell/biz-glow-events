# НДС в документах: единый блок настроек и корректный расчёт

Добавляем НДС во все документы: КП, КП промо, счёт, акт, договор. Везде — один и тот же раскрывающийся блок настроек и одна и та же логика расчёта.

## Блок настроек НДС (одинаковый везде)

Свёрнутая секция «НДС» в разделе «Деньги» документа:

- **Режим**: без НДС / начисляется сверху / в том числе
- **Ставка, %** — появляется только когда НДС включён, по умолчанию 20
- **Показывать НДС отдельной позицией в таблице** — галочка (иначе НДС только строкой в блоке «Итого»)
- **Примечание по НДС** — текстовая строка внизу документа (уже есть в КП, переносим в этот блок)

По умолчанию для новых документов — **без НДС**. Ставка 20% подставляется в момент включения.

## Как считается

```text
Сверху:        Сумма без НДС = позиции − скидка + доставка
               НДС = сумма × ставка/100
               Итого с НДС = сумма + НДС

В том числе:   Итого = позиции − скидка + доставка (цены уже с НДС)
               НДС = итого × ставка / (100 + ставка)
               Сумма без НДС = итого − НДС
```

Округление до копеек на каждом шаге, чтобы «Сумма + НДС» всегда сходилось с «Итого». Предоплата и остаток считаются от итога **с НДС**. Маржа и себестоимость — от суммы **без НДС**.

## Где появится в документе

Блок «Итого» во всех форматах (превью, PDF, публичная ссылка, Excel для КП промо):

```text
Сумма без НДС        1 200,00
НДС 20%                240,00
Итого с НДС          1 440,00
```

Если включена галочка «отдельной позицией» — в конце таблицы позиций добавляется строка «НДС 20%» с суммой, и она же дублируется в итогах. При режиме «без НДС» остаётся текущий вид плюс текстовое примечание.

Сумма прописью и все места, где сейчас печатается общая стоимость (счёт, акт, п. 2.1 договора), берут итог с НДС и добавляют «в том числе НДS 20% — X» вместо статичной заметки.

## Счёт, акт, договор

Эти документы генерируются из заказа и своих настроек не имеют — блок НДС для них живёт в разделе «Настройки документов» (режим, ставка, отдельная позиция, примечание) и применяется ко всем трём.

## Технические детали

1. **Миграция**
   - `quotes`: `vat_mode text default 'none'`, `vat_rate numeric default 20`, `vat_as_line boolean default false`
   - `promo_quotes`: `vat_mode`, `vat_as_line`; существующие `vat_enabled = true` переносятся в `vat_mode = 'add'`, поле остаётся синхронизированным для обратной совместимости
   - `document_settings`: `vat_mode`, `vat_rate`, `vat_as_line`
2. **`src/lib/documents/vat.ts`** (новый) — тип `VatConfig`, `computeVat(base, cfg)`, лейблы («Сумма без НДС» / «НДС 20%» / «Итого с НДС»), формирование строки-позиции. Единый источник для всех рендереров.
3. **Расчёты**: `computeTotals` в `src/lib/quotes-model.ts` и `computePromoTotals` в `src/lib/promo-quote-model.ts` переводятся на `computeVat`; хардкод `QUOTE_VAT_RATE` из `src/lib/quote-blocks.ts` удаляется, плейсхолдеры `vat_rate` / `vat_amount` / `total_with_vat` считаются от реального конфига.
4. **UI**: общий компонент блока настроек, подключается в `admin.documents.quotes.$id.index.tsx`, `admin.documents.promo.$id.index.tsx` и в настройках документов; панели итогов (`PromoTotalsPanel`, сводка в КП) показывают новые строки.
5. **Рендереры**: `quote-html.ts`, `promo-quote-html.ts`, `pdf.server.ts` (КП, КП промо, счёт, акт, договор), `build.server.ts`, `promo-xlsx.browser.ts` — итоги и опциональная строка-позиция из общего модуля; в Excel НДС остаётся формулой.
6. **Схемы**: `quotePatchSchema` и promo-схема получают новые поля с валидацией ставки 0–30.
