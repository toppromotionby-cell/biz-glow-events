# Объединённая ячейка «услуга» вместо пустых единиц и количеств

## Что меняется

Если у позиции единица измерения — «услуга» (или «усл.»), количество = 1 и вторая
единица не заполнена, то ячейки «Ед. изм.» и «Кол-во» (а при включённых колонках
второй единицы — и вторая пара «Ед. изм.» / «Кол-во») объединяются в одну ячейку
на всю их ширину со словом «услуга» по центру. Прочерков «—» в таких строках больше нет.

Пример из скриншота: строка «Шатер "Звезда"» вместо `услуга | 1 | — | —`
показывает одну широкую ячейку `услуга`.

Колонка «Всего» и остальные колонки не объединяются — остаются как есть.

Условия объединения (все сразу):
- единица измерения строки — «услуга»/«усл.» (без учёта регистра и точки);
- количество равно 1;
- вторая единица у строки не заполнена.

Служебные строки (управление, комиссия, НДС) с единицей «услуга» и прочерками
получают такое же объединение — это уберёт лишние прочерки в подвале таблицы.

## Где применяется

- Превью КП промо и обычного КП в админке.
- PDF-выгрузка.
- Excel-выгрузка: объединение ячеек листа для тех же строк (импорт продолжает
  читать такие строки как «услуга», кол-во 1).
- Google Документ: объединение ячеек таблицы теми же правилами.
- Google Таблица: объединять не будем — лист остаётся строгой сеткой для
  двусторонней синхронизации, там ячейки просто останутся пустыми вместо «—».

## Технические детали

- В `src/lib/promo-quote-model.ts` (и аналог в `quotes-model.ts`) — хелпер
  `isServiceOnlyRow(item)`, единый источник правила.
- `src/lib/documents/promo-quote-html.ts` и `quote-html.ts`: для таких строк
  вместо 2–4 `<td>` рендерится один `<td colspan="N" class="c-unit">услуга</td>`;
  та же логика в `midCells()` для служебных строк.
- `src/lib/documents/pdf.server.ts`: в `drawTable` добавляется поддержка
  объединения соседних колонок в строке (поле вида `_span: { from: "unit", to: "qty2", text: "услуга" }`),
  отрисовка текста по центру объединённой ширины и одна вертикальная граница вместо трёх.
- `src/lib/documents/promo-xlsx.browser.ts` / `quote-xlsx.browser.ts`:
  `worksheet.mergeCells` по диапазону колонок единиц/количеств, значение «услуга»,
  выравнивание по центру. Формулы суммы строки берут количество из скрытой
  логики (кол-во = 1), расчёт не меняется.
- `src/lib/documents/promo-gdocs.server.ts`: запросы `mergeTableCells` для тех же
  диапазонов при сборке документа; парсер чтения (`readPromoDocRows`) должен
  корректно обрабатывать строку с меньшим числом ячеек — трактовать её как
  «услуга», кол-во 1.
- `src/lib/promo-sheets.server.ts`: без merge, только замена «—» на пустые ячейки
  в этих строках.
