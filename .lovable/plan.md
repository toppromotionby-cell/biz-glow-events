## Что проверено

- `src/lib/search.functions.ts` — серверная функция `globalSearch` (поиск по zones/tech_equipment/services/production_items/cases/blog_posts).
- `src/components/SearchTrigger.tsx` — диалог Cmd/Ctrl+K в шапке.
- `src/components/ui/command.tsx` — обёртка над `cmdk`.
- Использование: только в `SiteChrome` (десктоп + мобайл).
- На страницах каталогов (`/zones`, `/equipment`, `/services`, `/production`, `/blog`, `/cases`) локального поиска/фильтра по тексту нет.

## Найденные проблемы

### Баги (важно)

1. **Конфликт фильтрации `cmdk` с серверными результатами.** `CommandDialog` использует встроенный fuzzy-фильтр `cmdk`. Он сравнивает ввод с `value="${kind}-${id}-${title}"` и **скрывает** карточки, которые сервер вернул по совпадению в `excerpt`/`summary`/`client` (поле в `value` не включено). Симптом: «сервер нашёл — UI показывает “Ничего не найдено”».
2. **Нет debounce.** Запрос на сервер уходит на **каждое нажатие клавиши** — лишняя нагрузка и мерцание результатов.
3. **`queryKey` использует не-trimmed `q`** → `"свет"` и `"свет "` создают разные кэш-записи.
4. **Нет состояний загрузки и ошибки.** Пока летит запрос — пусто; если сервер упал — тоже тихо пусто, без понимания причины.
5. **Нет ARIA для триггера** содержит подсказку «Ctrl+K», но на macOS правильнее `⌘K`. Мелочь, но видно.
6. **Производительность БД.** `ilike '%...%'` без `pg_trgm` GIN-индексов — на больших таблицах будет медленно (сейчас не критично, но стоит заложить).

### Улучшения UX

7. Показывать подсказку быстрых клавиш (`⌘K` / `Ctrl K`) прямо в кнопке/инпуте.
8. Приоритезировать совпадения в **названии** над совпадениями в описании (сейчас порядок случайный по `Promise.all`).
9. Подсветка совпадения (highlight) в названии/excerpt.
10. История последних запросов (localStorage) и/или популярные разделы при пустом запросе.
11. На страницах каталогов (`/zones`, `/equipment`, `/services`, `/production`, `/blog`, `/cases`) добавить **локальный фильтр-инпут** — самое частое ожидание пользователей. Сейчас его нет совсем.
12. Расширить серверный поиск: добавить поиск по `description` и `category` (а не только `title`/`short_description`).
13. На мобильном текущая кнопка `9×9` иконкой — нормально, но нет видимой подписи; добавить `sr-only` уже есть, можно оставить.

### Производительность

14. Параллельные запросы к 6 таблицам всегда — даже когда вводят 2 символа. Можно ограничить выдачу до 3 на категорию и группировать «Показать ещё».
15. Добавить миграцию: расширение `pg_trgm` + GIN-индексы по `title`, `short_description`, `summary`, `excerpt` — ускорит `ilike` в десятки раз.

- При пустом инпуте показывать секцию «Недавние запросы» (localStorage, 5 шт.). При выборе результата сохранять запрос.
- Подсветка совпадения через простую обёртку `<mark>` в `title`/`excerpt`.

### 3. `src/components/ui/command.tsx`

- Прокинуть проп `shouldFilter` в `Command` и `CommandDialog`, чтобы можно было отключать клиентскую фильтрацию.

### 4. Локальный поиск на listing-страницах *(опционально, по подтверждению)*
