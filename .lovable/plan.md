# Новый универсальный бот-помощник в Telegram

Отдельный третий бот (рядом с планером и DJ-ботом): отвечает на любые рабочие вопросы, умеет искать в интернете по бесплатным источникам, осмысливает найденное моделью и работает строго по прописанной роли — без самодеятельности.

## Что нужно от вас

1. Создать бота в @BotFather (`/newbot`) и прислать **@username** и **токен**.
2. В @BotFather: `/setprivacy` → Disable (если планируете добавлять его в группы), `/setdescription`, `/setcommands` я подготовлю сам.
3. Ваш Telegram: просто напишите новому боту `/start` — он выдаст код привязки, вводите его в админке.
4. По желанию: ID рабочего чата, если бот должен отвечать и в группе.

Токен подключу как отдельное подключение Telegram-коннектора — вручную нигде хранить не нужно.

## Что умеет бот

**Ответы на вопросы.** Свободный текст и голосовые. Модель — Gemini 3.7 Flash через Lovable AI (голос — распознавание речи, ответ текстом + при необходимости картинкой/таблицей/графиком).

**Поиск в интернете.** Каскад бесплатных источников: DuckDuckGo → Wikipedia → чтение и очистка 2–3 найденных страниц. Дальше модель делает выжимку и всегда указывает источники ссылками. Если источники противоречат или ничего не найдено — бот прямо это говорит, а не выдумывает.

**Режимы работы (комбинированная строгость):**

```text
Простой вопрос / поиск      → отвечает сразу, со ссылками
Нестандартная задача        → собирает план и присылает на утверждение
                              (✅ Утвердить · ✏️ Правки · 🚫 Отменить)
Опасное действие            → всегда подтверждение кнопкой
Вне зоны ответственности    → вежливый отказ + список того, что он умеет
Не привязанный пользователь → только /start
```

**Команды:** `/start`, `/help`, `/ask <вопрос>`, `/find <запрос>` (только поиск), `/plan <задача>`, `/mode` (кратко/подробно), `/sources` (источники последнего ответа), `/reset` (сброс контекста), `/mute`, `/unmute`.

## Роль бота (прописывается полностью)

Отдельный файл персоны с жёсткими правилами: кто он, кому подчиняется, чем занимается и чем НЕ занимается; формат ответа (сначала суть, потом детали, максимум 5 пунктов, без «воды» и эмодзи-мусора); обязательные ссылки на источники при интернет-поиске; запрет придумывать факты, цифры и цитаты; запрет выдавать внутренние данные и ключи; порядок действий при неоднозначном запросе (переспросить одним вопросом, не гадать); что делать при ошибке инструмента (честно сообщить и предложить альтернативу); сценарии на все типовые случаи — вопрос, поиск, задача, документ, отказ, ошибка, таймаут, пустой результат, повтор.

## Админка

Новая вкладка `/admin/assistant` (или отдельный блок в «Настройки»):
- статус вебхука, кнопка перерегистрации, проверка связи;
- привязанные пользователи и их роли;
- журнал диалогов и планов, кто что утвердил;
- переключатели: разрешить интернет-поиск, лимит запросов в сутки, «только план-режим».

## Техническая часть

- Миграция: `assistant_bot_links` (chat_id ↔ user_id, роль, mute), `assistant_bot_codes` (одноразовые коды привязки), `assistant_bot_updates` (update_id PK — дедупликация ретраев Telegram), `assistant_bot_messages` (журнал), `assistant_bot_settings`. Для каждой таблицы GRANT + RLS: свои строки пользователю, полный доступ админам, `service_role` для сервера.
- Вебхук: `src/routes/api/public/assistant/webhook.ts` — проверка `X-Telegram-Bot-Api-Secret-Token` (timing-safe), дедуп по `update_id`, немедленный `200` и обработка в фоне.
- Транспорт: `src/lib/assistant/transport.server.ts` — отправка через connector-gateway, ретраи, разбивка длинных сообщений, кнопки.
- Поиск: `src/lib/assistant/research.server.ts` — расширение существующего DuckDuckGo-поиска (Wikipedia, чтение страниц, дедуп доменов, таймауты, лимит трафика). Существующий `calendar/research.server.ts` переиспользуется, не дублируется.
- Мозг: `src/lib/assistant/agent.server.ts` — Gemini 3.7 Flash через Lovable AI Gateway, инструменты `web_search`, `read_page`, `make_plan`, `send_chart`. Без искусственных таймаутов на вызовах модели, обработка 402/403/429 по контракту гейтвея с понятным сообщением в чат.
- Персона: `src/lib/assistant/persona.ts` — полный текст роли и правил.

## Проверки, чтобы не ломалось

- Юнит-тесты: парсер поисковой выдачи, обрезка и форматирование сообщений, дедуп `update_id`, маршрутизация режимов (вопрос / план / отказ / опасное действие).
- Тест персоны: набор из ~20 типовых запросов проверяет, что бот не выходит за роль и всегда отдаёт источники при поиске.
- Health-check `/api/public/assistant/health`: состояние вебхука, последний успешный апдейт, доступность модели; при сбое — уведомление вам в Telegram (как уже сделано для календаря).
- Логи ошибок агента пишутся в журнал и видны в админке.

## Порядок работ

1. Миграция + RLS + GRANT.
2. Транспорт, вебхук, привязка по коду.
3. Персона и агент с инструментами.
4. Интернет-поиск (DuckDuckGo + Wikipedia + чтение страниц) и цитирование.
5. План-режим с утверждением кнопкой.
6. Админка и health-check.
7. Тесты и проверка в реальном чате после получения токена.
