
# Аудит админ-панели и предложения по улучшению

Прошёлся по структуре `/admin/*` (22 страницы), сайдбару, дашборду, CRM-заказам и каталогу. Ниже — конкретные идеи, сгруппированные по приоритету. Это план улучшений UX/производительности — без кодовых изменений на этом шаге, дальше выберешь, что внедряем.

---

## 1. Навигация и шапка (быстрые победы)

- **Глобальный поиск (Cmd/Ctrl+K)** в шапке: заказы по имени/телефону/№, карточки каталога, кейсы, посты блога, пользователи. Сейчас в каждый раздел нужно идти руками.
- **Badge-счётчики в сайдбаре**: «Заказы» → число новых (`status = new`), «Календарь» → бронирований на сегодня, «Отзывы» → не модерированных. Видно «где ждёт работа».
- **Хлебные крошки кликабельные** + добавить вторую часть (`Заказы / #a1b2c3 / Договор`). Сейчас только статичный лейбл.
- **Pinned/последние разделы** — мини-блок «Недавнее» в шапке (последние 3 заказа, к которым возвращались).
- **Keyboard shortcuts**: `g o` → заказы, `g c` → календарь, `n` → новая запись на текущей странице, `/` → поиск. Подсказка `?` показывает список.

## 2. Дашборд (`/admin`)

- **Сравнение с прошлым периодом**: «42 заявки за 30 дн (+18% к пред.)». Сейчас цифры без контекста.
- **KPI «Долг» и «Конверсия»**: сумма дебиторки (`total − paid` по активным) и % new→paid за период. Это то, что реально мониторят.
- **График делать переключаемым**: 7д / 30д / 90д, и слой «Выручка» поверх «Заявки» (двойная ось).
- **Воронка статусов** вместо круговой — нагляднее: `new → consultation → estimate → contract → paid`.
- **Алерты-плашки сверху**: «5 заказов без ответа > 24ч», «3 события на этой неделе без подтверждения», «Низкий остаток складских позиций». Кликабельные → отфильтрованный список.
- **Цвета статусов унифицировать** между Pie/таблицами/StatusPill (сейчас локальный массив `PIE_COLORS` отличается от `ORDER_STATUS_COLOR`).

## 3. Заказы / CRM (`/admin/orders`)

- **Kanban-вид** (toggle: список ↔ доска по статусам) с drag-n-drop смены статуса. Под CRM это норма.
- **Сохранённые фильтры**: «Мои», «Горящие (event_date ≤ 7 дн)», «С долгом», «Без задач». В URL search params, чтобы шарить ссылкой.
- **Multi-select + bulk actions**: смена статуса/назначение менеджера/экспорт выбранных.
- **Колонка «Возраст»**: сколько часов/дней в текущем статусе, с цветовой подсветкой SLA (зелёный/жёлтый/красный).
- **Inline-редактирование** суммы/оплаты прямо в строке (сейчас только в модалке).
- **Виртуализация списка** (`@tanstack/react-virtual`) — лимит 500 уже задан, но при росте подвиснет.
- **Дебаунс поиска** — сейчас `q` идёт в `queryKey` напрямую, каждый символ = запрос в БД.
- **Realtime-индикатор**: маленькая точка «● live» в шапке списка, чтобы было видно, что подписка активна.

## 4. Каталог (`/admin/catalog/$type`)

- **Табы типов закреплены вверху** с счётчиками (`Зоны 12 · Техника 34 · Услуги 8 · Производство 5`).
- **Drag-n-drop сортировка `order_index`** — сейчас редактируется числом.
- **Bulk publish/unpublish** + «дублировать карточку».
- **Подсветка незаполненных карточек**: бейдж «черновик» если нет фото/цены/описания.
- **Превью «как на сайте»** в отдельной панели справа от формы (split view), а не модалка.
- **Автосохранение черновика** в localStorage на случай случайного закрытия.

## 5. Календарь / Занятость

- **Цветовая легенда статусов** + фильтр по менеджеру/типу события.
- **Drag события** для переноса даты с подтверждением.
- **iCal-подписка** (`/api/public/calendar.ics?token=...`) — менеджер видит в Google Calendar.

## 6. Загрузка медиа (UniversalMediaUploader)

- **Прогресс-бар на каждый файл** + общая полоса.
- **Drag-n-drop порядка** превью (сортировка галереи).
- **Авто-сжатие изображений** на клиенте (browser-image-compression) до загрузки — экономит трафик и storage.
- **Замена изображения «на месте»** без удаления (двойной клик на превью → выбрать файл).

## 7. Производительность

- **Префетч на hover** ссылок сайдбара (`Link` с `preload="intent"`).
- **`select` в запросах** — не тянуть `select("*")` в списках заказов/каталога, забирать только нужные поля.
- **Серверная пагинация** для заказов > 100 (сейчас лимит 500 = большой JSON в браузере).
- **React Query staleTime ≥ 30s** для справочников (статусы, категории) — сейчас рефетч на каждом монтировании.
- **Code-splitting тяжёлых редакторов** (CampaignEditor 345 строк, OrderAttachments) — `lazy()` + Suspense.

## 8. Визуальная иерархия и «подсветка»

- **Цвет статуса = единственный акцент** в строке (сейчас и градиент в сайдбаре, и pill, и иконки конкурируют за внимание).
- **Sticky-итоги внизу таблицы заказов**: сумма / оплачено / долг по текущему фильтру — уже считается, но скрыто наверху.
- **Empty states с CTA**: «Заказов нет — Создать вручную» / «Нет карточек — Добавить первую». Сейчас просто текст.
- **Skeleton loaders** вместо «Проверка доступа…» и пустых таблиц при `isLoading`.
- **Иконка опасных действий** (удаление) — `text-destructive` + подтверждение через AlertDialog, а не window.confirm.

## 9. Доступность и мобильная админка

- **Контраст активного пункта сайдбара**: `bg-gradient-primary` + `text-primary-foreground` ок, но проверить на светлой теме.
- **Таблицы на мобиле** → карточный вид (сейчас горизонтальный скролл).
- **Focus-ring на всех интерактивных** строках таблицы (сейчас часть рядов — это `<tr>` с onClick без `tabIndex`).
- **Aria-labels** на иконочных кнопках (Download/ExternalLink в orders).

## 10. Аудит и безопасность как фича

- **Лента активности на дашборде**: «Иван изменил статус #abc на paid · 2 мин назад» (из `audit_logs`/`order_timeline`).
- **«Кто сейчас в админке»** — presence через supabase realtime, мини-аватарки в шапке.
- **Лог изменений в карточке заказа** — таймлайн уже есть, но скрыт в модалке; вынести как отдельную вкладку.

## Что предлагаю сделать **первым этапом** (максимум пользы / минимум риска)

1. **Cmd+K глобальный поиск** по заказам/каталогу/блогу.
2. **Badge-счётчики в сайдбаре** (новые заказы, бронирования сегодня, не модерированные отзывы).
3. **Заказы**: дебаунс поиска + колонка «Возраст в статусе» с цветовой SLA-подсветкой + sticky-строка итогов.
4. **Дашборд**: сравнение с прошлым периодом, KPI «Долг», воронка статусов, унифицированные цвета.
5. **Каталог**: счётчики на табах, бейдж «черновик», drag-сортировка `order_index`.
6. **Skeleton loaders** + `AlertDialog` для удалений + empty states с CTA.
7. **Префетч ссылок + staleTime для справочников** — заметно ускорит навигацию.

Дальше — Kanban для заказов, автосохранение черновиков, presence, iCal — это уже отдельные итерации.
