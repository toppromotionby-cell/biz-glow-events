## Цель
Поднять конверсию сайта event-hub.by в заявки и заказы: убрать трение, усилить доверие, ускорить первый контакт.

---

## 1. Конверсионные блоки (наибольший эффект на продажи)

**1.1 Sticky CTA-бар на мобильном** в карточках услуг/оборудования/зон
Внизу экрана плавающая панель: «Цена от X · Заказать» + «В корзину». Сейчас CTA скрыт ниже фолда — на мобильном теряется 30–50% кликов.

**1.2 Lead-magnet / quick-quote форма прямо в карточке**
Над «Похожие» — мини-форма: «Получить расчёт за 15 минут» (имя + телефон + дата). Без перехода на /contacts. Ускоряет lead time, поднимает конверсию x2–3.

**1.3 Социальное доказательство выше фолда**
- Лента отзывов/логотипов клиентов в hero главной (есть `TestimonialsTeaser`, но ниже).
- В карточках — счётчик «N мероприятий с этой услугой за год», даты ближайших занятых дат из `AvailabilityCalendar`.

**1.4 Срочность и дефицит**
- Бейдж «Осталось N дат в этом месяце» в зонах/оборудовании.
- «N человек смотрят сейчас» (мягкий fake-realtime) — этично использовать с реальными данными из аналитики.

**1.5 Exit-intent поп-ап + промокод**
При уходе с карточки — окно «Скидка 5% на первый заказ + чек-лист подготовки мероприятия» с email-захватом. Связать с `subscribeNewsletter` и `promo`.

**1.6 Калькулятор бюджета на главной**
Сейчас `/calculator` спрятан. Виджет на главной «Подберём за 1 минуту»: тип события → гостей → бюджет → персональная подборка + захват контакта.

## 2. Карточки и каталог

**2.1 Полнота информации в карточке**
Добавить чек-лист: что входит / что не входит, длительность монтажа, минимальный заказ, площадь, подходит для (свадьба/корпоратив/конференция). Сейчас только описание + цена.

**2.2 Сравнение и избранное на видном месте**
`CompareButton` и `WishlistButton` есть, но не вынесены как самостоятельный CTA в карточке списка. Добавить иконки в hover-стейте карточки + бейдж счётчика в шапке.

**2.3 Видео-превью**
Поддержать видео-обложку для зон/оборудования (autoplay muted loop при hover на десктопе). Гораздо выше engagement, чем фото.

**2.4 Микроразметка Product/Service + Offer**
Расширить JSON-LD в `seo-jsonld.ts`: `aggregateRating`, `review`, `priceRange`, `availability`. Прямой эффект на CTR из Google.

## 3. Шрифты и типографика

**3.1 Зафиксировать шкалу через CSS-переменные**
В `src/styles.css` есть план `.lovable/plan.md`, но не до конца раскатан. Завершить:
- `--text-xs: clamp(13px, 0.85rem, 14px)` (минимум 13px на мобильном)
- `--text-base: clamp(16px, 1rem + 0.1vw, 17px)`
- Lead-параграфы: `text-lg sm:text-xl md:text-2xl`
- CTA-кнопки: минимум 16px шрифт, height 48px на мобильном (тач-таргет)

**3.2 Контраст на dark-теме**
Проверить `text-muted-foreground` на карточках — местами на тёмном фоне опускается ниже AA. Поднять на 1 шаг светлее.

**3.3 Display-шрифт**
Сейчас Space Grotesk. Для премиального event-сегмента подходит, но в hero крупных заголовках добавить `letter-spacing: -0.03em` и `font-feature-settings: "ss02"` для более «дорогого» кёрнинга.

## 4. Скорость и UX

**4.1 LCP оптимизация**
- Hero-картинка главной: преобразовать в AVIF/WebP с `<link rel="preload" as="image" fetchpriority="high">`.
- Шрифты: `font-display: swap` + `<link rel="preconnect">` к Google Fonts.

**4.2 Skeleton-стейты**
В каталоге, рекомендациях, недавно просмотренных — заменить пустоту/спиннер на skeleton-карточки. Снижает воспринимаемое время загрузки.

**4.3 Прогресс-индикатор оформления заказа**
В `/cart` сделать 3 шага: Корзина → Контакты → Подтверждение. Сейчас всё в одной форме — длинная страница пугает.

**4.4 Восстановление брошенной корзины**
Если корзина не пуста и пользователь ушёл — через 1 час email/Telegram-нотификация (если оставлял контакт), при возврате — баннер «У вас осталось N позиций».

## 5. Доверие и контент

**5.1 Страница «Кейсы» с фильтрами**
Сейчас `/cases` есть, но без фильтров по типу события/индустрии. Добавить чипы-фильтры + связку «эта услуга использовалась в этих кейсах» в карточке.

**5.2 FAQ с микроразметкой FAQPage**
Добавить аккордеон на главной и в карточках топ-услуг. + JSON-LD FAQPage для rich snippets в Google.

**5.3 Прозрачное ценообразование**
Если цена «от» — рядом ссылка «что влияет на цену» (попап с факторами). Скрытые цены = главный барьер B2B-продаж.

**5.4 Команда и процесс**
На `/about` блок «Как мы работаем» с шагами 1–5 и фото менеджера, который перезвонит. Существенный буст доверия для B2B.

## 6. Функциональные доработки

**6.1 Webhook-нотификации в реальном времени**
В `submitLead` уже есть Telegram. Добавить:
- Push в браузер админу через service worker.
- SMS-фолбэк на критичные лиды (бюджет > X) через SMS-провайдер.

**6.2 A/B-тесты CTA**
Через `analytics` уже есть GA4 + Метрика. Добавить простой server-side split-test для текста кнопок («Заказать» vs «Получить расчёт» vs «Узнать стоимость»). Таблица `ab_experiments` + хук `useExperiment`.

**6.3 Динамические UTM-страницы**
Лендинги `/lp/svadba`, `/lp/korporativ` — отдельные посадочные под рекламу с заточенным сообщением и одним CTA. Сейчас весь трафик льётся на главную.

**6.4 Чат-виджет**
`FloatingContacts` есть. Добавить онлайн-чат (Telegram Web App / Crisp) — первая линия 24/7 поднимает конверсию на 15–25%.

**6.5 Личный кабинет — повторные заказы**
В `/profile` кнопка «Повторить заказ» из истории, «Добавить всё в корзину». LTV-механика.

## 7. SEO для притока клиентов

**7.1 Кластеры контента**
Блог сейчас плоский. Сделать рубрики «Свадьбы», «Корпоративы», «Конференции» — pillar-страницы + 5–10 статей каждая, перелинковка с карточками каталога.

**7.2 Локальное SEO**
Микроразметка LocalBusiness, страницы под гео-запросы («аренда зала в Минске», «звук на свадьбу Минск»). Sitemap уже есть — добавить hreflang ru-BY.

**7.3 Sitemap по категориям**
Разбить `sitemap.xml` на index + sitemap-services / sitemap-equipment / sitemap-blog. Лучше индексируется в Google.
