## Идея

Для позиций с почасовой тарификацией заменить «выбор строки таблицы» на удобный ползунок: пользователь тянет слайдер — мгновенно видит итоговую сумму и пояснение, из чего она сложилась. Таблица тарифов остаётся как справка (read-only), но не требует кликов.

## Логика расчёта

1. **Определение режима «часы»**: если хотя бы одна строка `tiers` имеет unit/label, распознанный как «час» (`detectQuantityKind` уже умеет это), включаем режим слайдера.
2. **Парсинг тарифов**:
   - Из каждой строки извлекаем `hours` (число из label: «1 час», «4 часа», «5 часов») и `price`.
   - Отдельно ищем строку «каждый последующий час» / unit=«час» без числа в label → `extraPerHour`.
3. **Базовый диапазон**: от `minHours` (обычно 1) до `maxTierHours` (например 5) — точные цены берём из таблицы.
4. **Расширение**: если есть `extraPerHour`, слайдер уходит дальше (до 24 ч по умолчанию). Цена = `priceAt(maxTierHours) + (hours − maxTierHours) × extraPerHour`.
5. **Если `extraPerHour` нет** — слайдер ограничен `maxTierHours`.

## UI блока цены (карточка в модалке и на странице)

```text
Стоимость актуальна в безналичном расчёте
1 120 Br                       ← крупно, обновляется live
4 часа · 280 Br/час            ← мелкая расшифровка

[───────●─────────]  1 ── 24 ч  ← слайдер + −/+ кнопки
                                  под ним метки: 1ч, 4ч (популярно), 5ч, 24ч

▸ Подробная тарифная сетка     ← раскрывающийся блок с PriceTableView (read-only)

[ Заказать · 1 120 Br ]        ← CTA с актуальной суммой
```

- Над слайдером — текущее значение и формула.
- Подпись «Популярный» подсвечивает соответствующее деление шкалы.
- Заголовок «от 180 Br» убираем, когда выбрано конкретное значение (показываем итог).
- На мобильных — sticky CTA с итогом.

## Корзина

`addToCart` получает:
- `price` = итог,
- `qty` = выбранные часы,
- `title` = `"<название> — 4 часа"`,
- `meta.hours`, `meta.unitPrice` (для редактирования в админке заказов).

## Поведение по умолчанию

- Начальное значение слайдера = «популярный» тариф, иначе минимальный.
- Шаг = 1 час.
- При hover/drag — лёгкая анимация числа итога (без тяжёлых эффектов).
- Если в тарифах нет ни «часа», ни `extraPerHour` — блок не активируется, рендерим прежний выбор строкой.

## Edge cases

- Только одна часовая строка и нет «каждый последующий» → слайдер скрываем, показываем фиксированную цену.
- Тарифы не строго линейные (например, оптовая скидка на 4 ч): между опорными точками используем ближайшую снизу опорную цену, а не линейную интерполяцию, чтобы не «врать» пользователю.
- `extraPerHour` без хотя бы одной опорной цены → берём `extraPerHour` как базовую и считаем `hours × extraPerHour`.
