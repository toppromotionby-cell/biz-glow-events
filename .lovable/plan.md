# Шаблоны слайдов 2026–2027 + надёжность PDF

## 1. Завершаю ранее утверждённое (альбомное превью КП)

Без изменений по объёму: проп ориентации у листа A4, три колонки «Себестоимость / Прибыль / %» в превью, кнопка «Альбомный + маржа» рядом с «Внутренний вид» (только при праве на себестоимость, состояние в `editor_prefs`), клиентские PDF/HTML не меняются + тест на отсутствие себестоимости в клиентском выводе.

## 2. Блок добавления слайда: топовые шаблоны и по 5 вариантов оформления

Сейчас при добавлении слайда есть только 5 типов (Титульный, Товар/позиция, Текстовый, Разделитель, Контакты) без выбора оформления. Делаю:

- Для каждого типа слайда — 5 готовых вариантов раскладки в актуальной презентационной стилистике 2026–2027 (крупная типографика, асимметрия, полноэкранное фото с затемнением, split-экран, карточная сетка, «bento», минимал с большим воздухом). Примеры по типам:
  - Титульный: полноэкранное фото, split 50/50, минимал по центру, крупный оверлей-заголовок, bento-обложка.
  - Товар/позиция: фото слева + характеристики, фото-герой сверху, галерея 2×2, карточка с ценой-акцентом, сравнение двух колонок.
  - Текстовый: одна колонка, две колонки, тезисы с крупными цифрами, цитата, чек-лист.
  - Разделитель: цветная плашка, номер главы, фото на весь экран, тонкая линия-минимал, градиент.
  - Контакты: центр, split с фото, карточка с QR, три колонки, футер-полоса.
- В блоке добавления слайда карточка типа раскрывает мини-превью 5 вариантов — видно, как будет выглядеть слайд, выбор одним кликом.
- Вариант хранится в слайде как отдельное поле и применяется одинаково в редакторе, превью и PDF; уже созданные слайды получают вариант «по умолчанию» и выглядят как сейчас.
- Дополнительно расширяю набор тем презентации современными наборами (нейтраль-графит, тёплый песок, электрик-синий, монохром + акцент, «мягкий градиент»), с автоматической проверкой контраста, которая уже есть.

## 3. Надёжность PDF (5 запрошенных механизмов)

1. Единый подбор шрифтов и fallback: один модуль решает, каким начертанием рисовать фрагмент (обычный / жирный / дисплейный / кириллица), и при отсутствии гарнитуры или глифа спускается по цепочке замен вместо поломки вёрстки. Все генераторы PDF (документы, КП, презентации) ходят через него.
2. Режим отладки для внутреннего пользования: переключатель, который в PDF и превью рисует рамки блоков и подсвечивает места, где текст обрезан, перенесён или ужат по кеглю, со сводкой в конце файла. Доступен только сотрудникам, в клиентских документах отсутствует.
3. Регрессионные тесты вёрстки PDF: наборы с разными шрифтами, очень длинными словами и суммами, пустыми и «тяжёлыми» наборами фото (0, 1, 3, 5 картинок, вертикальные и панорамные) — проверяют, что ничего не выходит за поля и не накладывается.
4. Автопроверка «превью = PDF»: сравнение ключевых таблиц (состав колонок, число строк, итоги) и картинок (сколько, в каких рамках) между HTML-превью и PDF; расхождение валит тест и подсвечивается в панели проверки документа.
5. Настройки обрезки изображений: выбор поведения фото (вписать / заполнить / заполнить с фокусом сверху) для внутреннего PDF и презентаций, с сохранением в настройках и мгновенным превью.

## Что не меняется

- Клиентские КП, договоры, счета: их вывод остаётся прежним, отладочные слои и себестоимость туда не попадают.
- Расчёты сумм, скидок, маржи; база данных существующих слайдов (миграция не требуется — новые поля добавляются в JSON слайда с безопасным значением по умолчанию).

## Технические детали

- `src/lib/presentations/model.ts`: `SlideVariant` (5 значений на каждый тип), нормализация с дефолтом; `PRESENTATION_TEMPLATES` дополняется новыми темами + подписи.
- `src/lib/presentations/design.ts` / `content-spec.ts`: раскладки-варианты как чистые функции над `Rect`, используются и в `SlideCanvas.tsx`, и в `pdf.server.ts` — один источник правды.
- UI выбора: расширение блока добавления слайда в `admin.documents.presentations.$id.index.tsx` + мини-превью вариантов (SVG-схемы, без тяжёлого рендера).
- Шрифты: `src/lib/documents/pdf-fonts.server.ts` получает `resolveFont(face, weight, text)` с цепочкой fallback; `pdf.server.ts` (документы и презентации) переходит на него.
- Отладка: флаг `debugLayout` в опциях генерации, отрисовка рамок и меток поверх контента; UI-переключатель рядом с «Внутренний PDF».
- Обрезка: `imageFit: "cover" | "contain" | "cover-top"` в настройках документа/презентации, применяется в клиппинге pdf-lib и в CSS превью.
- Тесты: `src/lib/presentations/__tests__/pdf-layout.regression.test.ts`, `src/lib/documents/__tests__/preview-pdf-parity.test.ts`.
