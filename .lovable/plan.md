# Перетаскивание и масштабирование элементов на слайде

Сейчас раскладка слайда считается полностью автоматически: сторона и ширина фотоблока, текстовая область, цена и логотипы определяются по объёму текста и количеству фото. Вручную можно задать только сторону фото. Добавляем прямое управление мышью на превью — по модели «умные зоны»: элемент тянется, встаёт в ближайшую допустимую зону, остальные автоматически перестраиваются, центрируются и подгоняют кегль.

## Что получит пользователь

- В крупном превью слайда элементы становятся интерактивными: фотоблок, текстовый блок, блок цены/характеристик, логотип компании и логотип клиента.
- Перетаскивание: при захвате элемента подсвечиваются доступные зоны (слева / справа / сверху / фон — для фото; верх / центр / низ — для текста; под текстом / в углу / рядом с фото — для цены; 4 угла + низ по центру — для логотипов). Отпускаешь — элемент садится в подсвеченную зону.
- Масштабирование: угловой маркер меняет размер элемента (доля слайда). Фотоблок — от 25% до 65% ширины; текст — ширина колонки; логотипы — коэффициент к базовому размеру. Значения ограничены так, чтобы ничего не выходило за поля и не наезжало.
- После любой правки остальные блоки сразу перестраиваются: текст занимает свободное место, кегль подбирается автоматически (существующая шкала плотности), содержимое центрируется по вертикали в своей зоне.
- Кнопка «Сбросить раскладку» на слайде возвращает полный автомат.
- Всё, что видно в превью, идентично отдаётся в PDF и PPTX.

## Как это будет работать

- В содержимое слайда добавляется необязательный блок настроек раскладки: зона и масштаб фото, зона и ширина текста, зона цены, зона и масштаб каждого логотипа. Пустые значения = «авто», то есть текущее поведение сохраняется для всех уже созданных презентаций.
- Раскладка остаётся единым расчётом: ручные значения — это входные параметры автомата, а не абсолютные координаты. Поэтому «остальное подстраивается само» работает всегда.

## Технические детали

- `src/lib/presentations/model.ts`: новый тип `SlideLayoutOverrides` (`photoZone`, `photoScale`, `textZone`, `textWidth`, `priceZone`, `brandLogo`/`clientLogo`: `{ zone, scale }`) внутри `SlideContent`, плюс нормализация с дефолтом `auto` — обратная совместимость со старыми записями.
- `src/lib/presentations/design.ts`: `slideLayout(slide)` принимает overrides: зона задаёт `placement`, `photoScale` заменяет расчёт `photoW`, `textWidth`/`textZone` корректируют `textBox` (с вертикальным центрированием), добавляется `priceBox` в `SlideLayout`. Все значения проходят через clamp по полям сетки.
- `src/lib/presentations/fit.ts`: подбор плотности продолжает работать от изменённого `textBox`; при переполнении показывается существующее предупреждение.
- `src/lib/presentations/logo-plan.ts`: `planSlideLogos` учитывает ручную зону/масштаб; при конфликте (занятая зона) остаётся правило «один логотип каждого типа на слайде».
- `src/components/admin/presentations/SlideCanvas.tsx`: новый режим `interactive` (только в редакторе). Оверлей с рамками элементов, drag через Pointer Events на невращаемом контейнере, пересчёт координат с учётом текущего `transform: scale`, подсветка кандидат-зон, угловые маркеры ресайза, `touch-action: none`. Превью/фуллскрин/миниатюры рендерятся как сейчас.
- Новый файл `src/lib/presentations/zones.ts`: описание допустимых зон каждого элемента и функция «какая зона ближе к точке» — общая для drag-логики и для тестов.
- `src/routes/admin.documents.presentations.$id.index.tsx`: изменения раскладки идут в тот же локальный стейт слайда и автосохранение (с уже добавленным `dirtyRef`), плюс кнопка сброса раскладки в панели настроек слайда.
- `src/lib/presentations/pdf.server.ts` и `pptx.browser.ts`: используют обновлённые `slideLayout` и `planSlideLogos` — правок логики не требуется, только передача overrides.
- Тесты: `src/lib/presentations/__tests__/` — выбор зоны по координате, clamp масштабов, отсутствие пересечений фото/текста/цены, обратная совместимость слайдов без overrides.
