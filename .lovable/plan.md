# Календарь планера + визуальные ответы в Telegram

## Часть 1. Полноценный календарь в разделе «Планер»

Сейчас в `/admin/planner` только списки (Сегодня / Просрочено / Дальше / Приоритеты / Аналитика / Входящие / Настройки). Добавляем вкладку **«Календарь»** — с той же логикой, что в Google Календаре.

**Масштабы просмотра**
- День — почасовая сетка.
- Неделя — почасовая сетка на 7 дней.
- Месяц — классическая сетка.
- Год — 12 мини-месяцев с точками загруженности; клик по дню открывает день.
- Переключатели «Сегодня / ‹ / ›», как в Google.

**Фильтры (панель слева над календарём)**
- Отдельные переключатели **Задачи** и **Встречи** (можно смотреть только одно).
- Направления (Личное, Belight, EventHub, Top Promotion) — чекбоксы с цветами.
- Статус: скрыть выполненные, показать только просроченные.
- Важные (жёсткие) — отдельный флажок.
- Выбор фильтров запоминается в браузере.

**Работа прямо в календаре**
- Клик по пустому месту — быстрое создание (название, задача/встреча, направление).
- Перетаскивание и растягивание события меняет время (с подтверждением, ничего не двигается само).
- Клик по событию — карточка справа: перенести, отметить сделанным, удалить, открыть заметки.
- Задачи без времени показываются лентой «на весь день» сверху, как в Google.

**Цвета и читаемость**: цвет берётся от направления, выполненные — приглушённые с зачёркиванием, просроченные — красная рамка, жёсткие — иконка замка.

## Часть 2. Визуальные ответы в Telegram

Бот перестаёт отвечать «сухим» текстом там, где нагляднее картинка или таблица.

**Что появится**
- **Картинка дня/недели**: на `/today`, `/week`, утренний и вечерний дайджест бот присылает изображение-таймлайн (полоски дел по часам с цветами направлений) + короткий текст с кнопками.
- **Таблицы**: списки (просрочено, хвосты, поиск) — моноширинной таблицей, которая ровно выглядит в Telegram, для длинных — картинкой-таблицей.
- **Графики**: в понедельничном обзоре и по запросу «аналитика» — диаграмма нагрузки по направлениям и столбики «сделано / перенесено» по дням.
- **Альбом**: неделя может прийти как альбом из 7 картинок-дней (по запросу «неделя картинками»).
- **Всегда есть текст**: под каждой картинкой — подпись с тем же содержанием, чтобы можно было читать и голосом (Алиса), и при сбое картинки.

**Кнопки под визуалом**: «Сегодня / Завтра / Неделя», «Только задачи», «Только встречи», «Обновить» — переключают вид прямо в чате без набора команд.

**Настройка**: в «Настройках планера» — переключатель «Присылать картинки» (вкл/выкл), выбор «картинка + текст» или «только текст», и что показывать в дайджесте.

## Как это устроено технически

- **Календарь**: используем уже установленный FullCalendar, добавляем плагины `timegrid` (день/неделя) и `multimonth` (год) + `rrule` не нужен. Новый компонент `src/components/admin/planner/PlannerCalendar.tsx`, источник данных — существующие серверные функции планера, расширенные диапазоном `from/to` и фильтрами (`kinds`, `direction_ids`, `statuses`). Перетаскивание вызывает уже готовые `rescheduleItem` / `saveItem`.
- **Год**: `multiMonthYear` из FullCalendar; тепловая заливка дней считается на клиенте из загруженного диапазона.
- **Рендер картинок для Telegram**: backend Cloudflare Workers, поэтому Canvas/sharp недоступны. Генерируем **SVG-макет** (таймлайн дня, таблица, столбчатый график) в `src/lib/calendar/visual/*.ts` и превращаем в PNG через внешний рендер-эндпоинт по URL (QuickChart-совместимый `/chart` для графиков и `/svg` для таймлайнов) — Telegram скачивает картинку сам по ссылке через `sendPhoto`, без хранения файлов. Если рендер недоступен, автоматический откат на моноширинный текст `<pre>`.
- **Telegram API**: добавляем в `src/lib/calendar/telegram.server.ts` методы `tgSendPhoto`, `tgSendMediaGroup`, `tgSendDocument`; вызовы идут через уже подключённый коннектор бота планера (`TELEGRAM_API_KEY_1`).
- **Единый слой представления**: `src/lib/calendar/render.ts` расширяем функциями `renderTable()` (моноширинная таблица) и `visualForRange()` (решает: картинка, альбом или текст) — их используют и команды, и дайджесты, и инструмент `list_items` AI-мозга.
- **Настройки**: миграция добавит в `assistant_prefs` поля `visuals_enabled`, `visual_mode` (`image`/`text`), `digest_visual`.
- **Тесты**: юнит-тесты на построение SVG-таймлайна (границы суток, пересечения, пустой день), на моноширинную таблицу (ширины колонок, кириллица) и на выбор режима вывода при выключенных картинках.

## Порядок работ

1. Миграция настроек (`visuals_enabled`, `visual_mode`, `digest_visual`).
2. Серверные функции планера: диапазон + фильтры.
3. Вкладка «Календарь» с день/неделя/месяц/год и фильтрами задач/встреч.
4. Drag-and-drop, быстрое создание, карточка события.
5. SVG-визуалы (таймлайн, таблица, график) + отправка фото/альбомов в Telegram.
6. Подключение визуалов к командам, дайджестам и понедельничному обзору + кнопки переключения.
7. Настройки визуалов в UI планера и тесты.
