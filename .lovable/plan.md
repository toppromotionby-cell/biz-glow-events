# Переименование раздела «Документы» → «Коммерческие предложения»

Меняем только видимые тексты в админке. Адреса страниц (`/admin/documents/...`) остаются прежними, чтобы не ломать закладки и сохранённые ссылки.

## Что увидит пользователь

- **Сайдбар:** группа «Документы» → «Коммерческие предложения»; пункт «Все документы» → «Все КП». Пункты «Презентации», «База знаний», «Компании» остаются внутри группы без изменений.
- **Шапка страницы** `/admin/documents`: заголовок «Документы» → «Коммерческие предложения», подпись «N документов · на сумму …» → «N КП · на сумму …».
- **Вкладки списка:** «Документы» → «КП»; «Шаблоны», «Счета и акты», «Файлы по заказам», «Аналитика» остаются как есть (счета/акты — не КП).
- **Кнопки и диалоги:** «Создать документ» → «Создать КП»; диалог создания — «Создать КП» / «Выберите тип КП»; тосты «Документ удалён/создан/обновлён» → «КП удалено/создано/обновлено»; подтверждение «Удалить документ?» → «Удалить КП?»; пустые состояния «Документов не найдено» → «КП не найдено».
- **Хлебные крошки:** `/admin/documents` → «Коммерческие предложения» (правило для `/admin/documents/quotes` уже совпадает).
- **Командная палитра:** пункт «Документы» → «Коммерческие предложения».
- **Редакторы КП и КП промо:** заголовки, статус-бар («Документ готов к отправке» → «КП готово к отправке»), панели версий, ошибки «Документ не найден» → «КП не найдено».

## Что НЕ переименовываем

- Финансовые документы (счета, договоры, акты) и вложения по заказу — там «документ» означает именно счёт/акт/файл, а не КП: блок «Документы и файлы» в заказе, «Документы по заказу» в письмах, панель «Счета и акты», страница «Компании» (настройки реквизитов), клиентский кабинет `/my/$token`.
- Публичные страницы сайта и тексты писем клиентам.
- Технические названия: URL, имена файлов, ключи в БД, серверные функции, комментарии в коде.

## Технические детали

Правки — строковые, в файлах:

- `src/components/admin/AdminSidebar.tsx` (название группы и пункта)
- `src/routes/admin.tsx` (крошка `/admin/documents`)
- `src/routes/admin.documents.index.tsx` (заголовок, подпись, вкладки, кнопки, тосты, пустые состояния)
- `src/components/admin/documents/CreateDocumentDialog.tsx` (заголовки шагов, тексты)
- `src/components/admin/AdminCommandPalette.tsx`
- `src/routes/admin.documents.quotes.$id.index.tsx`, `src/routes/admin.documents.promo.$id.index.tsx` (тосты, ошибки)
- `src/components/admin/documents/DocStatusBar.tsx`, `DocVersionsPanel.tsx`, `SaveToLibraryDialog.tsx` — где текст относится к КП
- `src/lib/document-fetch-error.ts` + его тест — сообщение «Документ не найден» → «КП не найдено» (проверить, что оно не используется для счетов/актов; если используется — оставить нейтральным)

После правок — прогон юнит-тестов и визуальная проверка страницы списка и редактора КП.
