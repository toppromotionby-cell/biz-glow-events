# База знаний документов — раздел управления

Новый раздел админки «База знаний» в группе «Документы»: просмотр, поиск и удаление накопленных данных (клиенты, позиции, тексты), которые автоматически собираются при сохранении КП, КП Промо и документов по заказам.

## Что появится

Страница `/admin/documents/knowledge` с тремя вкладками:

1. **Контрагенты** — имя, компания, УНП, телефон, email, адрес, сколько раз использовался, когда использовался в последний раз.
2. **Позиции** — раздел, название, единица, цена, себестоимость, частота использования, дата последнего использования.
3. **Тексты** — тип фрагмента (примечание, футер, раздел, площадка, формат, условие), сам текст, частота и дата.

На каждой вкладке:
- строка поиска (по всем текстовым полям, с задержкой ввода);
- сортировка: по частоте использования, по дате последнего использования, по алфавиту;
- пагинация (по 50 записей);
- удаление одной записи с подтверждением;
- массовое выделение чекбоксами и удаление выбранных;
- отдельная кнопка «Удалить неиспользуемые» — записи, которые использовались 1 раз и старше 6 месяцев (с предварительным показом количества);
- пустое состояние и счётчик записей.

Удаление затрагивает только базу знаний — сами КП, заказы и документы не меняются. Удалённая запись просто перестанет предлагаться в подсказках; если такой клиент/позиция появится в новом документе, запись создастся заново.

Пункт «База знаний» добавляется в боковое меню в группе «Документы».

## Технические детали

- Расширить `src/lib/doc-knowledge.server.ts` функциями списка/удаления для трёх таблиц (`doc_contacts`, `doc_item_catalog`, `doc_text_snippets`): постраничный запрос с фильтром, сортировкой и общим количеством; удаление по массиву id; очистка редко используемых по порогу.
- Добавить в `src/lib/doc-knowledge.functions.ts` серверные функции `listKnowledge*`, `deleteKnowledge*`, `pruneKnowledge` с существующей проверкой `assertStaff` (admin/manager) — доступ только для персонала, работа через `supabaseAdmin` внутри обработчика.
- Новый роут `src/routes/admin.documents.knowledge.tsx` под существующей защитой `/admin`; данные через TanStack Query (`useQuery` + `useMutation` с инвалидацией).
- UI на существующих компонентах shadcn (Tabs, Table, Input, AlertDialog, Checkbox, Pagination), в фирменной палитре, без новых зависимостей.
- Пункт меню в `src/components/admin/AdminSidebar.tsx` (группа «Документы»).
- Изменения схемы БД не требуются.
