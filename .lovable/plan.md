## Что сейчас на странице `/admin/orders/$id`

Шапка: «К списку», заголовок «Заказ #xxxxxxxx», дата, кнопки «Скачать КП», «Предпросмотр письма», селект статуса, «Удалить заказ».
Грид: «Клиент» (имя, телефон, email, компания, дата мероприятия, UTM) и «Финансы» (сумма + оплачено).
Дальше отдельными блоками: «Позиции», «Вложения», «Комментарий клиента», «Внутренние заметки», «Таймлайн», модалка предпросмотра письма.

Карточка выросла «в высоту» — много одинаковых glass-блоков, действия размазаны по шапке, важная информация (остаток к оплате, контактные действия, статус оплаты) не выделена.

## Что можно **упростить** (выбери одно или несколько)

**S1. Свести шапку к одной строке + action-меню.**
Оставить в шапке только заголовок, дату и badge статуса. «Скачать КП», «Предпросмотр письма», «Удалить» убрать под одну кнопку «Действия ▾» (DropdownMenu). Селект статуса заменить на кликабельный badge с поповером выбора. Меньше визуального шума, экран не разъезжается на маленьких ноутбуках.

**S2. Двухколоночная компоновка вместо вертикальной ленты.**
Слева (основная колонка): Клиент, Позиции, Комментарий клиента, Вложения. Справа (sticky-сайдбар на lg+): Финансы, Статус, Внутренние заметки, Таймлайн. Карточка перестаёт быть бесконечной простыней, всё важное видно сразу.

**S3. Объединить «Клиент» и «Мероприятие» в один блок с явными группами.**
Сейчас дата мероприятия и UTM лежат в «Клиенте», что путает. Разделить на подсекции «Контакты» / «Мероприятие» / «Источник» внутри одной карточки, либо вынести «Мероприятие» отдельной плиткой рядом с «Финансами».

**S4. Свернуть «Таймлайн» и «Внутренние заметки» в табы.**
Один блок снизу с табами `Заметки | Таймлайн | Вложения`. Экономит ~50% высоты, ничего не теряется.

**S5. Упростить таймлайн.**
Сейчас `JSON.stringify(payload)` показывается как есть. Заменить на человекочитаемые подписи (например, для `status_changed:*` — «Статус → Подтверждён», для `email_sent` — «Письмо отправлено»), JSON прятать под «Подробнее».

## Что можно **добавить** (по приоритету из практики)

**A1. Сводная плашка-summary в шапке.**
Полоса под заголовком: `Статус · Сумма · Оплачено · Остаток · До мероприятия N дн.` Это то, что менеджер ищет в первую очередь.

**A2. Quick actions на контактах клиента.**
Иконки рядом с телефоном/email: позвонить (`tel:`), написать на почту (`mailto:`), скопировать в буфер. Плюс ссылка на WhatsApp/Telegram по номеру.

**A3. Платежи: «Внести оплату» + история.**
Кнопка «+ Оплата» открывает диалог (сумма, метод, дата, комментарий) → пишет в `order_timeline` событие `payment_added` и обновляет `paid`. Показывает остаток и прогресс-бар оплаты.

**A4. Inline-редактирование позиций.**
Сейчас позиции read-only. Добавить редактирование `qty`/`price`, удаление строки, кнопку «+ Позиция» (поиск по каталогу). Пересчёт `total` автоматически.

**A5. Быстрый чек-лист документов.**
В шапке/сайдбаре маленький блок: `КП ✓ · Договор · Счёт · Акт` — каждая иконка либо «уже сформирован/отправлен» (зелёная), либо кликабельная для генерации. Сейчас за этим надо ходить по отдельным роутам `/quote /contract /invoice /act`.

**A6. Готовые шаблоны писем клиенту.**
Рядом с «Предпросмотр письма» — выпадающий список: «Подтверждение», «Напоминание о предоплате», «Запрос отзыва», «Кастомное». Один клик — превью, второй — отправка.

**A7. Назначение ответственного менеджера.**
Поле `assignee` (user_roles). Видно в шапке аватаром, фильтруется в списке заказов. Сейчас непонятно, кто ведёт заказ.

**A8. Дублирование заказа.**
Кнопка «Создать похожий» — копирует клиента + позиции в новый draft. Часто нужно для постоянных клиентов.

**A9. Конфликты по дате/оборудованию.**
Badge-предупреждение в шапке, если на `event_date` уже есть другой подтверждённый заказ или пересечение по позициям из `availability`. Защита от двойного бронирования.

**A10. Действия по статусам (state-machine подсказки).**
Под селектом статуса — кнопка следующего ожидаемого шага: для `new` → «Отправить КП», для `quoted` → «Подтвердить», для `confirmed` → «Запросить предоплату» и т.д. Снижает когнитивную нагрузку.

## Что я предложил бы в первую очередь (если нужен мой выбор)

Минимальный пакет с большим эффектом и без переделки бэка:

1. **S2** (двухколоночная раскладка со sticky-сайдбаром)
2. **S1** (action-меню в шапке) + **S4** (табы для заметок/таймлайна/вложений)
3. **A1** (summary-плашка: статус, сумма, оплачено, остаток, дней до мероприятия)
4. **A2** (quick actions у контактов)
5. **A5** (чек-лист документов) — переиспользует существующие роуты `/quote /contract /invoice /act`

Это компактно, ничего не ломает в БД и сразу повышает скорость работы менеджера.

Следующим этапом (требует миграций/новых server fn): **A3 платежи**, **A4 редактирование позиций**, **A7 ответственный**, **A9 конфликты**.
