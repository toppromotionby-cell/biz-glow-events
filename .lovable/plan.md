# Кнопка DOCX: скачивание вместо «мигающего» предпросмотра + защита от повторов

Причина: при клике на «DOCX» файл грузится через общий просмотрщик документов, который кладёт любые байты в диалог с `<iframe src=blob:…>`. Word-файл браузер отобразить не умеет, поэтому вместо превью он молча запускает скачивание, а на экране остаётся пустой диалог. То есть скачивание — побочный эффект iframe, а не задуманное поведение.

## Что изменится

- Кнопка «DOCX» честно и сразу сохраняет файл: документ скачивается по клику, показывается тост «Файл сохранён», пустой диалог больше не открывается.
- Кнопка «PDF» работает как раньше — открывается предпросмотр с кнопкой «Скачать».
- Просмотрщик документов перестаёт пытаться показать в iframe форматы, которые браузер не умеет открывать (DOCX, XLSX, ZIP и прочее): вместо пустого окна — карточка с именем и размером файла и кнопкой «Скачать». Это защищает не только раздел документов, но и все другие места, где используется просмотрщик.
- Добавляется проверка целостности файла до показа/сохранения: DOCX должен быть корректным ZIP-архивом (как сейчас проверяется сигнатура PDF). При битом ответе — понятная ошибка вместо повреждённого файла.
- На стороне сервера добавляется проверка, что генератор DOCX вернул непустые байты, иначе — ошибка с id, а не «файл на 0 байт».
- Регрессионные тесты: юнит-тест на выбор режима (предпросмотр / скачивание) по MIME и тест на сборку DOCX (валидный ZIP, непустой размер).

## Также завершаю начатую задачу по фирменному бланку

Работа из утверждённого ранее плана доделывается в том же заходе: выбор компании в верхней панели редактора, автоподстановка основной компании, живое обновление настроек бланка и поле «Логотип клиента» в панели бланка.
